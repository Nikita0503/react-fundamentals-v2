What are the main differences between imperative and reactive approaches to programming in the context of React?


(x) The imperative approach uses regular variables to store and update data, while the reactive approach uses "reactive" variables created with hooks to manage state in React components. ( ) The imperative approach uses only class components, and the reactive approach uses only functional ones. ( ) Imperative programming uses a stylized approach to creating components, while reactive uses a declarative one.

How is the useState hook used to work with state in React functional components?


(x) The useState hook creates a pair of a value and a function to update it, is initialized with a default value, and this allows creating and updating state in functional components. ( ) The useState hook is used only to change state values in class components. ( ) The useState hook automatically determines and updates state without setting an initial value.

What does an example of using the useState hook to create a Counter in a React functional component look like?


Option 1: 
// Counter.tsx
import React, { useState } from 'react';

const Counter = () => {

  const count = 0;

  const setCount = (newCount: number) => {
    count = newCount;
  };

  const increment = () => {
    setCount(count + 1);
  };

  return (
  <div>
    <p>Count: {count}</p>
    <button onClick={increment}>Increment</button>
  </div>);
};

export default Counter;

Option 2:
// Counter.tsx
import React, { useState } from 'react';

const Counter = () => {
  const [count, setCount] = useState<number>(0);

  const increment = () => {
    setCount(count + 1);
  };

  return (
  <div>
    <p>Count: {count}</p>
    <button onClick={increment}>Increment</button>
  </div>);
  );
};

export default Counter;
