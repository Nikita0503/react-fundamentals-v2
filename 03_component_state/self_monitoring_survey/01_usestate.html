Які основні відмінності між імперативним та реактивним підходами до програмування в контексті React?


(x) Імперативний підхід використовує звичайні змінні для збереження та оновлення даних, тоді як реактивний використовує «реактивні» змінні, створювані за допомогою хуків, для керування станом в компонентах React. ( ) Імперативний підхід використовує тільки класові компоненти, а реактивний - тільки функціональні. ( ) Імперативне програмування використовує стилізований підхід до створення компонентів, тоді як реактивне - декларативний.

Як використовується хук useState для роботи зі станом в функціональних компонентах React?


(x) Хук useState створює пару значення та функцію для її оновлення, ініціалізується за допомогою значення по замовчуванню, і це дозволяє створити та оновлювати стан у функціональних компонентах. ( ) Хук useState використовується тільки для зміни значення стану в класових компонентах. ( ) Хук useState автоматично визначає та оновлює стан без задання початкового значення.

Як виглядає приклад використання хука useState для створення лічильника (Counter) у функціональному компоненті React?


Варіант 1: 
import React, { useState } from 'react';

const Counter = () => {

  const count = 0;

  const setCount = (newCount) => {
    count = newCount;
  };

  const increment = () => {
    setCount(count + 1);
  };

  return (
  <div>
    <p>Count: {count}</p>
    <button onClick={increment}>Increment</button>
  </div>);
};

export default Counter;
