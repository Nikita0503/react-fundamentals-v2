useState

Програмування на React не передбачає використання звичайних змінних:

let count = 0;
count = count + 1;

Такий підхід використовується у імперативному програмуванні (у звичайному, наприклад з використанням Java). В компонентах React використовуються «реактивні» змінні. Вони створюються за допомогую хуків. Створити якусь змінну у функціональному комопоненті можна за допомогою хука useState.

Хук useState є одним з вбудованих хуків у React, який використовується для додавання стану (змінних) до функціональних компонентів. Він дозволяє зберігати та оновлювати значення стану в функціональних компонентах, що раніше було можливо тільки з використанням класових компонентів.

Ось приклад використання хука useState у функціональному компоненті:

import React, { useState } from 'react';

const Counter = () => {
  // Використання хука useState для створення стану зі значенням по замовчуванню 0
  const [count, setCount] = useState(0);

  // Функція для збільшення значення лічильника
  const increment = () => {
    setCount(count + 1);
  };

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={increment}>Increment</button>
    </div>
  );
};

export default Counter;

У цьому прикладі ми використовуємо хук useState для створення стану зі значенням по замовчуванню 0. Хук useState повертає масив, де перший елемент - поточне значення стану (count), а другий елемент - функція для оновлення стану (setCount). Ми використовуємо цю функцію setCount для зміни значення стану count при кожному кліку на кнопку.

Таким чином, хук useState дозволяє нам зберігати та оновлювати стан в функціональних компонентах, роблячи їх більш простими та зрозумілими.

Зміна стану компонента змушує його перемальовуватись (rerender), для того щоб відобразити актуальні дані. 

Алгоритм того як думає компонент:

1) Компонент відображує розмітку з початковими даними. «Count: 0». Так, як початкове значення count = 0.

2) Клік по кнопці викликає функцію increment, де в ній викликається setCount(count + 1). Це значить що у setCount (функцію для зміни значення count), ми передаємо поточне значення count збільшене на 1.

3) Компонент розуміє що значення count змінено (count = 1), тому мусить перемалюватися з актуальними даними.

4) Компонент перемальовується і відображує розмітку з актуальними (оновленими) даними. «Count: 1». Так, як значення count = 1.
