useState

Programming in React does not involve using regular variables:

let count = 0;
count = count + 1;

This approach is used in imperative programming (in regular programming, for example using Java). In React components, "reactive" variables are used. They are created using hooks. You can create a variable in a functional component using the useState hook.

The useState hook is one of the built-in hooks in React that is used to add state (variables) to functional components. It allows storing and updating state values in functional components, which was previously only possible using class components.

Here is an example of using the useState hook in a functional component:

import React, { useState } from 'react';

const Counter = () => {
  // Using the useState hook to create state with a default value of 0
  const [count, setCount] = useState(0);

  // Function to increment the counter value
  const increment = () => {
    setCount(count + 1);
  };

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={increment}>Increment</button>
    </div>
  );
};

export default Counter;

In this example, we use the useState hook to create state with a default value of 0. The useState hook returns an array, where the first element is the current state value (count), and the second element is the function to update the state (setCount). We use this setCount function to change the count state value on each button click.

Thus, the useState hook allows us to store and update state in functional components, making them simpler and more understandable.

Changing the component's state forces it to re-render (rerender), in order to display up-to-date data.

The algorithm of how a component thinks:

1) The component displays markup with initial data. "Count: 0". Since the initial value of count = 0.

2) Clicking the button calls the increment function, where setCount(count + 1) is called. This means that in setCount (the function to change the count value), we pass the current count value incremented by 1.

3) The component understands that the count value has changed (count = 1), so it must re-render with up-to-date data.

4) The component re-renders and displays markup with up-to-date (updated) data. "Count: 1". Since the count value = 1.
