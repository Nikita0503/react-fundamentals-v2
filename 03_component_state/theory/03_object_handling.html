Important Aspects of Working with Objects in JavaScript

Object comparison in JavaScript is based on comparing references to objects, not their content.

When we compare two objects using the comparison operator == or the strict comparison operator ===, JavaScript checks whether both operands refer to the same memory area, that is, whether they have the same reference. If the objects have different references, the comparison will return false, even if the content of the objects is the same.

Here is an example of object comparison in JavaScript:

const obj1: { name: string; age: number } = { name: 'John', age: 25 };
const obj2: { name: string; age: number } = { name: 'John', age: 25 };
const obj3 = obj1;

console.log(obj1 == obj2); // false, because obj1 and obj2 have different references
console.log(obj1 === obj2); // false, because obj1 and obj2 have different references

console.log(obj1 == obj3); // true, because obj1 and obj3 have the same reference
console.log(obj1 === obj3); // true, because obj1 and obj3 have the same reference

To compare the content of two objects, you need to compare each field separately. However, you can use object comparison libraries, such as Lodash, for convenient comparison of object content.

By changing values in objects and logging them to the console, we can observe how the content of objects changes and how this affects object comparison:

const obj1: { name: string; age: number } = { name: 'John', age: 25 };
const obj2: { name: string; age: number } = { name: 'John', age: 25 };
const obj3 = obj1;

console.log('obj1:', obj1);
console.log('obj2:', obj2);
console.log('obj3:', obj3);

obj1.age = 30;
console.log('obj1:', obj1); // { name: 'John', age: 30 }
console.log('obj2:', obj2); // { name: 'John', age: 25 }
console.log('obj3:', obj3); // { name: 'John', age: 30 }

console.log(obj1 == obj2); // false, because obj1 and obj2 have different references
console.log(obj1 === obj2); // false, because obj1 and obj2 have different references

console.log(obj1 == obj3); // true, because obj1 and obj3 have the same reference
console.log(obj1 === obj3); // true, because obj1 and obj3 have the same reference

As we can see, changing the value of the age field in obj1 also changes the content of obj3, because they have the same reference. However, this does not affect obj2, because it has its own reference to a different object. Object comparison using == and === also returns expected results according to their references.
