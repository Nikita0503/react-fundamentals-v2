Важливі моменти роботи з об`єктами у javascript

Порівняння об'єктів у JavaScript базується на порівнянні посилань (references) на об'єкти, а не на їхньому вмісті.

Коли ми порівнюємо два об'єкти за допомогою оператора порівняння == або оператора строгого порівняння ===, JavaScript перевіряє, чи посилаються обидва операнди на одну і ту ж область пам'яті, тобто чи мають вони однакове посилання. Якщо об'єкти мають різні посилання, то порівняння поверне false, навіть якщо вміст об'єктів однаковий.

Ось приклад порівняння об'єктів у JavaScript:

const obj1 = { name: 'John', age: 25 };
const obj2 = { name: 'John', age: 25 };
const obj3 = obj1;

console.log(obj1 == obj2); // false, оскільки obj1 та obj2 мають різні посилання
console.log(obj1 === obj2); // false, оскільки obj1 та obj2 мають різні посилання

console.log(obj1 == obj3); // true, оскільки obj1 та obj3 мають однакові посилання
console.log(obj1 === obj3); // true, оскільки obj1 та obj3 мають однакові посилання

Щоб порівняти вміст двох об'єктів, потрібно порівняти кожне поле окремо. Однак, можна використовувати бібліотеки порівняння об'єктів, як наприклад Lodash, для зручного порівняння вмісту об'єктів.

Змінюючи значення в об'єктах та виводячи їх у консоль, ми можемо спостерігати, як змінюється вміст об'єктів та як це впливає на порівняння об'єктів:

const obj1 = { name: 'John', age: 25 };
const obj2 = { name: 'John', age: 25 };
const obj3 = obj1;

console.log('obj1:', obj1);
console.log('obj2:', obj2);
console.log('obj3:', obj3);

obj1.age = 30;
console.log('obj1:', obj1); // { name: 'John', age: 30 }
console.log('obj2:', obj2); // { name: 'John', age: 25 }
console.log('obj3:', obj3); // { name: 'John', age: 30 }

console.log(obj1 == obj2); // false, оскільки obj1 та obj2 мають різні посилання
console.log(obj1 === obj2); // false, оскільки obj1 та obj2 мають різні посилання

console.log(obj1 == obj3); // true, оскільки obj1 та obj3 мають однакові посилання
console.log(obj1 === obj3); // true, оскільки obj1 та obj3 мають однакові посилання

Як бачимо, зміна значення поля age у obj1 також змінює вміст obj3, оскільки вони мають однакове посилання. Однак, це не впливає на obj2, оскільки він має власне посилання на інший об'єкт. Порівняння об'єктів за допомогою == та === також повертає очікувані результати відповідно до їхніх посилань.
