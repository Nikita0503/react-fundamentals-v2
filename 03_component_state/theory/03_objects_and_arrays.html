Reference Equality

React compares old and new state with Object.is(). For objects and arrays, this means comparing the reference (memory address), not the content:

  • Same reference → no re-render (React thinks nothing changed)
  • New reference → re-render (even if content is identical)

Rule: never mutate state directly. Always create a new object or array.

Updating Objects — Use Spread Operator

type User = { name: string; email: string; age: number };
const [user, setUser] = useState<User>({ name: "Alice", email: "alice@test.com", age: 25 });

// ❌ Mutation — won't trigger re-render
user.name = "Bob";
setUser(user); // same reference!

// ✅ New object with spread
setUser({ ...user, name: "Bob" });

// or with functional updater:
setUser(prev => ({ ...prev, name: "Bob" }));

The spread operator (...) copies all properties into a new object. Properties listed after the spread override the copied ones.

Updating Nested Objects

When objects are nested, you must spread at every level that contains a change:

type Profile = { name: string; address: { city: string; zip: string } };
const [profile, setProfile] = useState<Profile>({
  name: "Alice",
  address: { city: "NYC", zip: "10001" },
});

// ✅ Spread at every level
setProfile(prev => ({
  ...prev,
  address: { ...prev.address, city: "LA" },
}));

If you only spread the top level and directly assign a nested property, the nested object is still the same reference — React won't detect the change.

Updating Arrays — Common Operations

type Todo = { id: number; text: string; done: boolean };
const [todos, setTodos] = useState<Todo[]>([]);

// Add item
setTodos(prev => [...prev, { id: Date.now(), text: "New todo", done: false }]);

// Remove item by id
setTodos(prev => prev.filter(todo => todo.id !== idToRemove));

// Update one item (toggle done)
setTodos(prev => prev.map(todo =>
  todo.id === idToToggle ? { ...todo, done: !todo.done } : todo
));

// Replace entire array
setTodos(newTodos);

All of these create a new array — they never modify the existing one in place.
