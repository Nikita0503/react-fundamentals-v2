useEffect Syntax

The useEffect hook takes two parameters: an effect function and a dependency array.

useEffect(() => {
  // effect logic (runs after render)
  return () => {
    // cleanup (optional — runs before next effect or unmount)
  };
}, [dependencies]);

Three Dependency Patterns

1. Empty array [] — run once after mount

useEffect(() => {
  console.log("Component mounted");
  // Fetch initial data, set up subscriptions, etc.
}, []);

Use for: initial data fetching, one-time setup.

2. With dependencies [dep1, dep2] — run when dependencies change

const [userId, setUserId] = useState("1");

useEffect(() => {
  fetch(`/api/users/${userId}`)
    .then(res => res.json())
    .then(data => setUser(data));
}, [userId]); // re-runs when userId changes

Use for: reacting to state/prop changes, re-fetching data.

3. No array (omitted) — run after EVERY render

useEffect(() => {
  console.log("Rendered!"); // runs on mount AND every update
});

Use for: rarely needed. Debugging, or effects that truly need to sync on every render.

How React Decides When to Run the Effect

  • After every render, React compares current dependencies with previous ones (using Object.is)
  • If any dependency changed → run the effect
  • If none changed → skip the effect

Multiple useEffects

You can (and should) have multiple useEffect calls in one component, each handling a separate concern:

type User = {
  id: string;
  name: string;
  email: string;
};

const UserProfile = ({ userId }: { userId: string }) => {
  const [user, setUser] = useState<User | null>(null);
  const [isOnline, setIsOnline] = useState(false);

  // Effect 1: fetch user data
  useEffect(() => {
    fetch(`/api/users/${userId}`)
      .then(res => res.json())
      .then(data => setUser(data));
  }, [userId]);

  // Effect 2: subscribe to online status
  useEffect(() => {
    const ws = new WebSocket(`/ws/status/${userId}`);
    ws.onmessage = (e) => setIsOnline(JSON.parse(e.data).online);
    return () => ws.close();
  }, [userId]);

  return (
    <div>
      <h1>{user?.name}</h1>
      <span>{isOnline ? "Online" : "Offline"}</span>
    </div>
  );
};

Each effect is independent — easier to understand, test, and maintain. Don't combine unrelated logic into a single useEffect.
