useEffect

React дозволяє взаємодіяти з етапами життя компоненту. Тобто виконувати якийсь код під час цих етапів. Для цього React надає хук useEffect.

useEffect є одним з хуків в React, який дозволяє виконувати ефекти, тобто виконувати дії, які повинні відбутися після рендерингу компонента.

Він може бути використаний для взаємодії з зовнішніми ресурсами, такими як REST API-запити, підписка на події, маніпуляції з DOM, таймери, та багато іншого.

Синтаксис використання useEffect виглядає наступним чином:

useEffect(() => {
  // Логіка ефекту
}, []); //масив залежностей

useEffect приймає в себе 2 параметри:

  • Функція, яка виконується, коли ефект викликається
  • Масив залежностей, від якого залежуть виклики ефекту

У прикладі вище масив залежностей пустий. Це значить що ефект (тобто функція, яка надана першим параметром) буде викликаний 1 раз - після першого рендеру (першої відмальовки компоненту).

Такий підхід використовують як раз для запитів до REST API, встановлення таймерів, підписок на події і так далі. Приклад:

import React, { useState, useEffect } from "react";

const ExampleComponent = () => {
  const [data, setData] = useState(null);

  useEffect(() => {
    // Виконання запиту до API
    fetch("https://api.example.com/data")
      .then(response => response.json())
      .then(result => setData(result))
      .catch(error => console.error("Помилка під час отримання даних:", error));
  }, []); // Порожній масив залежностей - ефект виконується 1 раз, тільки після монтування компонента

  return (
    <div>
      {data && (
        // Відображення даних з API, якщо вони отримані
        <p>Дані з API: {data}</p>
      )}
    </div>
  );
};

export default ExampleComponent;

У цьому прикладі, дані з API отримуються в useEffect і зберігаються у стані компонента за допомогою функції setData. Якщо дані успішно отримані, вони відображаються в компоненті у вигляді текстового повідомлення. В іншому випадку, компонент не відображає нічого.

Як компонент думає в цьому разі:

  • Відмалювати компонент з початковими даними. Так як data = null, то компонент поверне пустий div.
  • Викликати useEffect, де виконується запит до REST API
  • Результат виклику помістити у змінну data, за допомогою setData. Тобто, оновити стан компоненту.
  • Відмалювати компонент з актуальними (оновленими) даними.

Логіка у JSX (у розмітці) де перевіряється чи містить data дані (data && … ), якщо так, то поверне

"<div><p>Дані з API: «дані»</p></div&gt"

або якщо ні, то поверне

"<div></div>"

Це називається «умовний рендеринг».

useEffect у такому виконанні, де масив залежностей пустий, буде викликано 1 раз за весь життєвий цикл компоненту.

Це аналог реалізації методу життєвого циклу componentDidMount класового компоненту, тільки у функціональому компоненті.

*Якщо у useEffect другим параметром не передавати масив залежностей, тобто передати тільки функцію першим параметром, то цей ефект буде викликатися після кожного рендеру компоненту.

Реалізуємо метод componentDidUpdate класового компоненту у функціональному компоненті, за допомогою useEffect.

componentDidUpdate є одним з методів життєвого циклу компонента в класових компонентах React, який викликається після оновлення компонента.

У функціональних компонентах, еквівалентним для componentDidUpdate є використання useEffect разом з відповідними залежностями:

import React, { useState, useEffect } from "react";

const Counter = () => {
  // Використання хука useState для створення стану зі значенням 0
  const [count, setCount] = useState(0);

  // Функція для збільшення значення лічильника
  const increment = () => {
    // Використання функції setCount з передачею нового значення стану
    setCount(count + 1);
  };

  // Використання useEffect для виконання певної логіки після оновлення компонента
  useEffect(() => {
    console.log("Значення count змінилося:", count);
  }, [count]); // Залежність від значення count

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={increment}>Increment</button>
    </div>
  );
};

export default Counter;

У цьому прикладі useEffect виконується після кожної зміни count.

В проектах, така реалізація useEffect використовується в якості реакції на зміни даних для виклику інших функцій або оновлення логіки відображення компоненту.

Останній метод життєвого циклу, з яким вміє працювати useEffect, у класовому компоненті називається componentWillUnmount. Він викликається під час демонтування компонента з DOM (знищення):

import React, { useState, useEffect } from "react";

const Counter = () => {
  // Використання хука useState для створення стану
  const [count, setCount] = useState(0);

  // Ефект, що виконується при монтуванні компонента
  useEffect(() => {
    // Код, що виконується при монтуванні компонента
    console.log("Component mounted");

    // Функція очищення, що виконується перед видаленням компонента з DOM
    return () => {
      // Код, що виконується перед знищенням компонента
      console.log("Component unmounted");
      setCount(0);
    };
  }, []); // Порожній масив залежностей означає, що ефект виконується тільки при монтуванні та розмонтуванні компонента

  // Функція для збільшення значення лічильника
  const increment = () => {
    setCount(count + 1);
  };

  // Рендер компонента
  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={increment}>Increment</button>
    </div>
  );
};

export default Counter;

У цьому прикладі, функція очищення буде виконана при знищенні компонента, вона встановить значення count на 0. Функція очищення мусить повертатися (в return) з функції, котра була передана в useEffect першим параметром.

У проектах таку реалізацію useEffect використовують дуже часто для роботи з підписками на події:

import React, { useState, useEffect } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0);

  useEffect(() => {
    // Функція-підписка на подію
    const handleClick = () => {
      setCount(count + 1);
    };

    // Додаємо прослуховувач події при монтуванні компонента
    document.addEventListener('click', handleClick);

    // Функція очищення, яка виконається перед знищенням компонента
    return () => {
      // Відписуємося від події при знищенні компонента
      document.removeEventListener('click', handleClick);
    };
  }, []);

  return (
    <div>
      <p>Count: {count}</p>
    </div>
  );
};

export default Counter;

Кількість useEffect у компоненті необмежена. Можна використовувати стільки, скільки потрібно. Але це потрібно робити уважно, щоб компонент мав очевидну поведінку та не було зайвого навантаження на браузер.
