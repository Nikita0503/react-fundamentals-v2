useEffect

React allows you to interact with the stages of a component's life. That is, to execute some code during these stages. For this, React provides the useEffect hook.

useEffect is one of the hooks in React that allows you to perform effects, that is, to perform actions that should happen after the component renders.

It can be used to interact with external resources, such as REST API requests, event subscriptions, DOM manipulations, timers, and much more.

The syntax for using useEffect looks as follows:

useEffect(() => {
  // Effect logic
}, []); // dependency array

useEffect accepts 2 parameters:

  • Function that is executed when the effect is called
  • Dependency array on which the effect calls depend

In the example above, the dependency array is empty. This means that the effect (i.e., the function provided as the first parameter) will be called 1 time - after the first render (first drawing of the component).

This approach is used precisely for REST API requests, setting timers, event subscriptions, and so on. Example:

// ExampleComponent.tsx
import React, { useState, useEffect } from "react";

const ExampleComponent = () => {
  const [data, setData] = useState<string | null>(null);

  useEffect(() => {
    // Making a request to the API
    fetch("https://api.example.com/data")
      .then(response => response.json())
      .then((result: string) => setData(result))
      .catch(error => console.error("Error while fetching data:", error));
  }, []); // Empty dependency array - effect runs 1 time, only after component mounts

  return (
    <div>
      {data && (
        // Displaying data from API if received
        <p>Data from API: {data}</p>
      )}
    </div>
  );
};

export default ExampleComponent;

In this example, data from the API is fetched in useEffect and stored in the component's state using the setData function. If the data is successfully received, it is displayed in the component as a text message. Otherwise, the component displays nothing.

How the component thinks in this case:

  • Render the component with initial data. Since data = null, the component will return an empty div.
  • Call useEffect, where a REST API request is made
  • Place the result of the call into the data variable using setData. That is, update the component's state.
  • Render the component with up-to-date (updated) data.

The logic in JSX (in the markup) where it checks whether data contains data (data && … ), if yes, it will return

"<div><p>Data from API: «data»</p></div&gt"

or if no, it will return

"<div></div>"

This is called "conditional rendering".

useEffect in this implementation, where the dependency array is empty, will be called 1 time during the entire lifecycle of the component.

This is the equivalent of implementing the componentDidMount lifecycle method of a class component, but in a functional component.

*If you do not pass a dependency array as the second parameter to useEffect, that is, pass only the function as the first parameter, then this effect will be called after every render of the component.

Let's implement the componentDidUpdate method of a class component in a functional component using useEffect.

componentDidUpdate is one of the lifecycle methods of a component in React class components, which is called after the component updates.

In functional components, the equivalent of componentDidUpdate is using useEffect with corresponding dependencies:

// Counter.tsx
import React, { useState, useEffect } from "react";

const Counter = () => {
  // Using the useState hook to create state with value 0
  const [count, setCount] = useState(0);

  // Function to increment the counter value
  const increment = () => {
    // Using the setCount function passing a new state value
    setCount(count + 1);
  };

  // Using useEffect to execute certain logic after the component updates
  useEffect(() => {
    console.log("The count value has changed:", count);
  }, [count]); // Dependency on the count value

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={increment}>Increment</button>
    </div>
  );
};

export default Counter;

In this example, useEffect executes after every change to count.

In projects, this implementation of useEffect is used as a reaction to data changes to call other functions or update the component's display logic.

The last lifecycle method that useEffect can work with, in a class component is called componentWillUnmount. It is called when the component is unmounted from the DOM (destroyed):

// Counter.tsx
import React, { useState, useEffect } from "react";

const Counter = () => {
  // Using the useState hook to create state
  const [count, setCount] = useState(0);

  // Effect that runs when the component mounts
  useEffect(() => {
    // Code that runs when the component mounts
    console.log("Component mounted");

    // Cleanup function that runs before the component is removed from the DOM
    return () => {
      // Code that runs before the component is destroyed
      console.log("Component unmounted");
      setCount(0);
    };
  }, []); // Empty dependency array means the effect runs only on mount and unmount

  // Function to increment the counter value
  const increment = () => {
    setCount(count + 1);
  };

  // Render the component
  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={increment}>Increment</button>
    </div>
  );
};

export default Counter;

In this example, the cleanup function will be executed when the component is destroyed, it will set the count value to 0. The cleanup function must be returned (in return) from the function that was passed to useEffect as the first parameter.

In projects, this implementation of useEffect is very often used for working with event subscriptions:

// Counter.tsx
import React, { useState, useEffect } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0);

  useEffect(() => {
    // Event subscription function
    const handleClick = () => {
      setCount(count + 1);
    };

    // Adding an event listener when the component mounts
    document.addEventListener('click', handleClick);

    // Cleanup function that runs before the component is destroyed
    return () => {
      // Unsubscribing from the event when the component is destroyed
      document.removeEventListener('click', handleClick);
    };
  }, []);

  return (
    <div>
      <p>Count: {count}</p>
    </div>
  );
};

export default Counter;

The number of useEffect hooks in a component is unlimited. You can use as many as needed. But this should be done carefully so that the component has predictable behavior and there is no unnecessary load on the browser.
