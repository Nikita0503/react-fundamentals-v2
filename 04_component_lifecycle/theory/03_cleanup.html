What is Cleanup?

Cleanup is the function returned from useEffect. It "undoes" what the effect set up — removes event listeners, clears timers, closes connections, cancels requests.

When Cleanup Runs

  • Before the component unmounts (removed from DOM)
  • Before the effect re-runs (when dependencies change) — this is often missed!

Why cleanup matters: without it, you get memory leaks, stale subscriptions, and bugs where removed components still try to update state.

Example 1: Event Listeners

useEffect(() => {
  const handleResize = () => {
    setWidth(window.innerWidth);
  };
  window.addEventListener("resize", handleResize);

  return () => {
    window.removeEventListener("resize", handleResize); // cleanup!
  };
}, []);

Example 2: Timers

useEffect(() => {
  const intervalId = setInterval(() => {
    setSeconds(prev => prev + 1);
  }, 1000);

  return () => {
    clearInterval(intervalId); // cleanup!
  };
}, []);

Example 3: Fetch with AbortController

Prevents setting state on an unmounted component:

useEffect(() => {
  const controller = new AbortController();

  fetch(`/api/users/${userId}`, { signal: controller.signal })
    .then(res => res.json())
    .then(data => setUser(data))
    .catch(err => {
      if (err.name !== "AbortError") {
        setError("Failed to fetch");
      }
    });

  return () => {
    controller.abort(); // cancel the request if component unmounts or userId changes
  };
}, [userId]);

Cleanup on Dependency Change

This is important to understand — cleanup doesn't only run on unmount:

useEffect(() => {
  const ws = new WebSocket(`/ws/chat/${roomId}`);
  ws.onmessage = (e) => addMessage(JSON.parse(e.data));

  return () => {
    ws.close(); // close OLD connection before opening new one
  };
}, [roomId]); // when roomId changes: cleanup old → run new

Sequence when roomId changes:

  1. Cleanup runs → closes the old WebSocket connection
  2. Effect runs → opens a new WebSocket connection with the new roomId

The Rule

If your effect sets up something (subscription, timer, connection), it should clean it up. Always ask yourself: "What happens if this component disappears or this dependency changes? Will something be left dangling?"
