Component Lifecycle

Functional components in React have their own "lifecycle" (component lifecycle) - this is a sequence of phases that a component goes through from the moment of its creation to the moment of its removal from the DOM tree. It is important to note that with the introduction of hooks in React 16.8, the lifecycle of functional components became simpler and more understandable.

The main phases of the lifecycle of a functional component in React using hooks are:

Mounting phase (mounting) - this is when a new component is created and inserted into the DOM, or in other words, when the component's life begins. This can only happen once and is often called the "initial render".

Updating phase (updating) — this is when the component is updated or re-rendered (re-renders). This reaction is triggered when props are updated (we will look at props later) or when the state is updated. This phase can repeat multiple times, which is the essence of React.

Unmounting / destruction (unmounting) - The last stage of the component lifecycle is removal from the DOM.
