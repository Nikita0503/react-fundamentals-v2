Життєвий цикл компонента

Функціональні компоненти в React мають свій "життєвий цикл" (component lifecycle) - це послідовність фаз, через які проходить компонент від моменту його створення до моменту його видалення з DOM-дерева. Важливо зазначити, що з введенням хуків у React 16.8, життєвий цикл функціональних компонентів став більш простим та зрозумілим.

Основні фази життєвого циклу функціонального компонента в React з використанням хуків такі:

Фаза монтування / створення (mounting) - це коли новий компонент створюється та вставляється в DOM або, іншими словами, коли починається життя компонента. Це може статися лише один раз і часто називається «початковим рендером».

Етап оновлення (updating) — це коли компонент оновлюється або повторно відображається (ререндери). Ця реакція запускається, коли оновлюються реквізити (props - далі розглянемо) або коли оновлюється стан. Ця фаза може повторюватися кілька разів, у чому полягає суть React.

Демонтування / знищення (unmounting) - Останнім етапом життєвого циклу компонента є видалення з DOM.
