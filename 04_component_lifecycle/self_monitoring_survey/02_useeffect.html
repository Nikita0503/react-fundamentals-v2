How does useEffect work in React, and what parameters does it accept?


( ) useEffect is called only during component mounting and on every update, does not accept parameters.
(x) useEffect allows performing effects after the component renders. It accepts two parameters: a function containing the effect logic, and a dependency array on which the effect call depends.
( ) useEffect is intended only for making HTTP requests.

How to use useEffect for interacting with REST API in React?


( ) useEffect only interacts with the local state of the component, it is not intended for working with external resources.
( ) When using useEffect with REST API, you do not need to pass a dependency array, as this can lead to errors.
(x) useEffect can be used to interact with REST API, specifying the resource URL and setting the received data into the component's state.

How is useEffect used to emulate the componentDidUpdate method in React functional components?


( ) useEffect cannot emulate the componentDidUpdate method in functional components.
( ) To emulate componentDidUpdate, a separate useDidUpdate hook is used, since useEffect is intended only for componentDidMount.
(x) useEffect can emulate componentDidUpdate if you specify dependencies on which the effect call depends, for example, [count] for updating when count changes.

How to use useEffect to emulate the componentWillUnmount method in React functional components?


( ) useEffect cannot emulate the componentWillUnmount method in functional components.
( ) To emulate componentWillUnmount, a separate useWillUnmount hook is used, since useEffect is intended only for componentDidMount and componentDidUpdate.
(x) useEffect can emulate componentWillUnmount if the function it returns contains cleanup logic, for example, unsubscribing from events or cleaning up resources.
