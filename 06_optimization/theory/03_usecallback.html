useCallback

useCallback is a hook in React that allows you to cache a memoized version of a function between component renders.

The main idea of useCallback is that it returns a memoized version of the function that will remain the same on every component render, as long as none of the dependencies in the dependency array change.

This allows you to avoid unnecessary creation of new functions on every component render, which can happen in some cases when we pass functions as props to child components.

So, the main advantages of using useCallback include:

  • Performance optimization: Using useCallback helps avoid unnecessary re-renders of child components, since functions will not be recreated on every render of the parent component.
  • Ensuring reference stability: Memoizing functions with useCallback allows you to guarantee the stability of references to these functions. This can be useful in cases where we pass these functions as props to child components that are also memoized with React.memo.

So, here is an example of using useCallback:

import React, { useState, useCallback } from 'react';
import ChildComponent from './ChildComponent';

const ParentComponent = () => {
  const [count, setCount] = useState(0);

  // Declare a click handler function using useCallback,
  // passing the dependency [count]
  const handleClick = useCallback(() => {
    console.log('Click handler function is called');
    setCount(count + 1);
  }, [count]);

  return (
    <div>
      <h1>Counter: {count}</h1>
      {/* Pass the handler function as a prop to the child component */}
      <ChildComponent handleClick={handleClick} />
    </div>
  );
};

export default ParentComponent;

// Using React.memo to memoize the child component
// This allows avoiding unnecessary re-renders when props don't change
import React from 'react';

const ChildComponent = ({ handleClick }) => {
  console.log('Child component renders');
  return (
    <button onClick={handleClick}>Increment</button>
  );
};

export default React.memo(ChildComponent);

In this example, we use useCallback to cache the handleClick function, which is a button click handler function. The dependency array [count] indicates that the function should be updated if the count value changes (a variable stored in the parent component's state).

The child component ChildComponent is also memoized with React.memo, which helps avoid unnecessary re-renders, since we pass a stable handleClick function as a prop that does not change (the reference to it remains the same) on every render of ParentComponent.
