useCallback

useCallback є хуком в React, який дозволяє кешувати мемоізовану версію функції між рендерами компонента.

Основна ідея useCallback полягає в тому, що він повертає мемоїзовану версію функції, яка буде однаковою при кожному рендері компонента, поки не зміниться жодна залежність з масиву залежностей.

Це дозволяє уникнути непотрібного створення нових функцій при кожному рендері компонента, що може відбуватись в деяких випадках, коли ми передаємо функції як пропси до дочірніх компонентів.

Отже, основні переваги використання useCallback включають:

  • Оптимізація продуктивності: Використання useCallback допомагає уникнути зайвих рендерів дочірніх компонентів, оскільки функції не будуть перестворюватись при кожному рендері батьківського компонента.
  • Забезпечення стабільності посилань: Мемоїзація функцій за допомогою useCallback дозволяє гарантувати стабільність посилань на ці функції. Це може бути корисним у випадках, коли ми передаємо ці функції як пропси в дочірні компоненти, що також мемоїзовані за допомогою React.memo.

Отже, ось приклад використання useCallback:

import React, { useState, useCallback } from 'react';
import ChildComponent from './ChildComponent';

const ParentComponent = () => {
  const [count, setCount] = useState(0);

  // Оголошуємо функцію-обробник кліку з використанням useCallback,
  // передаємо залежність [count]
  const handleClick = useCallback(() => {
    console.log('Функція-обробник кліку викликається');
    setCount(count + 1);
  }, [count]);

  return (
    <div>
      <h1>Лічильник: {count}</h1>
      {/* Передаємо функцію-обробник як пропс до дочірнього компонента */}
      <ChildComponent handleClick={handleClick} />
    </div>
  );
};

export default ParentComponent;

// Використовуємо React.memo для мемоїзації дочірнього компонента
// Що дозволяє уникнути зайвих рендерів при зміні пропсів, якщо вони не змінюються
import React from 'react';

const ChildComponent = ({ handleClick }) => {
  console.log('Дочірній компонент рендериться');
  return (
    <button onClick={handleClick}>Збільшити</button>
  );
};

export default React.memo(ChildComponent);

У цьому прикладі ми використовуємо useCallback для кешування функції handleClick, яка є функцією-обробником кліку кнопки. Масив залежностей [count] вказує, що функція повинна бути оновлена, якщо змінюється значення count (змінна, що зберігається в стані батьківського компонента).

Дочірній компонент ChildComponent також мемоїзований за допомогою React.memo, що допомагає уникнути зайвих рендерів, оскільки ми передаємо стабільну функцію handleClick як пропс, яка не змінюється (посилання на неї однакове) при кожному рендері ParentComponent.
