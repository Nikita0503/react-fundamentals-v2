React.memo

Зважаючи на правила перемальовки компонентів у React напрошується цілком нормальне питання - «чи можна запобігти зайвих перемальовок, якимось чином?». Відповідь - так, можна. Для цього використовують React.memo.

React.memo - це вбудована функція в бібліотеці React, яка надає можливість оптимізувати процес ререндерингу компонентів. Вона дозволяє кешувати результати рендерингу компонентів і перерендерювати їх лише при зміні вхідних властивостей (props).

Коли ви використовуєте React.memo для обгортання функціонального компонента, React автоматично перевіряє вхідні props компонента під час рендерингу. Якщо значення вхідних props не змінюються, React повторно використовує кешований результат рендерингу компонента замість виконання повторного рендерингу. Це може допомогти уникнути зайвих рендерів і покращити продуктивність додатку.

Основний синтаксис використання React.memo виглядає наступним чином:

import React from 'react';

const MyComponent = (props) => {
  // Код компонента
};

export default React.memo(MyComponent);

Застосування React.memo може бути корисним, коли ви маєте компонент, який необхідно перерендерювати тільки при зміні певних вхідних props, а інші властивості компонента залишаються незмінними. Це може бути корисно, наприклад, коли ви маєте великі списки компонентів або вкладені компоненти, і ви хочете уникнути зайвих рендерів, які можуть впливати на продуктивність додатку.

Приклад використання React.memo з двома вхідними props, але компонент буде перерендерюватись тільки при зміні одного з цих пропсів:

import React from 'react';

const MyComponent = ({ prop1, prop2 }) => {
  // Код компонента

  return (
    <div>
      {/* Використовуємо значення prop1 */}
      <p>Prop1: {prop1}</p>
      {/* Використовуємо значення prop2 */}
      <p>Prop2: {prop2}</p>
    </div>
  );
};

// Використовуємо React.memo для оптимізації рендерингу
export default React.memo(MyComponent, (prevProps, nextProps) => {
  // Перевіряємо, чи змінився тільки prop1, а prop2 залишився незмінним
  return prevProps.prop1 === nextProps.prop1;
});

У цьому прикладі React.memo використовується для оптимізації рендерингу компонента MyComponent. Він приймає два аргументи: перший - це сам компонент, а другий - це функція порівняння (compare function). Функція порівняння приймає два аргументи - prevProps і nextProps, які представляють попередні та наступні значення props відповідно.

У прикладі функція порівняння перевіряє, чи змінився тільки prop1, а prop2 залишився без перевірки. Якщо так, то React.memo повторно використовує кешований результат рендерингу компонента, і не виконує повторного рендерингу, що допомагає уникнути зайвих операцій рендерингу.

Тобто, якщо prop2 буде змінено, то це не вплине на рендер компонента. Компонент MyComponent буде перерендерюватись лише при зміні prop1, оскільки функція порівняння в React.memo порівнює лише значення prop1 між попередніми та наступними вхідними пропсами. У цьому випадку prop2 не впливає на результат.

Це може бути корисною оптимізацією в деяких випадках, коли ви хочете уникнути непотрібного перерендерингу компонента, якщо зміни в деяких props не впливають на візуальний вигляд або поведінку компонента.

Однак, слід бути обережним з використанням React.memo, оскільки неправильне використання може призвести до некоректної роботи компонентів, особливо коли вони взаємодіють зі станом або змінюють його.
