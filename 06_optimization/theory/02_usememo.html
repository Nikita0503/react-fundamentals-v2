useMemo

В React є можливість оптимізувати компоненти також з середини.

useMemo - це хук в React, який дозволяє оптимізувати рендеринг компонентів, запобігти непотрібних перерахувань.

useMemo використовується для кешування результатів обчислень і повертає закешоване значення, якщо вхідні залежності не змінилися. Це може бути корисним, коли у вас є обчислювально важкі операції, такі як обчислення даних або виклик зовнішнього API, які не потрібно робити при кожному рендері компонента.

Ось приклад використання useMemo:

import React, { useMemo } from 'react';

const MyComponent = ({ a, b }) => {
  // Використання useMemo для кешування результату обчислення
  const result = useMemo(() => {
    console.log('Результат обчислення');
    return a + b;
  }, [a, b]); // Залежності, на основі яких буде виконано повторне обчислення

  return (
    <div>
      <p>Результат: {result}</p>
    </div>
  );
};

export default MyComponent;

useMemo першим параметром приймає функцію, яка мусить повернути результат обчислень, другим параметром - масив залежностей.

Коли будь-яка змінна в масиві змінюється, useMemo виконає функцію знову та оновить кешований результат. У випадку, коли всі змінні в масиві залежностей залишаються незмінними між рендерами, useMemo поверне закешований результат без виконання функції обчислення заново.
