useMemo

In React, there is also the ability to optimize components from the inside.

useMemo is a hook in React that allows you to optimize component rendering and prevent unnecessary recalculations.

useMemo is used to cache the results of computations and returns the cached value if the input dependencies have not changed. This can be useful when you have computationally expensive operations, such as data calculations or external API calls, that do not need to be performed on every component render.

Here is an example of using useMemo:

import React, { useMemo } from 'react';

type MyComponentProps = {
  a: number;
  b: number;
};

const MyComponent = ({ a, b }: MyComponentProps) => {
  // Using useMemo to cache the computation result
  const result = useMemo(() => {
    console.log('Computing result');
    return a + b;
  }, [a, b]); // Dependencies based on which recalculation will be performed

  return (
    <div>
      <p>Result: {result}</p>
    </div>
  );
};

export default MyComponent;

useMemo accepts a function as its first parameter, which must return the computation result, and a dependency array as its second parameter.

When any variable in the array changes, useMemo will execute the function again and update the cached result. In the case when all variables in the dependency array remain unchanged between renders, useMemo will return the cached result without executing the computation function again.
