What is useMemo and how can it optimize component rendering in React?


( ) useMemo is a way to automatically cache all component rendering results in an application, ensuring a high level of performance. (x) useMemo is a hook in React that allows optimizing component rendering and preventing unnecessary recalculations. ( ) Using useMemo always leads to a complete stop of recalculations and component rendering, regardless of input dependencies. ( ) useMemo provides caching of component rendering results, making rendering instant in all cases.

How is useMemo used to cache computation results in React components?


( ) useMemo accepts two functions: the first is a function that determines how to cache the result, and the second is a function that computes the result. ( ) useMemo is used by passing it a function that computes the result and a dependency array based on which caching occurs. (x) useMemo accepts a function that must return the computation result and a dependency array, upon changes to which recalculation occurs.

When can using useMemo be particularly important?


( ) Using useMemo is not important because React automatically optimizes component rendering. (x) Using useMemo is important when you have computationally expensive operations that do not need to be performed on every component render. ( ) Using useMemo is always important because it allows avoiding any recalculations in components. ( ) The importance of using useMemo depends on the size and complexity of components, and it is always the same for all cases.
