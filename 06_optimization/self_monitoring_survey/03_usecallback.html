Що таке useCallback і як воно може оптимізувати рендеринг компонентів в React?


(x) useCallback є хуком в React, який дозволяє кешувати мемоізовану версію функції між рендерами компонента, уникнути зайвих рендерів та забезпечити стабільність посилань на функції. ( ) useCallback призначено для автоматичної оптимізації всіх функцій в додатку, забезпечуючи високий рівень продуктивності. ( ) Використання useCallback завжди призводить до створення нових функцій при кожному рендері компонента, незалежно від змін у залежностях.

Коли використання useCallback може бути особливо важливим?


(x) Важливе використання useCallback, коли у вас є функції, які передаються як пропси до дочірніх компонентів, і ви хочете уникнути непотрібного створення нових функцій при кожному рендері батьківського компонента. ( ) Використання useCallback не є важливим, оскільки React автоматично оптимізує рендеринг компонентів. ( ) Важливість використання useCallback залежить від розміру та складності компонентів, і вона завжди однакова для всіх випадків.

У якому варіанті синтаксис використання useCallback є вірним?


Варіант 1: 
const fetchData = () => {
  // Логіка отримання даних
};

Варіант 2: 
const fetchData = useCallback(() => {
  // Логіка отримання даних
}, []);

Варіант 3: 
const fetchData = useCallback(() => {
  // Логіка отримання даних
});
