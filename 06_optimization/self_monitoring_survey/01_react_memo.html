Що таке React.memo і як воно може оптимізувати рендеринг компонентів в React?


(x) React.memo є вбудованою функцією в бібліотеці React, яка дозволяє кешувати результати рендерингу компонентів і перерендерювати їх лише при зміні вхідних властивостей (props). ( ) React.memo застосовується для автоматичної оптимізації всіх компонентів у додатку, незалежно від їхньої структури та логіки рендерингу. ( ) React.memo слід використовувати тільки для класових компонентів, а для функціональних краще використовувати PureComponent.

У якому випадку застосування React.memo може бути особливо корисним?


( ) React.memo застосовується тільки для класових компонентів у React. ( ) React.memo корисний лише для компонентів зі станом. (x) Застосування React.memo може бути корисним, коли ви маєте компонент, який потрібно перерендерювати тільки при зміні певних вхідних props, а інші властивості залишаються незмінними.

Як виглядає основний синтаксис використання React.memo для оптимізації компонентів?


Варіант 1: 
import MyComponent from 'react';

Варіант 2: 
import React from 'react'; 
const MyComponent = (props) => { /* код компонента */ }; 
export default React.memo(MyComponent);

Варіант 3: 
import React from 'react';
const MyComponent = (props) => { /* код компонента */ };
export MyComponent;

( ) Варіант 1 (x) Варіант 2 ( ) Варіант 3

Коли використання функції порівняння в React.memo є особливо важливим?


( ) Використання функції порівняння не є важливим, оскільки React.memo завжди автоматично оптимізує рендеринг компонентів. (x) Використання функції порівняння важливе, коли ви хочете точно контролювати, які властивості повинні призводити до перерендерення компонента. ( ) Функцію порівняння слід використовувати завжди, оскільки це дозволяє зробити рендеринг компонентів максимально оптимізованим. ( ) Важливість використання функції порівняння залежить від типу компонента: для функціональних вона обов'язкова, а для класових - ні.
