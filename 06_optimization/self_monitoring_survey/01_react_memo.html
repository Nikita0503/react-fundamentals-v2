What is React.memo and how can it optimize component rendering in React?


(x) React.memo is a built-in function in the React library that allows caching component rendering results and re-rendering them only when input properties (props) change. ( ) React.memo is used to automatically optimize all components in an application, regardless of their structure and rendering logic. ( ) React.memo should only be used for class components, while for functional components it is better to use PureComponent.

In which case can using React.memo be particularly useful?


( ) React.memo is only used for class components in React. ( ) React.memo is useful only for components with state. (x) Using React.memo can be useful when you have a component that needs to re-render only when certain input props change, while other properties remain unchanged.

When is using the comparison function in React.memo particularly important?


( ) Using the comparison function is not important because React.memo always automatically optimizes component rendering. (x) Using the comparison function is important when you want to precisely control which properties should trigger a component re-render. ( ) The comparison function should always be used because it allows making component rendering as optimized as possible. ( ) The importance of using the comparison function depends on the component type: for functional components it is mandatory, and for class components it is not.
