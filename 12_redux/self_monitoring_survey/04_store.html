Що є основною функцією функції combineReducers в Redux?


( ) Збірка усіх Actions в один об'єкт ( ) Створення екземпляра Store (x) Об'єднання усіх Reducers в один rootReducer

Чому ключі у об'єкті, що передається в combineReducers, є важливими в Redux?


( ) Для додавання додаткових полів у Store (x) Ключі вказують, як звертатися до різних Reducers у Store, наприклад, state.user.name ( ) Для перевірки наявності Reducers в додатку

Чому не рекомендовано змінювати Store напряму в Redux?


( ) Це призводить до автоматичного видалення всіх даних у Store ( ) Для збереження місця в пам'яті (x) Store в Redux є імутабельним, тобто його не слід змінювати напряму

Як можна оновлювати дані в Store в Redux?


( ) Змінюючи значення в Store напряму ( ) Використовуючи функцію modifyStore (x) Використовуючи Dispatch, Action та Reducer, які оновлюють значення у Store
