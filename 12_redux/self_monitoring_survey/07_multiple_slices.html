Self-Monitoring Survey: Multiple Slices

1. How do you combine multiple slices into a single store?

By calling combineReducers() manually and passing it to createStore()
By importing all slices into a single "mega-slice"
(x) By adding each slice's reducer to the reducer object in configureStore — each key becomes a top-level state property

2. Given this store configuration, how do you access the cart items in a component?

const store = configureStore({
  reducer: {
    user: userReducer,
    cart: cartReducer,
    notifications: notificationsReducer,
  },
});
useAppSelector((state) => state.items)
useAppSelector((state) => state.cartReducer.items)
(x) useAppSelector((state) => state.cart.items)
useAppSelector((state) => state.cartSlice.items)

3. What is the recommended file structure for a Redux store with multiple features?

Put all reducers in a single reducers.ts file
(x) A store/ folder with store.ts, hooks.ts, and a slices/ subfolder containing one file per feature slice
Separate actions/, reducers/, and constants/ folders (one file per action type)
One file per component that contains both the slice and the component code

4. If one slice needs to react to another slice's action (e.g., cart clears when user logs out), what mechanism does RTK provide?

Import the other slice's state directly and modify it
Use useEffect in a component to watch one slice and dispatch to another
(x) Use extraReducers in the slice definition to listen for actions defined outside the slice
Create a shared "meta-reducer" that wraps both slices
