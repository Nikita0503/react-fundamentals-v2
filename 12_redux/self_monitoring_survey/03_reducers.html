Які параметри приймає Reducer в Redux?


( ) State та Action Type (x) Поточний Store та Action ( ) Action та Payload

Чому Reducer не повинен змінювати поточний Store в Redux?


( ) Так як зміна Store може викликати помилку у React ( ) Для спрощення коду (x) Так як Store в Redux є імутабельним ( ) Зазвичай Redux має декілька екземплярів Store

Чому case default в switch у Reducer є обов'язковим?


( ) Для додавання додаткових полів у Store (x) Так як Reducer має завжди повертати екземпляр Store, інакше буде помилка ( ) Щоб зменшити шанси на колізії з іншими Reducers

Як правильно виглядає приклад Reducer для оновлення Store в Redux?


Варіант 1: 
const userReducer = (state = initialState, action) => {
  switch(action.type){   
    case SET_NAME:
      state.name = action.payload
      break;
    case SET_SURNAME:
      state.surname = action.payload
      break;
  }
}

Варіант 2: 
const userReducer = (state = initialState, action) => {
  switch(action.type){   
    case SET_NAME:
      return {
        ...state,
        name: action.payload
      }
    case SET_SURNAME:
      return {
        ...state,
        surname: action.payload
      }
    default: 
        return state
  }
}

Які є основні принципи роботи зі Store та Reducer в Redux?


( ) Store повинен бути змінюваним та містити всю бізнес-логіку додатку. ( ) Reducer повинен змінювати Store напряму, без використання Action. (x) Reducer - це чиста функція, яка приймає поточний стан Store та Action, і повертає новий стан.
