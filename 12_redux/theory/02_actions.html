Actions

Сам по собі action є об'єктом з 2 полями: Action Type та Payload.

  • Payload - нове значення, котре надходитиме у Store
  • Action Type - унікальна стрічка, котра вказує Reducer що саме робити з Payload

Приклад:

{
  type: "SET_NAME",
  payload: "MyName"
}

Зазвичай Action Type будується по принципу - ACTION_FIELDNAME (ДІЯ_НАЗВАПОЛЯ). Це не є офіційним правилом, але так зручніше та зрозуміліше.

Але працювати з Action у такому вигляді є поганою практикою, для цього створюють Action Creator:

const setName = (name) => ({
  type: "SET_NAME",
  payload: name
})

Action Creator - функція що формує та повертає Action.

Стрічка з поля Action Type нам знадобляться у інших місцях коду, хорошою практикою буде винести її у константу:

const SET_NAME = "SET_NAME";

const setName = (name) => ({
  type: SET_NAME,
  payload: name
})

Тепер сформуємо таку саму пару для surname та зробимо можливість експорту:

/** /redux/actions.js */
export const SET_NAME = "SET_NAME";
export const SET_SURNAME = "SET_SURNAME";

export const setName = (name) => ({
  type: SET_NAME,
  payload: name
});

export const setSurname = (surname) => ({
  type: SET_SURNAME,
  payload: surname
});

Ми сформували Actions. Action Types (SET_NAME, SET_SURNAME) знадобляться у Reducer. Action Creators (setName, setSurname) знадобляться у View/UI.

Увага:

Payload є необов`язковим полем. Він потрібен тоді, коли ми хочемо передати до Reducer якесь значення. Може бути таке що одного Action Type буде достатньо. Наприклад, Action Type "RESET_NAME" дасть зрозуміти, що name треба зробити пустим.

Action Types мусять бути унікальними для запобігання колізій з інишми Reducers.
