Actions

An action by itself is an object with 2 fields: Action Type and Payload.

  • Payload - the new value that will go into the Store
  • Action Type - a unique string that tells the Reducer what exactly to do with the Payload

Example:

{
  type: "SET_NAME",
  payload: "MyName"
}

Usually, Action Type is built following the principle - ACTION_FIELDNAME. This is not an official rule, but it is more convenient and understandable.

But working with an Action in this form is bad practice, so Action Creators are created for this:

const setName = (name) => ({
  type: "SET_NAME",
  payload: name
})

Action Creator - a function that forms and returns an Action.

The string from the Action Type field will be needed in other places in the code, so it is good practice to extract it into a constant:

const SET_NAME = "SET_NAME";

const setName = (name) => ({
  type: SET_NAME,
  payload: name
})

Now let's create the same pair for surname and make it exportable:

/** /redux/actions.js */
export const SET_NAME = "SET_NAME";
export const SET_SURNAME = "SET_SURNAME";

export const setName = (name) => ({
  type: SET_NAME,
  payload: name
});

export const setSurname = (surname) => ({
  type: SET_SURNAME,
  payload: surname
});

We have formed the Actions. Action Types (SET_NAME, SET_SURNAME) will be needed in the Reducer. Action Creators (setName, setSurname) will be needed in the View/UI.

Note:

Payload is an optional field. It is needed when we want to pass some value to the Reducer. There may be cases where the Action Type alone is sufficient. For example, the Action Type "RESET_NAME" makes it clear that name should be made empty.

Action Types must be unique to prevent collisions with other Reducers.
