What problem do state managers solve?

In previous topics, we looked at the possibilities of managing state (application data) using tools built into React itself. In real projects, state managers are used for this purpose.

As the code grows larger, data management becomes increasingly complex and the likelihood of making mistakes increases, where the behavior of data and the application becomes unpredictable. Also, there is the concept of props drilling, which makes code inconvenient, unreadable, and can cause unnecessary component re-renders, leading to decreased application performance.

What is Redux?

The most popular state manager for React is Redux.

Its principles:

  • Keeping data separate from components in a single storage (Store);
  • Giving components the ability to retrieve data from the store, react to its changes (display current data);
  • Modifying data using special functions (Dispatch, Reducers) and objects (Actions)

Let's look at how Redux looks from the inside:

In simple terms:

    • View/UI – component
    • Store - data storage
    • Subscribe - View/UI subscribes to data changes in the Store. View/UI will know that data in the Store is being updated and will display the current values
    • Reducer - a function that knows how to update data in the Store
    • Action - an object that the Reducer function accepts. It contains new data that will update the Store
    • Dispatch - a function called from View/UI when data needs to be updated in the Store. It accepts an Action, which passes it to the Reducer.

At first glance, the architecture seems overly complex. But its advantages are felt as the project grows. This approach ensures stable and comfortable data control with large volumes and complex structures.

Let's look at a component with 2 reactive variables:

/** /components/UserData.js */
import React from 'react';

const UserData = () => {
  const [name, setName] = React.useState('');
  const [surname, setSurname] = React.useState('');

  return (
    <div>
      <input value={name} onChange={(event) => setName(event.target.value)} />
      <input value={surname} onChange={(event) => setSurname(event.target.value)} />
    </div>
  );
}

export default UserData;

Our task is to move name and surname to the Store.
