Яку проблему вирішують стейт-менеджери?

У попередніх темах ми розглядали можливості керування стейтом (даними додатку) за допомогою інструментів вбудованих в сам React. На реальних проектах для цього використовуються стейт-менеджери.

Коли код стає більшим, керування даними стає все більш складнішим та збільшується ймовірність допустити помилки, при котрих поведінка даних та додатку стане непередбаченою. Також, існує поняття props drilling, котре робить код незручним, нечитабельним та може породжувати зайві рендери компонентів, що призводить до подіння продуктивності додатку.

Що таке Redux?

Самим популярним стейт-менеджером для React є Redux.

Його принципи:

  • Утримання даних окремо від компонентів у єдиному сховищі (Store);
  • Давати змогу компонентам можливість отримати дані зі сховища, реагувати на їх зміну (відображати актуальні);
  • Змінювати дані за допомогою спеціальних функцій (Dispatch, Reducers) та об`єктів (Actions)

Розглянемо як виглядає Redux з середини:

Простою мовою:

    • View/UI – компонент
    • Store - сховище даних
    • Subscribe - View/UI підписується на зміну даних у Store. View/UI буде розуміти про те що у Store дані оновлюються і буде відображати актуальні
    • Reducer - функція, котра вміє оновлювати дані у Store
    • Action - об`єкт, який приймає в себе функція Reducer. Він містить у собі нові дані, котрі оновлять Store
    • Dispatch -  функція котра викликається з View/UI при потребі оновлення даних у Store. Вона приймає в себе Action, котрий передає його до Reducer.

На перший погляд, архітектура здається заскладною. Але її переваги відчуваються при збільшенні проекту. Такий підхід забеспечує стабільний та комфортний контроль даних при їх великих об'ємах та складній структурі.

Розглянемо компонент з 2 реактивними зміними:

/** /components/UserData.js */
import React from 'react';

const UserData = () => {
  const [name, setName] = React.useState('');
  const [surname, setSurname] = React.useState('');

  return (
    <div>
      <input value={name} onChange={(event) => setName(event.target.value)} />
      <input value={surname} onChange={(event) => setSurname(event.target.value)} />
    </div>
  );
}

export default UserData;

Наше завдання - зробити так, щоб name та surname перенеслися до Store.

Перший крок - створити папку redux у корені проекту.

Другий - встановити Redux:

npm install redux react-redux
