Store

Store - a single data storage. To initialize it, we need to create a rootReducer - a collection of all the application's Reducers.

/** /redux/store.ts */

import { combineReducers, createStore } from 'redux';
import userReducer from './reducer';

const rootReducer = combineReducers({
  user: userReducer,
});

export type RootState = ReturnType<typeof rootReducer>;
export type AppDispatch = typeof store.dispatch;

export const store = createStore(rootReducer);

Using the combineReducers function, we create the rootReducer.

RootReducer accepts an object where keys are the names by which you can access the Reducers, and values are the Reducers themselves.

For example, name, which is in userReducer, will be located at the address: state.user.name.

And we create the store using the createStore function, which accepts our created rootReducer as the first parameter.

The Redux writing part is complete. All that remains is to give components the ability to retrieve data from the Store and update it.
