Store

Store - едине сховище даних. Для його ініціалізації нам необхідно створити rootReducer - збірник усіх Reducers додатку.

/** /redux/store */

import { combineReducers, createStore } from 'redux'; import userReducer from './reducer'; const rootReducer = combineReducers({ user: userReducer, }); export const store = createStore(rootReducer);

За допомогою функції combineReducers створюємо rootReducer.

RootReduer приймає об`єкт, де ключи - це назви за котрими можна звертатися до Reducers, а значення - самі Reducers.

Наприклад, name, котрий у userReducer, буде знаходитися за адресою: state.user.name.

Та створюємо store за допомогою функції createStore, яка першим параметром приймає створений нами rootReducer.

Частина написання Redux завершилася. Залишилося дати змогу компонентам отримувати дані зі Store, та оновлювати їх.
