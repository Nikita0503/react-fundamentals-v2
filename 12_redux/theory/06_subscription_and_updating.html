Subscribe (data updating)

Let's return to the UserData file:

/** /components/UserData.tsx */

const UserData = () => {
  const [name, setName] = React.useState('');
  const [surname, setSurname] = React.useState('');

  return (
    <div>
      <input value={name} onChange={(event) => setName(event.target.value)} />
      <input value={surname} onChange={(event) => setSurname(event.target.value)} />
    </div>
  );
}

export default UserData;

name and surname are now inside the Store, so the reactive variables inside the component are no longer needed.

useSelector

To access name and surname in the View/UI (component), you can use the useSelector hook from the 'react-redux' package:

/** /components/UserData.tsx */

import { useSelector } from 'react-redux';
import { RootState } from '../redux/store';

const UserData = () => {
  const name = useSelector((state: RootState) => state.user.name);
  const surname = useSelector((state: RootState) => state.user.surname);

  return (
    <div>
      <input value={name} />
      <input value={surname} />
    </div>
  );
}

export default UserData;

useSelector returns values located at an address built following the principle - state.REDUCER_NAME.FIELD_NAME.

Since in the RootReducer we assigned the key user to userReducer, and name is inside userReducer, we have the address - state.user.name.

useDispatch

Now View/UI displays data from the Store. But when editing the input, name and surname still won't change.

Therefore, we need to teach the component to update name and surname. For this, the Dispatch function is used.

The useDispatch hook from the 'react-redux' package returns the Dispatch function:

/** /components/UserData.tsx */

import { useSelector, useDispatch } from 'react-redux';
import { setName, setSurname } from '../redux/actions';
import { RootState, AppDispatch } from '../redux/store';

const UserData = () => {
  const dispatch = useDispatch<AppDispatch>();

  const name = useSelector((state: RootState) => state.user.name);
  const surname = useSelector((state: RootState) => state.user.surname);

  return (
    <div>
      <input value={name} onChange={(event) => dispatch(setName(event.target.value))} />
      <input value={surname} onChange={(event) => dispatch(setSurname(event.target.value))} />
    </div>
  );
}

export default UserData;

Dispatch accepts an Action (which is formed and returned by the Action Creator) and sends it to the Reducer, where the Store update occurs.

Note:

  • Do not try to update data in the Store without using Dispatch.
  • useSelector and useDispatch are not the only ways to interact with the Store. There is a way to interact through the connect function.
