Connecting Redux to the Project

Currently the App.tsx file looks like this:

/** App.tsx */

const App = () => {
  return (
    <UserData/>
  );
};

export default App;

To give all components access to the Store, you need to wrap them in a Provider from the 'react-redux' package and provide it with the Store:

/** App.tsx */

import { Provider } from 'react-redux';
import { store } from './redux/store';
import UserData from './UserData';

const App = () => {

  return (
    <Provider store={store}> 
      <UserData/>
    </Provider>
  );
}


export default App;

Now every component used inside the App component has the ability to retrieve and update Store data.
