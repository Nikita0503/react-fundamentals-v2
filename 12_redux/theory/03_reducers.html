Reducers

Reducer - чиста функція, котра мусить повернути оновлений екземпляр Store. Reducer приймає 1 параметром поточний Store, 2 параметром Action. Так як Store в Redux є імутабельним, Reducer не повинен змінювати Store. Він мусить повернути новий Store на основі попереднього:

/** /redux/reducer.js */

import {SET_NAME, SET_SURNAME} from './actions';

const initialState = {
  name: '',
  surname: '',
}

const userReducer = (state = initialState, action) => {
  switch(action.type){   
    case SET_NAME:
      return {
        ...state,
        name: action.payload
      }
    case SET_SURNAME:
      return {
        ...state,
        surname: action.payload
      }
    default: 
        return state
  }
}

export default userReducer;

InitialState - частина Store за яку відповідає Reducer.

'state = initialeState' - у разі коли на місце state передали null(nullable), javascript підставить замість null(nullable) значення initialState. Таке відбувається при ініціалізації Redux.

Після того як Action попадає у Reducer, звіряємо action.type з кейсами в котрих Reducer зможе обробити наданий action.payload використовуючи switch-case.

Якщо action.type = SET_NAME, то Reducer поверне новий екземпляр Store, де name буде оновленим (його значенням буде те що було в action.payload), а усі останні поля (surname) залишаться незмінними.

Після того як Reducer поверне новий Store, View/UI відобразить актуальні дані. Якщо action.type не підходить ні до одного з кейсів, то Reducer відпрацює кейс default та поверне Store без змін.

Увага:

case default є обов`язковим, так як reducer мусить кожного разу повертати екземпляр Store.

При ініциалізації Redux, reducer приймає декілька разів свої внутрішні Actions, котрі не припадають на ваші кейси. Тому потрібен default case.
