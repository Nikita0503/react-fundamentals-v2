Reducers

A Reducer is a pure function that must return an updated instance of the Store. The Reducer accepts the current Store as the 1st parameter and an Action as the 2nd parameter. Since the Store in Redux is immutable, the Reducer must not modify the Store. It must return a new Store based on the previous one:

/** /redux/reducer.ts */

import { SET_NAME, SET_SURNAME, UserAction } from './actions';

type UserState = {
  name: string;
  surname: string;
};

const initialState: UserState = {
  name: '',
  surname: '',
};

const userReducer = (state = initialState, action: UserAction): UserState => {
  switch(action.type){   
    case SET_NAME:
      return {
        ...state,
        name: action.payload
      }
    case SET_SURNAME:
      return {
        ...state,
        surname: action.payload
      }
    default: 
        return state
  }
}

export default userReducer;

InitialState - the part of the Store that the Reducer is responsible for.

'state = initialState' - in case null(nullable) is passed in place of state, JavaScript will substitute the initialState value instead of null(nullable). This happens during Redux initialization.

After the Action reaches the Reducer, we compare action.type with cases in which the Reducer can process the provided action.payload using switch-case.

If action.type = SET_NAME, then the Reducer will return a new instance of the Store where name will be updated (its value will be what was in action.payload), and all other fields (surname) will remain unchanged.

After the Reducer returns the new Store, View/UI will display the current data. If action.type does not match any of the cases, the Reducer will execute the default case and return the Store without changes.

Note:

The default case is mandatory, since the reducer must return a Store instance every time.

During Redux initialization, the reducer receives its internal Actions several times, which do not match your cases. That is why the default case is needed.
