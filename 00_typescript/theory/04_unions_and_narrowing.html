Union Types

A union type means a value can be one of several types. You write it with the pipe symbol | (read it as "or"):

type Status = "idle" | "loading" | "success" | "error";

let currentStatus: Status = "idle";
currentStatus = "loading"; // ✅
currentStatus = "unknown"; // ❌ Error: not assignable to type Status

// A function that accepts string OR number
function formatId(id: string | number): string {
  return `ID: ${id}`;
}
formatId(123);     // ✅
formatId("abc");   // ✅
formatId(true);    // ❌ Error: boolean is not string | number

Literal Types

Literal types are exact values used as types — not just "any string" but a specific string:

type Direction = "up" | "down" | "left" | "right";
type HttpMethod = "GET" | "POST" | "PUT" | "DELETE";
type Size = "sm" | "md" | "lg";

This is extremely useful for component props in React. For example, <Button size="lg" /> — TypeScript ensures only valid sizes are passed. If you typo "large" instead of "lg", you get an error immediately.

Type Narrowing

Type narrowing is the process of telling TypeScript which specific type a value is within a union. When you have string | number, you need to narrow it down before using type-specific methods:

function printValue(value: string | number) {
  // TS doesn't know if it's string or number here
  console.log(value.toUpperCase()); // ❌ Error: toUpperCase doesn't exist on number

  // Narrow with typeof
  if (typeof value === "string") {
    console.log(value.toUpperCase()); // ✅ TS knows it's string here
  } else {
    console.log(value.toFixed(2)); // ✅ TS knows it's number here
  }
}

Narrowing Techniques

There are several ways to narrow types:

  • typeof — for primitives ("string", "number", "boolean")
  • in — check if a property exists in an object
  • instanceof — check if something is an instance of a class
  • Discriminated unions — a shared field that identifies which type it is:
type SuccessResponse = { status: "success"; data: User };
type ErrorResponse = { status: "error"; message: string };
type ApiResponse = SuccessResponse | ErrorResponse;

function handleResponse(response: ApiResponse) {
  if (response.status === "success") {
    console.log(response.data.name); // ✅ TS knows it's SuccessResponse
  } else {
    console.log(response.message); // ✅ TS knows it's ErrorResponse
  }
}

A discriminated union is a union where each member has a shared property (here: status) with a unique literal value. TypeScript uses that property to figure out which type you're dealing with.

Nullable Types

In real applications, values are often missing — a user might not be loaded yet, a search might return no results. You represent this with null:

type User = { name: string; email: string };

// User might not exist (e.g., not loaded yet)
let currentUser: User | null = null;

// Must check before using
if (currentUser) {
  console.log(currentUser.name); // ✅ TS knows it's not null here
}

Optional Chaining and Nullish Coalescing

Two operators that make working with nullable values much cleaner:

const user: User | null = getUser();

// Optional chaining (?.) — returns undefined if user is null (instead of crashing)
const name = user?.name; // type: string | undefined

// Nullish coalescing (??) — provide a default when value is null or undefined
const displayName = user?.name ?? "Anonymous"; // type: always string

?. says "if the thing before me is null/undefined, stop here and return undefined." ?? says "if the thing before me is null/undefined, use this default value instead."
