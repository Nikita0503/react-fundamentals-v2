What Are Utility Types?

TypeScript provides built-in utility types — type transformations that save you from writing repetitive types manually. They take an existing type and produce a new one by modifying it in some way (making properties optional, picking specific fields, etc.).

Partial<T>

Makes all properties optional:

type User = { name: string; email: string; age: number };

type UpdateUserDto = Partial<User>;
// Result: { name?: string; email?: string; age?: number }

// Use case: update functions where you only send changed fields
function updateUser(id: number, updates: Partial<User>) { /* ... */ }
updateUser(1, { name: "Bob" }); // ✅ only updating name

Required<T>

Makes all properties required (the opposite of Partial):

type Config = { theme?: string; locale?: string };
type FullConfig = Required<Config>;
// Result: { theme: string; locale: string } — no more optional

Pick<T, Keys>

Selects specific properties from a type — creates a new type with only the fields you list:

type User = { id: number; name: string; email: string; password: string };

type PublicUser = Pick<User, "id" | "name" | "email">;
// Result: { id: number; name: string; email: string } — no password

Omit<T, Keys>

Removes specific properties (the opposite of Pick):

type User = { id: number; name: string; email: string; password: string };

type CreateUserDto = Omit<User, "id">;
// Result: { name: string; email: string; password: string } — no id (server generates it)

Record<K, V>

Creates an object type with specific key and value types — useful for dictionaries and lookup maps:

type Status = "idle" | "loading" | "error";
type StatusMessages = Record<Status, string>;
// Result: { idle: string; loading: string; error: string }

const messages: StatusMessages = {
  idle: "Ready",
  loading: "Please wait...",
  error: "Something went wrong",
};

ReturnType<T>

Extracts the return type of a function:

function createUser() {
  return { id: 1, name: "Alice", createdAt: new Date() };
}

type NewUser = ReturnType<typeof createUser>;
// Result: { id: number; name: string; createdAt: Date }

Useful when you don't want to manually define a type that matches a function's output. typeof here gets the type of the function itself, and ReturnType extracts what it returns.

Parameters<T>

Extracts parameter types of a function as a tuple (ordered array of types):

function search(query: string, page: number, limit: number) { /* ... */ }

type SearchParams = Parameters<typeof search>;
// Result: [string, number, number]

Summary — When to Use Each

UtilityUse case
Partial<T>Update/patch operations (only some fields)
Required<T>Ensure all optional fields are provided
Pick<T, K>Select subset of fields (public API, DTOs)
Omit<T, K>Remove fields (hide password, remove id for creation)
Record<K, V>Dictionaries, lookup maps, config objects
ReturnType<T>Derive type from function output
