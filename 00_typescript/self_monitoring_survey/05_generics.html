What problem do generics solve?


( ) They make code run faster by optimizing types at compile time ( ) They allow you to skip type annotations entirely (x) They let you write reusable code that works with different types without losing type safety ( ) They convert JavaScript code to TypeScript automatically

What does `<T>` represent?


( ) A special HTML tag used in TypeScript ( ) A template literal type (x) A type parameter — a placeholder that gets filled in when the function/type is used ( ) A constraint that limits the function to only accept objects

What does a constraint like `<T extends { id: number }>` mean?


( ) T must be exactly the type `{ id: number }` and nothing else ( ) T must be a number type (x) T must be a type that has at least an `id` property of type number ( ) T extends the Number class

Where will you see generics in React?


( ) Only in class components, not in functional components ( ) Only when using Redux for state management (x) useState<T>, useRef<T>, createContext<T>, Promise<T> ( ) Only in third-party libraries, never in your own code
