Як використовувати Контекст (Context) в React для передачі даних між компонентами?


( ) Для використання Контексту в React, потрібно встановити спеціальну бібліотеку react-context. (x) Для використання Контексту в React, можна створити контекст за допомогою createContext, огорнути батьківський компонент в Provider з вказанням значення контексту, а потім використовувати useContext в дочірніх компонентах для отримання доступу до даних. ( ) Контекст в React може бути використаний тільки для передачі статичних даних і не підходить для передачі функцій чи об'єктів стану.

Чому використання механізму Контексту (Context) є корисним для передачі даних у дочірні компоненти вкладених на декілька рівнів вниз в ієрархії компонентів?


( ) Використання Контексту дозволяє створювати багаторазово використовувані "сховища" для даних, які легко об'єднують та переносять між різними гілками компонентної ієрархії. ( ) Використання пропсів є найефективнішим способом передачі даних у всіх сценаріях. (x) Контекст дозволяє уникнути пропс drilling, що робить код більш зрозумілим та покращує його обслуговування.

Чи можна використовувати реактивні змінні та функції їх зміни в механізмі Контексту (Context) в React?


( ) Ні, можна передавати тільки статичні дані без можливості їх зміни. ( ) Так, можна передавати реактивні змінні, але не можна передавати функції для їх оновлення. ( ) Ні, механізм Контексту підтримує передачу реактивних змінних та функцій для їх зміни. (x) Так, можна передавати реактивні змінні, також можна передавати функції для їх оновлення.
