When is Context the right choice?


( ) For data that changes on every keystroke or scroll event.
( ) For complex state with dozens of actions and reducers.
(x) For data that changes infrequently — theme, locale, auth status.
( ) For caching server responses and managing loading states.

When is Context NOT enough?


( ) When you need to pass data from parent to child.
( ) When you have only two or three components sharing state.
( ) When the data is a simple string or boolean.
(x) For frequently changing data, complex state with many actions, or when you need selectors.

What tools are designed for complex global state management?


( ) useState and useReducer — they handle all state needs.
( ) React Query and Axios — they manage all client state.
( ) useContext with useMemo — it solves all performance issues.
(x) Redux Toolkit and Zustand — dedicated state management libraries with selectors and middleware.
