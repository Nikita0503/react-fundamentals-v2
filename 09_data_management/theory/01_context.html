Context

Passing data down to child components through multiple levels of nesting can cause problems, especially regarding props drilling. To prevent these problems, React has a built-in mechanism that allows passing data without using props. This mechanism is called Context:

import React, { createContext } from 'react';

// Creating a context with a type
const MyContext = createContext<string>('');

// Parent component that provides the context
const ParentComponent = () => {
  const data = 'This is data from context';

  return (
    <MyContext.Provider value={data}>
      <ChildComponent />
    </MyContext.Provider>
  );
}

export default ParentComponent;
export { MyContext }; // export the context so it can be used in other components

In order for child components to have access to the context data, they need to be wrapped in the Provider component contained in MyContext, which was returned to us by the createContext function;

import React from 'react';
import GrandchildComponent from './GrandchildComponent';

const ChildComponent = () => {
  return (
    <div>
      <GrandchildComponent />
    </div>
  );
}

export default ChildComponent;

ChildComponent — a child component that also has the ability to receive data from the context, but it simply contains the GrandchildComponent, which will need the context data further down.

import React, { useContext } from 'react';
import { MyContext } from './ParentComponent';

// "Grandchild" component that receives data from the context
const GrandchildComponent = () => {
  const data = useContext(MyContext); // Getting data from the context

  return (
    <div>
      <p>{data} </p>
    </div>
  );
}

export default GrandchildComponent;

GrandchildComponent — a component that uses data from the context. For this, we imported MyContext, which was in ParentComponent (the highest component in the hierarchy), and used the useContext hook, to which we passed MyContext, so that it returns the data of this context into data.

The Context mechanism can be used to pass any data. For example, functions for changing the state of the parent component. For convenience, it is sufficient to pass an object into the context that contains these functions or other data as its fields.
