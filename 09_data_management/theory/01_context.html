Контекст

Просування даних у дочірні компоненти на декілька рівнів вкладеності вниз, можуть викликати проблеми, особливо це стосується props drilling. Для запобігання цих проблем React має вбудований механізм, який дозволяє передавати дані без використання пропсів (props). Цей механізм називається Контекст (Context):

import React, { createContext } from 'react';

// Створюємо контекст
const MyContext = createContext();

// Батьківський компонент, який надає контекст
const ParentComponent = () => {
  const data = 'Це дані з контексту';

  return (
    <MyContext.Provider value={data}>
      <ChildComponent />
    </MyContext.Provider>
  );
}

export default ParentComponent;
export { MyContext }; // експортуємо контекст, щоб його можна було використовувати в інших компонентах

Для того щоб дочірні компоненти мали доступ до даних контексту, їх потрібно огорнути в компонент Provider, що міститься у MyContext, який нам повернула функція createContext;

import React from 'react';
import GrandchildComponent from './GrandchildComponent';

const ChildComponent = () => {
  return (
    <div>
      <GrandchildComponent />
    </div>
  );
}

export default ChildComponent;

ChildComponent - Дочірній компонент, який також має змогу отримати дані з контексту, але він просто містить у собі GrandchildComponent, котрий буде потребувати даніі з контексту далі.

import React, { useContext } from 'react';
import { MyContext } from './ParentComponent';

// «Внуковий» компонент, який отримує дані з контексту
const GrandchildComponent = () => {
  const data = useContext(MyContext); // Отримання данних з контексту

  return (
    <div>
      <p>{data} </p>
    </div>
  );
}

export default GrandchildComponent;

GrandchildComponent - компонент, котрий використовує дані з контексту. Для цього ми імпортували MyContext, котрий був у ParentComponent (найвищий комопнент у ієрархії), та використали хук useContext, якому надали MyContext, для того щоб він повернув дані цього контексту у data.

Механізм Контексту можна застосовувати для передачі будь-яких даних. Наприклад, функції для зміни стану батьківського компоненту. Для зручності достатньо передавати у контекст об`єкт, який у якості полів містить ці функції або інші дані.
