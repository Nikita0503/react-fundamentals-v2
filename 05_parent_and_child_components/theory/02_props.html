Props

React provides the ability to pass data from a parent component to a child component. When parent components pass data to child components, they can use props (properties) to pass this data. Props are properties that are passed to a child component from the outside, from its parent, and are used in the child component to configure the display or behavior of the component.

Props are passed from the parent component to the child component through attributes in JSX (extended JavaScript syntax) when components are rendered. For example, in the parent component we can pass data to the child component using attributes:

// ParentComponent.tsx
import React from 'react';
import ChildComponent from './ChildComponent';

const ParentComponent = () => {
  const data: string = 'This is data from the parent component';

  return (
    <div>
      <h1>Parent Component</h1>
      <ChildComponent data={data} />
    </div>
  );
};

export default ParentComponent;
// ChildComponent.tsx
import React from 'react';

type ChildComponentProps = {
  data: string;
};

const ChildComponent = ({ data }: ChildComponentProps) => {
  return (
    <div>
      <h2>Child Component</h2>
      <p>Data from parent component: {data}</p>
    </div>
  );
};

export default ChildComponent;

Props is an object, we applied destructuring for convenient use of its fields (data). But if you don't do this and access the object's fields directly (props.data), it will not be an error:

// ChildComponent.tsx
import React from 'react';

type ChildComponentProps = {
  data: string;
};

const ChildComponent = (props: ChildComponentProps) => {

  return (
    <div>
      <h2>Child Component</h2>
      <p>Data from parent component: {props.data}</p>
    </div>
  );
};

export default ChildComponent;
