Props

React надає змогу передавати дані з батьківського компоненту до дитячого. Коли компоненти-батьки передають дані компонентам-дітям, вони можуть використовувати пропси (props) для передачі цих даних. Пропси - це властивості, які передаються компоненту-дитині ззовні, від його батька, і використовуються в компоненті-дитині для налаштування відображення або поведінки компонента.

Пропси передаються з компонента-батька до компонента-дитини через атрибути в JSX (синтаксис розширеного JavaScript), коли компоненти рендеряться. Наприклад, у компоненті-батьку ми можемо передати дані в компонент-дитину, використовуючи атрибути:

// Батьківський компонент
import React from 'react';
import ChildComponent from './ChildComponent';

const ParentComponent = () => {
  const data = 'Це дані з батьківського компонента';

  return (
    <div>
      <h1>Батьківський компонент</h1>
      <ChildComponent data={data} />
    </div>
  );
};

export default ParentComponent;
// Компонент-дитина
import React from 'react';

const ChildComponent = (props) => {
  const { data } = props;

  return (
    <div>
      <h2>Дитячий компонент</h2>
      <p>Дані з батьківського компонента: {data}</p>
    </div>
  );
};

export default ChildComponent;

Props -  об`єкт, ми застосували деструктуризацію для зручного використання його полів (data). Але якщо цього не робити і звертатися до полів об’єкта напряму (props.data), це не буде помилкою:

// Компонент-дитина
import React from 'react';

const ChildComponent = (props) => {

  return (
    <div>
      <h2>Дитячий компонент</h2>
      <p>Дані з батьківського компонента: {props.data}</p>
    </div>
  );
};

export default ChildComponent;
