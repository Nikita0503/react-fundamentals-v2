Props drilling

Props drilling (або також відомий як "prop drilling") - це патерн у React, коли пропси передаються через кілька рівнів вкладених компонентів, навіть якщо деякі з цих компонентів не використовують ці пропси. Це може призвести до зайвого передачі даних вниз по ієрархії компонентів, що може вплинути на читабельність та підтримку коду.

Основна проблема з props drilling полягає в тому, що пропси передаються через кожен вкладений компонент, навіть якщо вони потрібні лише останньому компоненту на цьому шляху. Це може зробити код більш складним для розуміння та підтримки, особливо в глибоко вкладених структурах компонентів.

Пропси використовуються в React для передачі даних від батьківського компонента до дочірніх компонентів. Проте, якщо в компонентах на шляху від батьківського до дочірнього компонента пропси не використовуються, але все ж потрібно передавати їх через кожен вкладений компонент, то це може призвести до надмірного передачі даних, збільшення кількості коду та зміни пропсів в багатьох місцях при їх зміні.

Деякі рішення для уникнення проблеми props drilling включають використання контексту (context) в React для передачі даних на кілька рівнів вкладених компонентів без потреби передавати пропси крізь всю ієрархію компонентів, а також використання станових керувальників (state management) бібліотек, таких як Redux, для централізованого зберігання та керування даними, що використовуються в декількох компонентах.

Приклад того, як props drilling виглядає у коді:

// Компонент App (найбільший рівень)
import React, { useState } from 'react';
import ParentComponent from './ParentComponent';
  
const App = () => {
  const [data, setData] = useState('Дані з App компонента');
  
  const handleDataChange = (newData) => {
    setData(newData);
  }
  
  return (
    <div>
      <h1>App компонент</h1>
      <p>Дані: {data}</p>
      <ParentComponent data={data} onDataChange={handleDataChange} />
    </div>
  );
};
  
export default App;
// Компонент ParentComponent (батьківський рівень)
import React from 'react';
import ChildComponent from './ChildComponent';

const ParentComponent = ({ data, onDataChange }) => {
  return (
    <div>
      <h2>Батьківський компонент</h2>
      <p>Дані: {data}</p>
      <ChildComponent data={data} onDataChange={onDataChange} />
    </div>
  );
};

export default ParentComponent;
// Компонент ChildComponent (дочірній рівень)
import React from 'react';

const ChildComponent = ({ data, onDataChange }) => {
  const handleButtonClick = () => {
    const newData = 'Дані змінені в дочірньому компоненті';
    onDataChange(newData);
  }

  return (
    <div>
      <h3>Дочірній компонент</h3>
      <p>Дані: {data}</p>
      <button onClick={handleButtonClick}>Змінити дані</button>
    </div>
  );
};

export default ChildComponent;

У цьому прикладі App є найбільшим рівнем компонентів, який містить стан data та функцію handleDataChange для зміни цього стану. Цей стан та функція передаються вниз через пропс data та onDataChange в батьківський компонент ParentComponent, а потім далі вниз в дочірній компонент ChildComponent.

В ChildComponent ці пропси використовуються для відображення даних та зміни даних через функцію onDataChange при кліку на кнопку. Це приклад використання props drilling, коли дані та функції передаються вниз в компонентах через пропси безпосередньо, навіть якщо деякі компоненти не використовують ці пропси.
