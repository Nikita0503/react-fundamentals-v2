What Are Props?

Props (short for "properties") are data passed from a parent component to a child component via JSX attributes. They are the mechanism that allows components to communicate in one direction — from parent to child.

Props are read-only — a child component can never modify its own props. If a child needs to change something, it must ask the parent to do it (via callbacks — covered in the next topic).

How to Pass Props

The parent passes data to the child as JSX attributes:

// Parent passes data to child
<UserCard name="Alice" age={25} isAdmin={true} />

Strings are passed in quotes. Numbers, booleans, arrays, objects, and functions are passed in curly braces {}.

How to Receive Props

There are two ways to receive props in a child component:

1. Destructuring (preferred):

type UserCardProps = {
  name: string;
  age: number;
  isAdmin: boolean;
};

const UserCard = ({ name, age, isAdmin }: UserCardProps) => {
  return (
    <div>
      <h2>{name}</h2>
      <p>Age: {age}</p>
      {isAdmin && <span>Admin</span>}
    </div>
  );
};

2. Props object (also valid):

const UserCard = (props: UserCardProps) => {
  return <p>{props.name}</p>;
};

Destructuring is preferred because it makes it immediately clear which props the component uses.

Different Prop Types

Props can be of any type. Here's a comprehensive example showing the most common ones:

type ExampleProps = {
  text: string;                    // string
  count: number;                   // number
  isVisible: boolean;              // boolean
  items: string[];                 // array
  user: { name: string; id: number }; // object
  onClick: () => void;             // function (no args)
  onChange: (value: string) => void; // function (with args)
  icon?: React.ReactNode;          // optional, any renderable content
};

Default Values

Use JavaScript default parameters to provide default values for optional props:

type ButtonProps = {
  label: string;
  variant?: "primary" | "secondary";
  size?: "sm" | "md" | "lg";
};

const Button = ({ label, variant = "primary", size = "md" }: ButtonProps) => {
  return <button className={`btn-${variant} btn-${size}`}>{label}</button>;
};

// Usage — defaults apply when prop is not passed:
<Button label="Click me" />              // variant="primary", size="md"
<Button label="Cancel" variant="secondary" /> // variant="secondary", size="md"

This approach is clean and idiomatic — no need for defaultProps (which is deprecated for function components).

Props Are the Component's API

Think of props as the interface that defines how a component can be configured from the outside. Just like a function's parameters define how you call it, a component's props define how you use it.

A well-designed props interface makes a component easy to use, predictable, and reusable across different parts of your application.

Note: there's a special prop called children that lets you pass content between opening and closing tags — covered in detail in a later module.
