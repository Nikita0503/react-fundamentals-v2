Props with Callback Functions

Props are read-only, meaning they cannot be changed by the child component. This helps ensure unidirectional data flow in React, where data is passed from top to bottom through the component hierarchy. A child component can use the props passed to it to display data or call functions passed in props, but it cannot change this data directly. Instead, the child component can notify the parent component about changes by calling functions from props passed to it from the parent component.

Props allow passing callback functions to child components, which allows child components to interact with their parents. When a child component calls a function passed in props from the parent component, it can notify the parent component about changes or invoke certain functionality that exists at the parent level:

// Parent component

import React, { useState } from "react";
import ChildComponent from "./ChildComponent";

const ParentComponent = () => {
  const [counter, setCounter] = useState(0);

  // Callback function that changes state in the parent component
  const incrementCounter = () => {
    setCounter(counter + 1);
  };

  return (
    <div>
      <h1>Parent Component</h1>
      <p>Counter: {counter}</p>
      <ChildComponent onButtonClick={incrementCounter} />
    </div>
  );
};

export default ParentComponent;
// Child component

import React from "react";

const ChildComponent = (props) => {
  return (
    <div>
      <h2>Child Component</h2>
      <button onClick={props.onButtonClick}>Increment counter</button>
    </div>
  );
};

export default ChildComponent;

The parent component ParentComponent contains the counter state and the incrementCounter function, which changes the counter state on each call. The child component ChildComponent accepts onButtonClick as a prop and uses it as a callback when the button is clicked. The incrementCounter function changes the counter state in ParentComponent, sending the new value from the child component to the parent component through the callback. When the counter value changes, the parent component ParentComponent will re-render, and ChildComponent will re-render along with it.
