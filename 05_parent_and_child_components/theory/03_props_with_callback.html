Props з використанням callback-функції

Пропси є одноразовими, тобто вони не можуть бути змінені дитячим компонентом. Це допомагає забезпечити односторонній потік даних в React, де дані передаються зверху вниз по ієрархії компонентів. Компонент-дитина може користуватися переданими їй пропсами для відображення даних або виклику функцій, переданих в пропсах, але вона не може змінювати ці дані безпосередньо. Замість цього, компонент-дитина може сповіщати батьківський компонент про зміни, викликаючи функції з пропсів, переданих їй від батьківського компонента.

Пропси дозволяють передавати функції-зворотні виклики (callback functions) в компоненти-діти, що дозволяє дочірнім компонентам взаємодіяти зі своїми батьками. Коли компонент-дитина викликає функцію, передану в пропсах від батьківського компонента, він може сповістити батьківський компонент про зміни або викликати певну функціональність, що знаходиться на батьківському рівні:

// Батьківський компонент

import React, { useState } from "react";
import ChildComponent from "./ChildComponent";

const ParentComponent = () => {
  const [counter, setCounter] = useState(0);

  // Функція-зворотний виклик, яка змінює стан у батьківському компоненті
  const incrementCounter = () => {
    setCounter(counter + 1);
  };

  return (
    <div>
      <h1>Батьківський компонент</h1>
      <p>Лічильник: {counter}</p>
      <ChildComponent onButtonClick={incrementCounter} />
    </div>
  );
};

export default ParentComponent;
// Компонент-дитина

import React from "react";

const ChildComponent = (props) => {
  return (
    <div>
      <h2>Дитячий компонент</h2>
      <button onClick={props.onButtonClick}>Збільшити лічильник</button>
    </div>
  );
};

export default ChildComponent;

Компонент-батько ParentComponent містить стан counter та функцію incrementCounter, яка змінює стан counter при кожному виклику. Компонент-дитина ChildComponent приймає onButtonClick як пропс та використовує його як зворотний виклик при натисканні на кнопку. Функція incrementCounter змінює стан counter у ParentComponent, відправляючи нове значення з компонента-дитини до компонента-батька через зворотний виклик. При зміні значення counter батьківський компонент ParentComponent буде паремальовуватися, разом з ним перемалюється й ChildComponent.
