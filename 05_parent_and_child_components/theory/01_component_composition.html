Component Composition

In React, components can contain other components within them. Components are used to build a display hierarchy, where each component can be a parent component for one or many child components, and vice versa, each component can be a child component for one or many parent components. This is called the component model, or "component composition":

// Parent component
import React from 'react';
import ChildComponent from './ChildComponent';
    
const ParentComponent = () => {
      
  return (
    <div>
      <h1>Parent Component</h1>
      <ChildComponent/>
    </div>
  );
};
    
export default ParentComponent;
// Child component
import React from 'react';

const ChildComponent = () => {

  return (
    <div>
      <h2>Child Component</h2>
    </div>
  );
};

export default ChildComponent;

The ParentComponent is the parent component for ChildComponent, since along with "<h1>Parent Component</h1>" it returns ChildComponent from itself. ChildComponent in turn is the child component for ParentComponent.

Important note: When the parent component re-renders, all its child components will re-render along with it.
