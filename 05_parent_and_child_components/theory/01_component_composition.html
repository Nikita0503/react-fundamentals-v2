Композиція компонентів

У React компоненти можуть містити у собі інші компоненти. Компоненти використовуються для побудови ієрархії відображення, де кожен компонент може бути батьківським компонентом для одного або багатьох дочірніх компонентів, і навпаки, кожен компонент може бути дочірнім компонентом для одного або багатьох батьківських компонентів. Це називається компонентною моделлю, або «композицією компонентів»:

// Батьківський компонент
import React from 'react';
import ChildComponent from './ChildComponent';
    
const ParentComponent = () => {
      
  return (
    <div>
      <h1>Батьківський компонент</h1>
      <ChildComponent/>
    </div>
  );
};
    
export default ParentComponent;
// Компонент-дитина
import React from 'react';

const ChildComponent = () => {

  return (
    <div>
      <h2>Дитячий компонент</h2>
    </div>
  );
};

export default ChildComponent;

Компонент ParentComponent є батьківським компонентом для ChildComponent, так як разом з "<h1>Батьківський компонент</h1>" він повертає з себе ChildComponent. ChildComponent в свою чергу є дитячим компонентом для ParentComponent.

Важливе зауваження: При перемальовці батьківського компоненту, усі його дитячі компоненти будуть перемальовуватися разом з ним. Компонент-дитина, дитячий компонент, дочірній компонент - одне і теж саме.
