Як можна передавати функції-зворотні виклики в компоненти-діти в React?


( ) Через глобальний стан. (x) Через пропси. ( ) Через використання локального сховища.

У чому полягає перевага одностороннього потоку даних в React?


( ) Він сприяє більш швидкому відображенню змін у стані компонентів.
( ) Він забезпечує автоматичну синхронізацію станів всіх компонентів.
(x) Він полегшує відлагодження та передбачення роботи компонентів, оскільки дані рухаються визначеним напрямком - зверху вниз.

Якщо компонент-дитина потрібно повідомити батьківський компонент про зміни, як це можна здійснити в React?


(x) Завдяки використанню функцій-зворотних викликів (callbacks) як пропсів, переданих у компонент-дитину.
( ) Завдяки використанню глобального об'єкта для обміну даними між компонентами.
( ) Завдяки використанню внутрішнього стану компонентів для автоматичного сповіщення батьківського компонента.

Що відбувається у коді?


// Батьківський компонент

import React, { useState } from "react";
import ChildComponent from "./ChildComponent";

const ParentComponent = () => {
  const [counter, setCounter] = useState(0);

  // Функція-зворотний виклик, яка змінює стан у батьківському компоненті
  const incrementCounter = () => {
    setCounter(counter + 1);
  };

  return (
    <div>
      <h1>Батьківський компонент</h1>
      <p>Лічильник: {counter}</p>
      <ChildComponent onButtonClick={incrementCounter} />
    </div>
  );
};

export default ParentComponent;

// Компонент-дитина

import React from "react";

const ChildComponent = (props) => {
  return (
    <div>
      <h2>Дитячий компонент</h2>
      <button onClick={props.onButtonClick}>Збільшити лічильник</button>
    </div>
  );
};

export default ChildComponent;

( ) Батьківський компонент викликає функцію incrementCounter, яка змінює стан counter у компонента-батька, і це безпосередньо оновлює лічильник в компоненті-дитині. (x) Компонент-батько ParentComponent має стан counter та функцію incrementCounter, яка змінює стан counter при кожному виклику. Компонент-дитина ChildComponent приймає onButtonClick як пропс та використовує його як зворотній виклик при натисканні на кнопку. Функція incrementCounter змінює стан counter у ParentComponent, відправляючи нове значення з компонента-дитини до компонента-батька через зворотній виклик. При зміні значення counter батьківський компонент ParentComponent буде перемальовуватися, разом з ним перемалюється й ChildComponent. ( ) Компонент-дитина має внутрішній стан counter, який вона безпосередньо змінює при кожному натисканні на кнопку. Це призведе до автоматичної перерендерингу і оновлення компонента-батька ParentComponent.
