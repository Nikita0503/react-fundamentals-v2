What is the advantage of unidirectional data flow in React?


( ) It promotes faster display of state changes in components.
( ) It provides automatic synchronization of states of all components.
(x) It makes debugging and predicting component behavior easier, since data moves in a defined direction - from top to bottom.

If a child component needs to notify the parent component about changes, how can this be done in React?


(x) By using callback functions as props passed to the child component.
( ) By using a global object for data exchange between components.
( ) By using internal component state for automatic notification of the parent component.

What happens in the code?


// Parent component

import React, { useState } from "react";
import ChildComponent from "./ChildComponent";

const ParentComponent = () => {
  const [counter, setCounter] = useState(0);

  // Callback function that changes state in the parent component
  const incrementCounter = () => {
    setCounter(counter + 1);
  };

  return (
    <div>
      <h1>Parent Component</h1>
      <p>Counter: {counter}</p>
      <ChildComponent onButtonClick={incrementCounter} />
    </div>
  );
};

export default ParentComponent;

// Child component

import React from "react";

const ChildComponent = (props) => {
  return (
    <div>
      <h2>Child Component</h2>
      <button onClick={props.onButtonClick}>Increment counter</button>
    </div>
  );
};

export default ChildComponent;

( ) The parent component calls the incrementCounter function, which changes the counter state in the parent component, and this directly updates the counter in the child component. (x) The parent component ParentComponent has a counter state and an incrementCounter function that changes the counter state on each call. The child component ChildComponent accepts onButtonClick as a prop and uses it as a callback when the button is clicked. The incrementCounter function changes the counter state in ParentComponent, sending the new value from the child component to the parent component through the callback. When the counter value changes, the parent component ParentComponent will re-render, and ChildComponent will re-render along with it. ( ) The child component has an internal counter state that it directly changes on each button click. This will lead to automatic re-rendering and updating of the parent component ParentComponent.
