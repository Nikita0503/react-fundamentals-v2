How does a child component communicate with its parent?


( ) By directly modifying the parent's state.
( ) By dispatching a custom DOM event.
(x) By calling a callback function passed via props.

What is the naming convention for callback props?


( ) Prefix with "handle" — handleClick, handleChange, handleSubmit.
(x) Prefix with "on" — onClick, onChange, onSubmit.
( ) Prefix with "cb" — cbClick, cbChange, cbSubmit.

In which direction does data flow in React?


(x) Down — from parent to child via props.
( ) Up — from child to parent via props.
( ) Both directions — props flow freely between parent and child.

In which direction do events flow in React?


( ) Down — from parent to child via event props.
(x) Up — from child to parent via callbacks.
( ) Sideways — between sibling components directly.
