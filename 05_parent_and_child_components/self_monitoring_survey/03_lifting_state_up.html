What does "lifting state up" mean?


( ) Moving state from a parent component into a child component.
(x) Moving shared state to the nearest common parent of the components that need it.
( ) Storing state in a global variable outside of React.

When should you lift state up?


( ) Whenever a component has any state at all.
( ) When a single component needs local UI state like open/closed.
(x) When two or more sibling components need the same data.

What is a "controlled component"?


( ) A component that uses useEffect to control side effects.
( ) A component wrapped in React.memo for performance.
(x) A component that doesn't own its value — the parent controls it via props.

When should you keep state local instead of lifting it up?


(x) When only one component uses the data (e.g., dropdown open/closed, input focus).
( ) Always — state should never be lifted.
( ) When the state changes frequently.
