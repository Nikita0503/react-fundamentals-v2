How is data passed from a parent component to a child component in React?


( ) Stored in the parent component's state and automatically passed to the child component.
( ) Internal variables of the parent component are used, which are automatically available to the child component.
(x) Passed through props when rendering components in JSX.

How can passed data be used in a child component?


( ) Only through internal variables of the child component.
(x) Through props, which are passed as parameters of the child component function.
( ) Only through the child component's state.

How can you access passed data in a child component using props?


(x) By applying destructuring to the props object or accessing directly (props.data).
( ) You always need to use destructuring on the props object, otherwise there will be an error.
( ) Only with destructuring of the props object, direct access is prohibited.

// Parent component
import React from 'react';
import ChildComponent from './ChildComponent';

const ParentComponent = () => {
  const data = 'This is data from the parent component';

  return (
    <div>
      <h1>Parent Component</h1>
      <ChildComponent data={data} />
    </div>
  );
};

export default ParentComponent;

// Child component
import React from 'react';

const ChildComponent = (props) => {

  return (
    <div>
      <h2>Child Component</h2>
      <p>Data from parent component: {props.data}</p>
    </div>
  );
};

export default ChildComponent;
