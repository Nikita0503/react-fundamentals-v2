Як передаються дані з компонента-батька до компонента-дитини в React?


( ) Зберігаються в стані компонента-батька та автоматично передаються компоненту-дитині.
( ) Використовуються внутрішні змінні компонента-батька, які автоматично доступні компоненту-дитині.
(x) Передаються через пропси (props) при рендерингу компонентів у JSX.

Як можна використовувати передані дані в компоненті-дитині?


( ) Тільки за допомогою внутрішніх змінних компонента-дитини.
(x) За допомогою пропсів (props), які передаються як параметри функції компонента-дитини.
( ) Тільки за допомогою стану компонента-дитини.

Як можна отримати доступ до переданих даних в компоненті-дитині, використовуючи пропси?


(x) Застосовуючи деструктуризацію до об'єкта props або отримуючи доступ напряму (props.data).
( ) Завжди потрібно використовувати деструктуризацію до об'єкта props, інакше буде помилка.
( ) Тільки з допомогою деструктуризації до об'єкта props, доступ напряму заборонений.

Що відбувається в коді?


// Батьківський компонент
import React from 'react';
import ChildComponent from './ChildComponent';

const ParentComponent = () => {
  const data = 'Це дані з батьківського компонента';

  return (
    <div>
      <h1>Батьківський компонент</h1>
      <ChildComponent data={data} />
    </div>
  );
};

export default ParentComponent;

// Компонент-дитина
import React from 'react';

const ChildComponent = (props) => {

  return (
    <div>
      <h2>Дитячий компонент</h2>
      <p>Дані з батьківського компонента: {props.data}</p>
    </div>
  );
};

export default ChildComponent;

(X) Батьківський компонент містить дані, які він передає дочірньому компоненту через пропси. Дочірній компонент використовує ці дані для відображення у своєму вмісті. ( ) Дочірній компонент генерує та передає дані до батьківського компонента через пропси, забезпечуючи спрямований потік інформації від дочірнього до батьківського компонента. ( ) У даному випадку батьківський компонент використовує дані, які отримав від дочірнього компонента, для подальшого використання чи обробки.
