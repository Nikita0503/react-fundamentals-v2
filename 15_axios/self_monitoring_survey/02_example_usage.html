How to pass the request body when using the PUT / POST method in Axios?


( ) Pass data directly in the URL (x) Specify body as the second parameter of the axios.put(url, data) / axios.post(url, data) method ( ) Use the body parameter when defining the request configuration in the third parameter

How to specify headers in a request with Axios?


Option 1: 
axios.put('https://jsonplaceholder.typicode.com/posts/1', 
    {
      id: 1,
    },
    {
      'Content-type': 'application/json; charset=UTF-8',
    })
    .then((response) => console.log(response.data))
    .catch((error) => console.log("error: ", error))

Option 2:
axios.put('https://jsonplaceholder.typicode.com/posts/1', 
    {
      id: 1,
      headers: {
        'Content-type': 'application/json; charset=UTF-8',
      },
    })
    .then((response) => console.log(response.data))
    .catch((error) => console.log("error: ", error))

Option 3:
