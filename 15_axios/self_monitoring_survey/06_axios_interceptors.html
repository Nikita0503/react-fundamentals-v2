Що таке інтерсептори в Axios?


( ) Функції, які автоматично роблять повторні запити до серверу у разі повернення помилки (x) Функції, які спрацьовують перед тим, як запит відправиться на сервер та після отримання відповіді ( ) Об'єкти, які містять конфігурації для кожного окремого запиту

Які типи інтерсепторів існують в Axios?


( ) Лише інтерсептори запитів (request) ( ) Лише інтерсептори відповідей (response) (x) Інтерсептори запитів (request) та інтерсептори відповідей (response)

Які завдання можуть бути вирішені за допомогою інтерсепторів Axios?


( ) Визначення URL для кожного окремого запиту ( ) Тільки додавання заголовків до запитів (x) Додавання та оновлення токенів доступу, перевірка статусу відповіді та обробка помилок

Коли викликається інтерсептор request у прикладі роботи з Axios?


(x) Перед тим, як запит буде відправлений на сервер (для модифікації запиту) ( ) Після отримання відповіді від сервера (для обробки відповіді) ( ) В залежності від налаштування

Коли викликається інтерсептор response у прикладі роботи з Axios?


( ) Перед тим, як запит буде відправлений на сервер (для модифікації запиту) (x) Після отримання відповіді від сервера (для обробки відповіді) ( ) В залежності від налаштування
