Що робить функція axios.create() у контексті використання Axios в проекті?


( ) Створює новий запит до сервера (x) Генерує екземпляр Axios ( ) Визначає функцію, яка буде викликатися під час успішного завершення запиту

Які налаштування можна визначити при створенні інстансу Axios за допомогою axios.create()?


( ) Методи запиту, наприклад, get, post, put, delete ( ) Обробник для визначення, як взаємодіяти з відповідями від сервера (x) Налаштування, такі як baseURL і timeout, які залишаються однаковими для всіх запитів, викликаних цим інстансом
