Що таке захищений ендпоінт у контексті роботи з REST API?


( ) Ендпоінт, який недоступний для клієнтів і завжди повертає помилку 403 Forbidden (x) Ендпоінт, доступ до якого вимагає надання додаткових авторизаційних даних, таких як токен доступу (access token) ( ) Ендпоінт, який доступний лише для адміністраторів системи

Як можна передати токен доступу (access token) при використанні Axios?


( ) Токен передається автоматично в кожному запиті, не потрібно додатково нічого робити ( ) Токен додається до параметрів запиту, наприклад, axios.get('https://example.com/api/data?token=your_access_token') (x) Токен передається у заголовках запиту, наприклад, axios.get('https://example.com/api/data', { headers: { 'Authorization': 'Bearer your_access_token' } })

Що таке access token і для чого він використовується при роботі з захищеними ендпоінтами?


( ) Access token - це ідентифікатор клієнта в системі, використовується для входу в особистий кабінет ( ) Access token - це шифрований ключ, який використовується для шифрування даних, переданих між клієнтом і сервером (x) Access token - це токен, який вимагається сервером для авторизації клієнта та отримання доступу до захищених ресурсів

Що таке refresh token і як він використовується при роботі з токенами в контексті безпеки REST API?


( ) Refresh token - це токен, який використовується для входу в систему і отримання доступу до ресурсів (x) Refresh token - це токен, який використовується для оновлення access token після закінчення його терміну дії ( ) Refresh token - це токен, який використовується для шифрування даних, переданих між клієнтом і сервером
