Що таке Axios

Невід'ємною частиною кожного проекта є взаємодія з REST API. Використання звичайного fetch у проектах маленього розміру є прийнятним, але при більших об’ємах взаємодія з сервером зазвичай стає складнішою і код роботи з REST API має становитися гнучнішим для запобігання непередбачуваних помилок. Для зменшення boilerplate коду та збільшення комфорту роботи з сервером використовують одну з найпопулярніших бібліотек - Axios.

Для початку роботи з Axios потрібно зробити 2 кроки:

1) Встановити в проект:

npm install axios

2) Написати компонент, який робить запит до серверу та відображує результат.
