What is Axios

An integral part of every project is interaction with REST API. Using regular fetch in small projects is acceptable, but with larger volumes, server interaction usually becomes more complex and the REST API code needs to become more flexible to prevent unexpected errors. To reduce boilerplate code and increase the comfort of working with the server, one of the most popular libraries is used - Axios.

To start working with Axios, you need to take 2 steps:

1) Install it in the project:

npm install axios

2) Write a component that makes a request to the server and displays the result.
