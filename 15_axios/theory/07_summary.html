Summary

In this module, we covered working with the Axios library, which is used for interacting with REST API. This knowledge will be sufficient for implementing work with various endpoints in projects of different scales.

Possible questions:

"On the Internet, there are code fragments where interceptors are configured directly in axios itself, without creating an axiosInstance. Why create them at all then?"

Answer - in some projects, not 1 server is used for REST API interaction, but several. Each requires different request configuration, so different instances are created. Using instances makes the code predictable. You may need to make a request to an API that doesn't require extra headers or other settings, for which you can use axios directly, without an instance (instead of fetch).
