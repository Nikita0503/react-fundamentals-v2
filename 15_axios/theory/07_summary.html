Axios Instance Config

const httpClient = axios.create({
  baseURL: "https://api.example.com",  // prepended to all URLs
  timeout: 10000,                       // ms before abort
  headers: {                            // default headers
    "Content-Type": "application/json",
  },
  withCredentials: true,                // send cookies cross-origin
});

Interceptor Patterns

// Request: inject auth token
httpClient.interceptors.request.use((config) => {
  const token = localStorage.getItem("accessToken");
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// Response: refresh token on 401
httpClient.interceptors.response.use(
  (response) => response,
  async (error) => {
    if (error.response?.status === 401 && !error.config._retry) {
      error.config._retry = true;
      // refresh token logic...
      return httpClient(error.config);
    }
    return Promise.reject(error);
  }
);

Recommended Architecture

src/api/
  httpClient.ts     // axios instance + interceptors
  users.ts          // usersApi service
  posts.ts          // postsApi service
  types.ts          // API response/request types

Best Practices

  • Always create an instance — never use bare axios.get() in components
  • Type your responses — use generics: httpClient.get<User[]>("/users")
  • Handle errors at two levels — global (interceptor) + local (component)
  • Cancel requests on unmount — use AbortController in useEffect cleanup
  • Use a service layer — group API calls into service objects (usersApi, postsApi)
  • Security note: Don't store tokens in localStorage in production — use httpOnly cookies instead. localStorage is vulnerable to XSS attacks.

What's Next

In real applications, Axios is often combined with React Query (TanStack Query) or RTK Query for:

  • Automatic caching and cache invalidation
  • Request deduplication (same request made by multiple components)
  • Automatic refetching (on window focus, on interval)
  • Built-in loading/error/success states
  • Optimistic updates

Understanding raw Axios patterns is the foundation — React Query builds on top of them.
