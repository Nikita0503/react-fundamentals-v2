Підсумки

В цьому модулі було розглянуто роботу з бібліотекою Axios, що використовується для взаємодії з REST API. Цих знань буде достатьно реалізації роботи з різними едпоінтами у проектах різного масштабу.

Можливі питання:

"В Інтернеті зустрічаються фрагменти коду де interceptors налаштовуються прямо у самому axios, без створення axiosInstance. Для чого їх взагалі тоді створювати?".

Відповідь - у деяких проектах використовується не 1 сервер для взаємодії з REST API, а декілька. Кожен потребує різне налаштування запитів, для цього створюють різні інстанси. З використанням інстансів код стає передбачуваним. Можливо знадобиться робити запит до API, котре не потребує зайвих headers або інших налаштувань, для цього можна використовувати axios напряму, без інстансу (замість fetch).
