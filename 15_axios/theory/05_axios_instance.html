Axios instance

Axios instance - an Axios instance that can be configured to your needs:

/** api/axios.js */

import axios from 'axios';

const axiosInstance = axios.create({
    baseURL: 'https://jsonplaceholder.typicode.com',
    timeout: 10000
});

export default axiosInstance;

axios.create - an instance creation function that accepts an object with settings;

baseURL - stores the common beginning of the request URL. For example: Without specifying baseURL, calling an endpoint using the newly created instance looks like this:

axiosInstanse.get('https://jsonplaceholder.typicode.com/posts/1');

If you specify baseURL:

axiosInstanse.get('/posts/1');

baseURL can store the domain where the server runs, and when calling an endpoint with axiosInstance, you don't need to specify the entire URL, only the remaining part of the endpoint address.

Timeout - the number of milliseconds after which axios will return an error if the response has not been received within this time. Now, by importing axiosInstance into REST API files, you can work with a configured axios.
