Axios instance

Axios instance - екземпляр Axios, котрий можна налаштувати під свої потреби:

/** api/axios.js */

import axios from 'axios';

const axiosInstance = axios.create({
    baseURL: 'https://jsonplaceholder.typicode.com',
    timeout: 10000
});

export default axiosInstance;

axios.create - функція створення інстансу, яка приймає об`єкт з налаштуваннями;

baseURL - зберігає однаковий початок стрічки запиту. Наприклад: Без вказання baseURL виклик ендпоінту використовуючи щойно створений інстанс виглядає так:

axiosInstanse.get('https://jsonplaceholder.typicode.com/posts/1');

Якщо вказати baseURL:

axiosInstanse.get('/posts/1');

baseURL може зберігати домен на якому працює сервер і при виклику ендпоінту з axiosInstance можна не вказувати увесь URL, а тільки залишок адреси ендпоінту.

Timeout - кількість мілісекунд, пілся яких axios поверне помилку, у разі якщо за цей час відповідь не повернулася. Тепер імпортуючи axiosInstance у файли роботи з REST API можна працювати з налаштованим axios.
