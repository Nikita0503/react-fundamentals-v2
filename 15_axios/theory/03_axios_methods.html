Axios Methods

GET - is one of the methods for interacting with REST API. There are methods that send a body (data object) to the server, for example PUT or POST methods:

/** /pages/PostsPage.js */

import React from 'react';

const PostsPage = () => {

  const [post, setPost] = React.useState();

  React.useEffect(() => { 
    fetch('https://jsonplaceholder.typicode.com/posts/1', {
      method: 'PUT',
      headers: {
        'Content-type': 'application/json; charset=UTF-8',
      },
      body: JSON.stringify({
        id: 1,
        title: 'Axios',
        body: 'Axios - promise based HTTP client for the browser and node.js.',
        userId: 1,
      }),
    })
    .then((response) => response.json())
    .then((json) => setPost(json))
    .catch((error) => console.log("error: ", error))
  }, []);


  return (<div>
    {<p>{post?.title}</p>} 
    {<p>{post?.body}</p>}
   </div>);
}

export default PostsPage;

In this example, PostPage has been modified. Now it displays not an array of posts, but a single post returned by the server. It also makes a request with the PUT method, where it passes a post object in the body that we want to place on the server. The server returns in the response the post that we passed in the body. To specify the body type, Content-type: application/json; charset=UTF-8 is specified in the headers.

Now the updated PostsPage using Axios:

/** /pages/PostsPage.js */

import React from 'react';
import axios from 'axios';

const PostsPage = () => {

  const [post, setPost] = React.useState();

  React.useEffect(() => { 
    axios.put('https://jsonplaceholder.typicode.com/posts/1', 
    {
      id: 1,
      title: 'Axios',
      body: 'Axios - promise based HTTP client for the browser and node.js.',
      userId: 1,
    },
    {
      headers: {
        'Content-type': 'application/json; charset=UTF-8',
      },
    })
    .then((response) => setPost(response.data))
    .catch((error) => console.log("error: ", error))
  }, []);


  return (<div>
    {<p>{post?.title}</p>}
    {<p>{post?.body}</p>}
  </div>);
}

export default PostsPage;

axios.put accepts the body as the second parameter, and headers are specified as a field of the object accepted as the third parameter.

This is what basic Axios usage looks like, without its main advantages - interceptors and instances.
