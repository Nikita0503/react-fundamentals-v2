Методи Axios

GET - один з методів взаємодії з REST API. Існують методи, які передають body (об’єкт даних) на сервер, наприклад PUT або POST методи:

/** /pages/PostsPage.js */

import React from 'react';

const PostsPage = () => {

  const [post, setPost] = React.useState();

  React.useEffect(() => { 
    fetch('https://jsonplaceholder.typicode.com/posts/1', {
      method: 'PUT',
      headers: {
        'Content-type': 'application/json; charset=UTF-8',
      },
      body: JSON.stringify({
        id: 1,
        title: 'Axios',
        body: 'Axios - promise based HTTP client for the browser and node.js.',
        userId: 1,
      }),
    })
    .then((response) => response.json())
    .then((json) => setPost(json))
    .catch((error) => console.log("error: ", error))
  }, []);


  return (<div>
    {<p>{post?.title}</p>} 
    {<p>{post?.body}</p>}
   </div>);
}

export default PostsPage;

У цьому прикладі PostPage змінений. Зараз він відображає не масив постів, а один пост, котрий повертає сервер. Також він робить запит з PUT методом, де в body передає об’єкт посту, котрий ми хочемо розмістити на сервері. Сервер віддає у відповіді той пост, який ми передали в body. Для того щоб указати тип body в headers вказано Content-type: application/json; charset=UTF-8.

Тепер оновлений PostsPage з використанням Axios:

/** /pages/PostsPage.js */

import React from 'react';
import axios from 'axios';

const PostsPage = () => {

  const [post, setPost] = React.useState();

  React.useEffect(() => { 
    axios.put('https://jsonplaceholder.typicode.com/posts/1', 
    {
      id: 1,
      title: 'Axios',
      body: 'Axios - promise based HTTP client for the browser and node.js.',
      userId: 1,
    },
    {
      headers: {
        'Content-type': 'application/json; charset=UTF-8',
      },
    })
    .then((response) => setPost(response.data))
    .catch((error) => console.log("error: ", error))
  }, []);


  return (<div>
    {<p>{post?.title}</p>}
    {<p>{post?.body}</p>}
  </div>);
}

export default PostsPage;

axios.put приймає body другим параметром, а headers вказується як поле об`єкта, який приймається третім параметром.

Так виглядає базове використання Axios, без його головних переваг - інтерсепторів та інстансів.

Перед цим треба згадати як влаштована безпека при роботі з REST API.
