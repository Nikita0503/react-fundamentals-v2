Security when working with REST API

There is a concept of a protected endpoint. To access a resource on the server, the client must provide additional data that will indicate to the server that this client is authorized. In most cases, this is the Authorization header, which looks approximately like this:

The huge string of characters is an access token. It contains data about the client making the request to the endpoint. The server decrypts the token and decides whether this client has access to the resource.

There is a similar token - the refresh token. The access token has an expiration period, after which it is considered invalid and the server will not allow the client to access the resource with it. Therefore, there are additional endpoints on the server that help create a new access token by providing the refresh token.

It looks approximately like this:

axios.post('https://myserver.com/generate_access_token', {
    'access_token': '…',
    'refresh_token': '…',
}).
then((reponse) => {
    //response: {new_access_token: '….'}
})
.catch((e) => {console.log("error: ", e)})

After receiving the new access_token, the client again has access to protected endpoints. Without going into details - the token pair is needed to increase security.

Usually, token refresh occurs when one of the protected endpoints returns an error indicating that the access token is no longer valid (expired). On the client side, in catch, we intercept this error and make a request to refresh the access token. After receiving the new token, we retry the failed request with the new access token.

This happens in such a way that the user does not notice this process. But the project developer can clearly see it, because with a large number of requests to different endpoints, they must apply this mechanism to each protected endpoint, which generates a large amount of boilerplate code.

Of course, you can independently develop a class that can do this and use it when making requests to the server. But in Axios, implementing this process is much easier and faster.
