Why Axios

Axios is a promise-based HTTP client for both browser and Node.js. It wraps HTTP requests with a developer-friendly API that eliminates the boilerplate of raw fetch.

Installation

npm install axios

Why Axios over raw fetch

  • Automatic JSON parsing — response.data is already parsed, no .json() call needed
  • Automatic error throwing — 4xx/5xx responses go to catch automatically
  • Request/response interceptors — inject auth tokens, handle errors globally
  • Request cancellation — AbortController support built-in
  • Timeout configuration — simple timeout option
  • Instance creation — pre-configure baseURL, headers, defaults
  • Better TypeScript support — generics for typing responses

fetch vs axios — Same Request

interface User {
  id: number;
  name: string;
  email: string;
}

// fetch — verbose
const response = await fetch("/api/users");
if (!response.ok) throw new Error(`${response.status}`);
const users: User[] = await response.json();

// axios — concise
const { data: users } = await axios.get<User[]>("/api/users");
// That's it. Errors auto-throw, JSON auto-parsed.

Axios Methods

import axios from "axios";

// GET — retrieve data
axios.get<T>(url, config?)

// POST — create resource
axios.post<T>(url, data?, config?)

// PUT — replace resource
axios.put<T>(url, data?, config?)

// PATCH — partial update
axios.patch<T>(url, data?, config?)

// DELETE — remove resource
axios.delete<T>(url, config?)

TypeScript Generics — Type the Response

// The generic parameter types response.data
const { data } = await axios.get<User[]>("/api/users");
// data is typed as User[]

const { data } = await axios.get<User>("/api/users/1");
// data is typed as User

POST/PUT with Body

interface CreateUserDto {
  name: string;
  email: string;
}

// POST — second argument is the request body (auto-serialized to JSON)
const { data } = await axios.post<User>("/api/users", {
  name: "Alice",
  email: "alice@test.com",
});

// PUT — replace entire resource
const { data } = await axios.put<User>("/api/users/1", {
  name: "Alice Updated",
  email: "alice.new@test.com",
});

Full Component Example

import { useState, useEffect } from "react";
import axios from "axios";

interface Post {
  id: number;
  title: string;
  body: string;
}

const PostList = () => {
  const [posts, setPosts] = useState<Post[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    const loadPosts = async () => {
      try {
        const { data } = await axios.get<Post[]>(
          "https://jsonplaceholder.typicode.com/posts"
        );
        setPosts(data);
      } catch (err) {
        setError("Failed to load posts");
      } finally {
        setLoading(false);
      }
    };

    loadPosts();
  }, []);

  if (loading) return <p>Loading...</p>;
  if (error) return <p>{error}</p>;

  return (
    <ul>
      {posts.map((post) => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  );
};
