Usage Example

To work with a server, we'll use the JSONPlaceholder API. This is a free resource that allows making requests and processing their responses:

/** /pages/PostsPage.tsx */

import React from 'react';

type Post = {
  id: number;
  title: string;
  body: string;
  userId: number;
};

const PostsPage = () => {

  const [posts, setPosts] = React.useState<Post[]>([]);

  React.useEffect(() => { 
    fetch('https://jsonplaceholder.typicode.com/posts?userId=1')
      .then((response) => response.json())
      .then((data: Post[]) => setPosts(data))
      .catch((error) => console.log('error: ', error));
  }, []);


  return(<div>
      {posts.map((post) => <p key={post.id}>{post.title}</p>)}
  </div>);
}

export default PostsPage;

The component makes a request to

https://jsonplaceholder.typicode.com/posts?userId=1

And saves the response in the reactive variable posts and displays its value (an array of posts).

Now using Axios:

/** /pages/PostsPage.tsx */

import React from 'react';
import axios from 'axios';

type Post = {
  id: number;
  title: string;
  body: string;
  userId: number;
};

const PostsPage = () => {

  const [posts, setPosts] = React.useState<Post[]>([]);

  React.useEffect(() => { 
    axios.get<Post[]>('https://jsonplaceholder.typicode.com/posts?userId=1')
      .then((response) => setPosts(response.data))
      .catch((error) => console.log("error: ", error));
  }, []);


  return (<div>
      {posts.map((post) => <p key={post.id}>{post.title}</p>)}
  </div>);
}

export default PostsPage;

Axios is imported from the package of the same name. This object has the necessary set of methods for working with REST API. In the example, when making a request to the server, the GET method is used:

axios.get<Post[]>('https://jsonplaceholder.typicode.com/posts?userId=1')

Processing the server response is more convenient than when using regular fetch. There is no need for an extra then chain to get the data returned by the server. Axios, after processing the first promise, returns it in the data field (response.data). All other response details are in the same response, for example response.status (200).
