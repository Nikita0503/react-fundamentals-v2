Приклад використання

Для роботи з сервером використаємо JSONPlaceholder API. Це безкоштовний ресурс, котрий дозволяє робити запити та обробляти їх відповіді:

/** /pages/PostsPage.js */

import React from 'react';

const PostsPage = () => {

  const [posts, setPosts] = React.useState([]);

  React.useEffect(() => { 
    fetch('https://jsonplaceholder.typicode.com/posts?userId=1')
      .then((response) => response.json())
      .then((data) => setPosts(data))
      .catch((error) => console.log('error: ', error));
  }, []);


  return(<div>
      {posts.map((post) => <p key={post.id}>{post.title}</p>)}
  </div>);
}

export default PostsPage;

Компонент робить запит до

https://jsonplaceholder.typicode.com/posts?userId=1

Та зберігає відповідь у реактивну змінну posts і відображає її значення (масив постів).

Тепер з використанням Axios:

/** /pages/PostsPage.js */

import React from 'react';
import axios from 'axios';

const PostsPage = () => {

  const [posts, setPosts] = React.useState([]);

  React.useEffect(() => { 
    axios.get('https://jsonplaceholder.typicode.com/posts?userId=1')
      .then((response) => setPosts(response.data))
      .catch((error) => console.log("error: ", error));
  }, []);


  return (<div>
      {posts.map((post) => <p key={post.id}>{post.title}</p>)}
  </div>);
}

export default PostsPage;

Axios імпортується з одноіменного пакету. Цей об`єкт має необхідний набір методів для роботи з REST API. В приколаді, при звертанні до серверу, використовується GET метод:

axios.get('https://jsonplaceholder.typicode.com/posts?userId=1')

Опрацювання відповіді серверу зручніше ніж при використанні звичайного fetch. Не потрібно робити зайву ланку then для отримання даних що повертає сервер. Axios після обробки першого промісу повертає це в полі data (response.data). Всі інші деталі відповіді знаходятся у тому ж response, наприклад reponse.status (200).
