HTTP Basics

HTTP (HyperText Transfer Protocol) is the foundation of client-server communication on the web. Every time your React app fetches data from a server, it uses HTTP.

Request Structure

Every HTTP request consists of:

  • Method — what action to perform (GET, POST, PUT, etc.)
  • URL — the address of the resource
  • Headers — metadata (Content-Type, Authorization, etc.)
  • Body — data sent to the server (not all methods have a body)

Response Structure

Every HTTP response consists of:

  • Status code — numeric indicator of the result (200, 404, 500, etc.)
  • Headers — metadata about the response
  • Body — the data returned (usually JSON)

Status Codes

2xx — Success:

  • 200 OK — request succeeded
  • 201 Created — new resource was created
  • 204 No Content — success, but no body in response

3xx — Redirect:

  • 301 Moved Permanently — resource has a new URL
  • 304 Not Modified — cached version is still valid

4xx — Client Error:

  • 400 Bad Request — malformed request
  • 401 Unauthorized — authentication required
  • 403 Forbidden — authenticated but not allowed
  • 404 Not Found — resource does not exist
  • 422 Unprocessable Entity — validation failed

5xx — Server Error:

  • 500 Internal Server Error — something broke on the server
  • 503 Service Unavailable — server is temporarily down

Common Headers

  • Content-Type — describes the format of the body (e.g., application/json)
  • Authorization — carries authentication credentials (e.g., Bearer <token>)
  • Accept — tells the server what format the client expects in the response

What is REST API

REST (Representational State Transfer) is an architectural style for APIs:

  • Resources as URLs — each entity has a unique address (e.g., /users, /users/123)
  • HTTP methods as operations — GET reads, POST creates, PUT/PATCH updates, DELETE removes
  • Stateless — each request contains all information needed; the server doesn't store session state between requests

JSON as the Standard Format

JSON (JavaScript Object Notation) is the standard data format for REST APIs. Both request bodies and response bodies are typically JSON:

// Example JSON response from GET /users/1
{
  "id": 1,
  "name": "Alice",
  "email": "alice@example.com"
}
