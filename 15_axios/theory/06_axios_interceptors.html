Axios інтерсептори

Інтерсептори - функції, котрі спрацьовують перед запитом та пілся отримання відповіді. Вони так і звуться:

Interceptor request - спрацьовує перед тим як запит піде до серверу;

Interceptor response - спрацьовує одразу після отримання відповіді (ще до того як ви оброблюєте відповідь).

Інтерсептор request

Interceptor request зазвичай використовують для додавання токену у header Authorization:

/** api/axios.js */

import axios from 'axios';

const axiosInstance = axios.create({
    baseURL: 'https://jsonplaceholder.typicode.com',
    timeout: 10000
});

axiosInstance.interceptors.request.use(async (config) => {
    const token = localStorage.getItem('accessToken');

    if(token){
        config.headers['Authorization'] = 'Bearer ' + token
    }

    return config;
},
(error) => {
    Promise.reject(error);
})

export default axiosInstance;

axiosInstance.interceptors.request.use - приймає функцію-коллбек першим параметром, яка відпрацює перед відправкою запиту на сервер. Вона має параметр config, котрий можна модифікувати на повернути.

В прикладі модифікований config має додатковий header Authorization, який містить токен доступу до захищених ендпоінтів серверу. Якщо такий токен є у localStorage, ми додаємо header, якщо ні - залишаємо все без змін. В кінці обов’язково повертаємо модифікований config.

Зараз при кожному виклику якогось методу axiosInstance, буде відпрацьовувати interceptor request та додаватиме header Authorization до запиту.

Інтерсептор response

Процес оновлення access token відбувається у interceptor response:

axiosInstance.interceptors.response.use(
  (response) => {
    return response; // цей колбек відпрацює, коли відповідь успішна. Відповідь йде далі у then (там де response.data - дані з серверу)
  },
  async (error) => { // цей колбек відпрацює, коли відповідь містить помилку
    const originalRequest = error.config;

    // Перевіряємо чи помилка сталася через прострочений access token, спробуємо його оновити
    if (error.response.status === 401 && !originalRequest._retry) { // код 401 свідчить про невалідність токену, також вважається як «unauthorized», тобто користувач неавторизований
      originalRequest._retry = true; // Встановіть прапорець _retry, щоб запобігти нескінченного циклу

      const refreshToken = localStorage.getItem('refreshToken');
      try {
        if (!refreshToken) { // Якщо немає refresh token, відхиліть спробу та переспрямуйте на сторінку входу (разлогініть користувача) або покажіть повідомлення про помилку
          return Promise.reject(error); 
        }
        const response = await axios.post('https://yourserver/auth/refresh', { refreshToken }); // Надсилаємо запит на сервер для оновлення accessToken
       
        // оновлюємо accessToken у сховищі
        const accessToken = response.data.accessToken;
        localStorage.setItem('accessToken', accessToken);

        originalRequest.headers.Authorization = `Bearer ${accessToken}`; // Оновлюємо поточний запит з новим access token
        return axiosInstance(originalRequest); // Повторюємо запит з новим токеном доступу
      } catch (refreshError) {
        // Сталася помилка оновлення токену, далі разлогінюємо користувача
        return Promise.reject(refreshError);
      }
    }

    return Promise.reject(error);
  }
);

axiosInstance.interceptors.response.use - приймає другим параметром функцію-колбек, яка відпрацює у разі поверненням серверу помилки. Вона має параметр error, котрий містать інформацію про помилку.

Для початківців цей процес здається заскладним.

На початку шляху деякі деталі можуть бути незрозумілими, але з часом все стає прозорим. Налаштуванням axios частіше займаються більш досвідчені інженери, але мати приблизне розуміння як це працює варто. Приклад вище відображає загальний випадок опрацювання токенів.

Кожен проект - окремий Всесвіт, де щось може працювати трішки інакше. Але переважна більшість цієї частини коду всеодно співпаде з прикладом.

Приклад створення та налаштування

Весь код прикладу створення та налаштування axiosInstance:

/** api/axios.js */

import axios from "axios";

const axiosInstance = axios.create({
    baseURL: 'https://jsonplaceholder.typicode.com',
    timeout: 10000
});

axiosInstance.interceptors.request.use(async (config) => {
    const token = 'qwerty';
    if(token){
        config.headers['Authorization'] = 'Bearer ' + token
    }
    return config;
},
(error) => {
    Promise.reject(error);
});

axiosInstance.interceptors.response.use((response) => {return response}, async (error) => {
    const originalRequest = error.config;
    if (error.response.status === 401 && !originalRequest._retry) {
        originalRequest._retry = true;
        const refreshToken = localStorage.getItem('refreshToken');
        try {
            if (!refreshToken) {
                return Promise.reject(error); 
            }
            const response = await axios.post('https://yourserver/auth/refresh', { refreshToken });
            const accessToken = response.data.accessToken;
            localStorage.setItem('accessToken', accessToken);
            originalRequest.headers.Authorization = `Bearer ${accessToken}`;
            return axiosInstance(originalRequest); 
        } catch (refreshError) {
            return Promise.reject(refreshError);
        }
    }
    return Promise.reject(error);
});

export default axiosInstance;
