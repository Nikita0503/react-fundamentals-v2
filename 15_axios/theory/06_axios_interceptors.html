Axios Interceptors

Interceptors - functions that execute before a request and after receiving a response. They are called:

Interceptor request - executes before the request goes to the server;

Interceptor response - executes immediately after receiving the response (even before you process the response).

Request Interceptor

Interceptor request is usually used to add a token to the Authorization header:

/** api/axios.js */

import axios from 'axios';

const axiosInstance = axios.create({
    baseURL: 'https://jsonplaceholder.typicode.com',
    timeout: 10000
});

axiosInstance.interceptors.request.use(async (config) => {
    const token = localStorage.getItem('accessToken');

    if(token){
        config.headers['Authorization'] = 'Bearer ' + token
    }

    return config;
},
(error) => {
    Promise.reject(error);
})

export default axiosInstance;

axiosInstance.interceptors.request.use - accepts a callback function as the first parameter that will execute before sending the request to the server. It has a config parameter that can be modified and returned.

In the example, the modified config has an additional Authorization header that contains the access token for protected server endpoints. If such a token exists in localStorage, we add the header; if not, we leave everything unchanged. At the end, we must return the modified config.

Now with every call to any axiosInstance method, the interceptor request will execute and add the Authorization header to the request.

Response Interceptor

The access token refresh process occurs in the interceptor response:

axiosInstance.interceptors.response.use(
  (response) => {
    return response; // this callback executes when the response is successful. The response goes further to then (where response.data contains server data)
  },
  async (error) => { // this callback executes when the response contains an error
    const originalRequest = error.config;

    // Check if the error occurred due to an expired access token, try to refresh it
    if (error.response.status === 401 && !originalRequest._retry) { // code 401 indicates token invalidity, also considered as "unauthorized", meaning the user is not authorized
      originalRequest._retry = true; // Set the _retry flag to prevent an infinite loop

      const refreshToken = localStorage.getItem('refreshToken');
      try {
        if (!refreshToken) { // If there is no refresh token, reject the attempt and redirect to the login page (log out the user) or show an error message
          return Promise.reject(error); 
        }
        const response = await axios.post('https://yourserver/auth/refresh', { refreshToken }); // Send a request to the server to refresh the accessToken
       
        // update the accessToken in storage
        const accessToken = response.data.accessToken;
        localStorage.setItem('accessToken', accessToken);

        originalRequest.headers.Authorization = `Bearer ${accessToken}`; // Update the current request with the new access token
        return axiosInstance(originalRequest); // Retry the request with the new access token
      } catch (refreshError) {
        // Token refresh error occurred, log out the user
        return Promise.reject(refreshError);
      }
    }

    return Promise.reject(error);
  }
);

axiosInstance.interceptors.response.use - accepts a callback function as the second parameter that will execute when the server returns an error. It has an error parameter that contains information about the error.

For beginners, this process may seem overly complex.

At the beginning of the journey, some details may be unclear, but over time everything becomes transparent. Axios configuration is more often handled by more experienced engineers, but having a general understanding of how it works is worthwhile. The example above shows the general case of token handling.

Every project is a separate Universe where something may work slightly differently. But the vast majority of this part of the code will still match the example.

Creation and configuration example

The complete code example for creating and configuring axiosInstance:

/** api/axios.js */

import axios from "axios";

const axiosInstance = axios.create({
    baseURL: 'https://jsonplaceholder.typicode.com',
    timeout: 10000
});

axiosInstance.interceptors.request.use(async (config) => {
    const token = 'qwerty';
    if(token){
        config.headers['Authorization'] = 'Bearer ' + token
    }
    return config;
},
(error) => {
    Promise.reject(error);
});

axiosInstance.interceptors.response.use((response) => {return response}, async (error) => {
    const originalRequest = error.config;
    if (error.response.status === 401 && !originalRequest._retry) {
        originalRequest._retry = true;
        const refreshToken = localStorage.getItem('refreshToken');
        try {
            if (!refreshToken) {
                return Promise.reject(error); 
            }
            const response = await axios.post('https://yourserver/auth/refresh', { refreshToken });
            const accessToken = response.data.accessToken;
            localStorage.setItem('accessToken', accessToken);
            originalRequest.headers.Authorization = `Bearer ${accessToken}`;
            return axiosInstance(originalRequest); 
        } catch (refreshError) {
            return Promise.reject(refreshError);
        }
    }
    return Promise.reject(error);
});

export default axiosInstance;
