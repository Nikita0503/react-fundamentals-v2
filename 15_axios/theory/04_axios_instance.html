Axios Instance

In real projects, you don't use bare axios.get() with a full URL every time. Instead, you create a pre-configured instance that holds your base URL, timeout, and default headers.

Creating an Instance

// api/httpClient.ts
import axios from "axios";

export const httpClient = axios.create({
  baseURL: "https://api.example.com",
  timeout: 10000,
  headers: {
    "Content-Type": "application/json",
  },
});

Using the Instance

import { httpClient } from "./api/httpClient";

// Request goes to https://api.example.com/users
const { data } = await httpClient.get<User[]>("/users");

// Request goes to https://api.example.com/users/1
const { data } = await httpClient.get<User>("/users/1");

Multiple Instances for Different APIs

// api/httpClient.ts
import axios from "axios";

export const mainApi = axios.create({
  baseURL: "https://api.example.com",
  timeout: 10000,
});

export const analyticsApi = axios.create({
  baseURL: "https://analytics.example.com",
  timeout: 5000,
});

Instance Config Options

OptionDescription
baseURLPrepended to all relative URLs
timeoutMilliseconds before request is aborted
headersDefault headers sent with every request
withCredentialsSend cookies with cross-origin requests
paramsDefault query parameters

Recommended File Structure

src/
  api/
    httpClient.ts      // axios instance + interceptors
    users.ts           // user-related API functions
    posts.ts           // post-related API functions
    types.ts           // API request/response types

API Service Layer Pattern

Group related API calls into a service object. This keeps your components clean — they call usersApi.getAll() instead of knowing about URLs and HTTP methods:

// api/users.ts
import { httpClient } from "./httpClient";

interface User {
  id: string;
  name: string;
  email: string;
}

interface CreateUserDto {
  name: string;
  email: string;
}

interface UpdateUserDto {
  name?: string;
  email?: string;
}

export const usersApi = {
  getAll: () =>
    httpClient.get<User[]>("/users"),

  getById: (id: string) =>
    httpClient.get<User>(`/users/${id}`),

  create: (data: CreateUserDto) =>
    httpClient.post<User>("/users", data),

  update: (id: string, data: UpdateUserDto) =>
    httpClient.put<User>(`/users/${id}`, data),

  delete: (id: string) =>
    httpClient.delete(`/users/${id}`),
};

Now in your component:

import { usersApi } from "./api/users";

// Clean and readable
const { data } = await usersApi.getAll();
const { data } = await usersApi.getById("123");
await usersApi.create({ name: "Alice", email: "alice@test.com" });
