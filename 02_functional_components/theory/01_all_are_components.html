In React Everything is Components

Components in React are isolated, reusable blocks of code that contain logic and interface rendering. They can be used to create various interface elements, such as buttons, forms, lists, headers, cards, etc.

Each component can have its own state, properties (props), and methods that allow it to interact with other components and change what is displayed on the screen.

// SomeComponent.tsx
import React from 'react';

const SomeComponent = () => {
  const [count, setCount] = React.useState(0);
  
  const handleClick = () => {
    setCount(count + 1);
  }
  
  return(
    <div>
      <div>Count: {count}</div>
      <button onClick={handleClick}>Increment</button>
    </div>
  )
};
  
export default SomeComponent;
// App.tsx
import React from 'react';
import SomeComponent from './components/SomeComponent';

const App = () => {

  return(
    <div>
      <span>My first component:</span>
      <SomeComponent/>
    </div>
  )
};

export default App;

Components in React can be nested within each other, forming a tree-like structure known as the "component tree". The main parent component that contains all other components is known as the "root component".

In this example, SomeComponent is a child component of App. Meanwhile, the App component is the parent component for SomeComponent.

Creating and using components is the main approach to interface development in React, which allows building scalable, maintainable, and efficient web applications.

One of the advantages of using components in React is their reusability. Components can be used on different pages, in different projects, or even in different applications, simplifying development and code maintenance.

// App.tsx
import React from 'react';
import SomeComponent from './components/SomeComponent';

const App = () => {

  return(
    <div>
      <span>My first component:</span>
      <SomeComponent/>
      <span>My first component again:</span>
      <SomeComponent/>
      <span>My first component one more time:</span>
      <SomeComponent/>
    </div>
  )
};

export default App;
