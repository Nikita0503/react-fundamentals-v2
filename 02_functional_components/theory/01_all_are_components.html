В React усе є компонентами

Компоненти в React - це відокремлені, повторно використовувані блоки коду, які містять логіку та відображення інтерфейсу. Вони можуть бути використані для створення різних елементів інтерфейсу, таких як кнопки, форми, списки, заголовки, картки тощо.

Кожен компонент може мати свій власний стан (state), властивості (props) і методи, що дозволяють йому взаємодіяти з іншими компонентами та змінювати відображення на екрані.

import React from 'react';

const SomeComponent = () => {
  const [count, setCount] = React.useState(0);
  
  const handleClick = () => {
    setCount(count + 1);
  }
  
  return(
    <div>
      <div>Count: {count}</div>
      <button onClick={handleClick}>Increment</button>
    </div>
  )
};
  
export default SomeComponent;
import React from 'react';
import SomeComponent from './components/SomeComponent';

const App = () => {

  return(
    <div>
      <span>Мій перший компонент:</span>
      <SomeComponent/>
    </div>
  )
};

export default App;

Компоненти в React можуть бути вкладені один в одного, утворюючи деревоподібну структуру, відому як "дерево компонентів". Головний батьківський компонент, що містить всі інші компоненти, відомий як "кореневий компонент" або "головний компонент" (root component).

На цьому прикладі SomeComponent є дочірнім компонентом для App. Тим часом компонент App для SomeComponent є батьківским компонентом.

Результат:

Створення і використання компонентів є основним підходом до розробки інтерфейсу в React, що дозволяє створювати масштабовані, підтримувані та ефективні веб-додатки.

Одна з переваг використання компонентів в React полягає в їх повторному використанні. Компоненти можуть бути використані на різних сторінках, в різних проектах або навіть в різних додатках, спрощуючи розробку та підтримку коду.

import React from 'react';
import SomeComponent from './components/SomeComponent';

const App = () => {

  return(
    <div>
      <span>Мій перший компонент:</span>
      <SomeComponent/>
      <span>Знову мій перший компонент:</span>
      <SomeComponent/>
      <span>Ще раз мій перший компонент:</span>
      <SomeComponent/>
    </div>
  )
};

export default App;
