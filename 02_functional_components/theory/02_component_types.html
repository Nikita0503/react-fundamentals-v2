Види компонентів

Компоненти можна умовно розділити на 2 частини: Прості компоненти (Dumb components) та Розумні компоненти (Smart components).

Прості компоненти

Прості компоненти також називаються «презентаційними» компонентами, тому що їх єдиний обов'язок представляти щось у DOM. Як тільки це буде зроблено, з компонентом буде покінчено. Не траба стежити за ним, не перевіряти час від часу, щоб подивитися, як ідуть справи. Розмістіть інформацію на сторінці та рухайтеся далі:

import React from 'react';

const SimpleComponent = () => {
  return <div>Hello, React!</div>;
};

export default SimpleComponent;

Розумні компоненти

Розумні компоненти (або компоненти-контейнери), з іншого боку, несуть іншу відповідальність. Оскільки на них лягає тягар бути розумними, вони стежать за станом і дбають про те, як працює програма.

Зважаючи на оновлення React 16.8, було введено поняття хуків (hooks), які дозволяють використовувати стан та функціональні можливості в функціональних компонентах, що робить їх більш потужними та зручними. Ось приклад використання функціональних компонентів з використанням хуків в React:

import React, { useState } from 'react';

const SmartComponent = () => {
  const [count, setCount] = useState(0); // Використання хука useState для стану

  const handleClick = () => {
    setCount(count + 1); // Оновлення стану за допомогою setCount
  }

  return (
    <div>
      <div>Count: {count}</div>
      <button onClick={handleClick}>Increment</button>
    </div>
  );
};

export default SmartComponent;

У цьому прикладі ми використали хук useState, який дозволяє використовувати стан в функціональному компоненті. Ми використовуємо деструктуризацію масиву для отримання поточного значення стану count та функції setCount для оновлення стану.

Також, ми використали функціональний підхід до визначення компонента, де ми повертаємо JSX (розмітка HTML + CSS, в якій можна використовувати вирази javascript у фігурних { } дужках) відразу з функції, що робить цей компонент функціональним.

Цей підхід з використанням функціональних компонентів та хуків дозволяє створювати більш прості та зрозумілі компоненти, які можуть керувати станом та взаємодіяти з іншими компонентами, без використання класів та методів життєвого циклу.
