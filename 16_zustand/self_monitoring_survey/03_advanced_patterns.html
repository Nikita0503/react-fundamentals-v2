Why should you use a selector function when accessing the store?


( ) It makes the code more readable ( ) It is required by TypeScript for type inference (x) To subscribe only to specific state — prevents unnecessary re-renders ( ) It enables server-side rendering support

What does the persist middleware do?


( ) Keeps the store in memory even after the component unmounts ( ) Sends state changes to a backend API automatically (x) Automatically saves state to localStorage and restores it on page reload ( ) Prevents state from being reset during hot module replacement
