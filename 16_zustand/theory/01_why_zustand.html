The Problem with Existing Solutions

Context API:

  • Works for simple cases, but ALL consumers re-render when the context value changes
  • No built-in selectors — you can't subscribe to a specific part of the value
  • Provider nesting becomes unwieldy as the app grows

Redux Toolkit:

  • Powerful but verbose for simple state
  • configureStore, createSlice, Provider, typed hooks — requires many files and configuration steps even for simple state like a counter

Zustand:

  • Minimal API, no Provider needed
  • Built-in selectors — components subscribe to specific parts of state
  • No boilerplate

What is Zustand

A small, fast, scalable state management library for React. The name means "state" in German.

Key Selling Points

  • No Provider wrapper needed — the store lives outside the React tree
  • Built-in selectors — components only re-render when their selected state changes
  • Tiny bundle size — ~1KB
  • DevTools support — via middleware (works with Redux DevTools)
  • Middleware ecosystem — persist, immer, devtools
  • TypeScript-first

When to Use What (Decision Guide)

ScenarioTool
Theme, locale, auth (rarely changes)Context
Simple shared client state (UI state, filters, modals)Zustand
Complex state with many slices, middleware needs, large teamRedux Toolkit
Server state (API data, caching, refetching)TanStack Query

Installation

npm install zustand

That's it. No additional packages, no Provider setup, no boilerplate files.

Zustand (minimal):

import { create } from "zustand";

type CounterStore = {
  count: number;
  increment: () => void;
  decrement: () => void;
  reset: () => void;
};

const useCounterStore = create<CounterStore>((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  decrement: () => set((state) => ({ count: state.count - 1 })),
  reset: () => set({ count: 0 }),
}));

// Usage in any component — no Provider needed:
const Counter = () => {
  const count = useCounterStore((state) => state.count);
  const increment = useCounterStore((state) => state.increment);
  return <button onClick={increment}>Count: {count}</button>;
};

15 lines for the store. No Provider. No boilerplate. Just works.
