The create Function

The create function creates a store and returns a hook:

import { create } from "zustand";

type Store = {
  // state (data)
  // actions (functions that change the data)
};

const useStore = create<Store>((set, get) => ({
  // initial state values + action implementations
}));

What is an Action in Zustand?

An action is simply a function inside the store that changes state. It's not a separate object like in Redux — just a regular function that calls set():

// Pattern: actionName: (parameters) => set(newStateOrUpdater)

const useStore = create<Store>((set) => ({
  count: 0,                                        // ← state
  increment: () => set({ count: 1 }),              // ← action (no params)
  setCount: (value: number) => set({ count: value }), // ← action (with param)
}));

set — How to Update State

set is the function you call inside actions to update the store. It has two forms:

// Form 1: pass an object — merges with current state
set({ count: 5 })
// If state was { count: 0, name: "Alice" }
// Result:      { count: 5, name: "Alice" } — shallow merge, other fields stay

// Form 2: pass a function — receives current state, return new partial state
set((state) => ({ count: state.count + 1 }))
// Use this when new value depends on the previous value

Key difference from Redux: no need to spread (...state). Zustand merges automatically. You only return the fields you want to change.

get — How to Read Current State

get returns the current state at the moment you call it. Use it when an action needs to read state before deciding what to do:

const useStore = create<Store>((set, get) => ({
  items: [],

  addItem: (item) => {
    const currentItems = get().items; // read current state
    if (currentItems.length >= 10) return; // don't add if already 10 items
    set({ items: [...currentItems, item] });
  },
}));

You don't need get often — most actions just call set. Use get when you need to check or read state before updating.

State + Actions Together

Zustand keeps state and actions in one place (like a slice):

type Todo = { id: number; text: string; done: boolean };

type TodoStore = {
  todos: Todo[];
  addTodo: (text: string) => void;
  toggleTodo: (id: number) => void;
  removeTodo: (id: number) => void;
};

const useTodoStore = create<TodoStore>((set) => ({
  todos: [],

  addTodo: (text) =>
    set((state) => ({
      todos: [...state.todos, { id: Date.now(), text, done: false }],
    })),

  toggleTodo: (id) =>
    set((state) => ({
      todos: state.todos.map((t) =>
        t.id === id ? { ...t, done: !t.done } : t
      ),
    })),

  removeTodo: (id) =>
    set((state) => ({
      todos: state.todos.filter((t) => t.id !== id),
    })),
}));

Using in Components

const TodoList = () => {
  const todos = useTodoStore((state) => state.todos);
  const toggleTodo = useTodoStore((state) => state.toggleTodo);
  const removeTodo = useTodoStore((state) => state.removeTodo);

  return (
    <ul>
      {todos.map((todo) => (
        <li key={todo.id}>
          <input
            type="checkbox"
            checked={todo.done}
            onChange={() => toggleTodo(todo.id)}
          />
          <span>{todo.text}</span>
          <button onClick={() => removeTodo(todo.id)}>Delete</button>
        </li>
      ))}
    </ul>
  );
};

const AddTodo = () => {
  const addTodo = useTodoStore((state) => state.addTodo);
  const [text, setText] = useState("");

  const handleSubmit = () => {
    if (text.trim()) {
      addTodo(text);
      setText("");
    }
  };

  return (
    <div>
      <input value={text} onChange={(e) => setText(e.target.value)} />
      <button onClick={handleSubmit}>Add</button>
    </div>
  );
};
  • No Provider wrapping. Components just import and use the hook.
  • Each component selects only what it needs — AddTodo doesn't subscribe to todos, so it won't re-render when todos change.

Multiple Stores

Separate concerns into different stores:

const useAuthStore = create<AuthStore>((set) => ({ ... }));
const useCartStore = create<CartStore>((set) => ({ ... }));
const useUIStore = create<UIStore>((set) => ({ ... }));
  • Each store is independent
  • Recommended: one store per domain/feature (auth, cart, UI preferences)

Using get for Actions That Read Current State

type CartItem = { id: string; name: string; qty: number };

type CartStore = {
  items: CartItem[];
  addItem: (product: { id: string; name: string }) => void;
};

const useCartStore = create<CartStore>((set, get) => ({
  items: [],

  addItem: (product) => {
    const existing = get().items.find((i) => i.id === product.id);
    if (existing) {
      // increment quantity
      set((state) => ({
        items: state.items.map((i) =>
          i.id === product.id ? { ...i, qty: i.qty + 1 } : i
        ),
      }));
    } else {
      set((state) => ({ items: [...state.items, { ...product, qty: 1 }] }));
    }
  },
}));
