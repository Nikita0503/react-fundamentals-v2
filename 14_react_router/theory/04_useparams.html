useParams

React Router має багато можливостей, з котрими бажано ознайомитися. Розглямено ще одну, котра доволі часто зустрічається на сайтах інтернет-магазинів.

Приклад URL:

https://online-shop/product/1

Є можливість зберігати дані у адресі до сторінки, наприклад id товару. Далі, у середині компоненту, можна отримати доступ до цих даних.

Додамо такий компонент до нашого прикладу:

/** App.js */

import React from 'react';
import { BrowserRouter, Route, Routes } from 'react-router-dom';
import ProfilePage from './pages/ProfilePage';
import HomePage from './pages/HomePage';
import ProductPage from './pages/ProductPage';

const App = () => {

  return (
    <BrowserRouter> 
      <Routes> 
        <Route path='home' element={<HomePage/>}/>
        <Route path='profile' element={<ProfilePage/>}/> 
        <Route path='product/:id' element={<ProductPage/>}/>
      </Routes>
    </BrowserRouter>
  )
}

export default App;

До навігації додамо сторінку - ProductPage. У шляху до неї додамо змінну - id. Таку змінну називають path variable. Реалізуємо ProductPage, де відобразимо id на сторінці:

/** /pages/ProductPage.js */

import React from 'react';
import { useParams } from "react-router-dom";

const ProductPage = () => {

  const { id } = useParams(); 

  return (
    <div>
      <div><span>Product id: {id}</span></div>
    </div>
  )
}

export default ProductPage;

Хук useParams повертає об`єкт, який містить path variables. За допомогою деструктуризації дістаємо id, та відображаємо його на сторінці.

Таким чином, наприклад, можна зручно дістати id товару та зробити запит до серверу, що поверне деталі обраного товару.
