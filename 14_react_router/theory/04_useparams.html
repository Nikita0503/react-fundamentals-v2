useParams

React Router has many capabilities that are worth getting familiar with. Let's look at another one that is quite commonly found on online store websites.

Example URL:

https://online-shop/product/1

It is possible to store data in the page address, for example a product id. Then, inside the component, you can access this data.

Let's add such a component to our example:

/** App.js */

import React from 'react';
import { BrowserRouter, Route, Routes } from 'react-router-dom';
import ProfilePage from './pages/ProfilePage';
import HomePage from './pages/HomePage';
import ProductPage from './pages/ProductPage';

const App = () => {

  return (
    <BrowserRouter> 
      <Routes> 
        <Route path='home' element={<HomePage/>}/>
        <Route path='profile' element={<ProfilePage/>}/> 
        <Route path='product/:id' element={<ProductPage/>}/>
      </Routes>
    </BrowserRouter>
  )
}

export default App;

We add a page to the navigation - ProductPage. In its path, we add a variable - id. Such a variable is called a path variable. Let's implement ProductPage, where we display the id on the page:

/** /pages/ProductPage.js */

import React from 'react';
import { useParams } from "react-router-dom";

const ProductPage = () => {

  const { id } = useParams(); 

  return (
    <div>
      <div><span>Product id: {id}</span></div>
    </div>
  )
}

export default ProductPage;

The useParams hook returns an object that contains path variables. Using destructuring, we extract the id and display it on the page.

This way, for example, you can conveniently extract a product id and make a request to the server that will return the details of the selected product.
