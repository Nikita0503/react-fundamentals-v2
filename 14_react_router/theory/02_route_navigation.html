Навігація між сторінками

Розлянемо приклад використання Link компоненту:

/** App.js */

import React from 'react';
import { BrowserRouter, Route, Routes, Link } from 'react-router-dom';
import ProfilePage from './pages/ProfilePage';
import HomePage from './pages/HomePage';

const App = () => {
  return (
    <BrowserRouter> 
      <>
        <Link to={'home'}>Home</Link>
        <Link to={'profile'}>Profile</Link>
      </>
      <Routes> 
        <Route path='home' element={<HomePage/>}/>
        <Route path='profile' element={<ProfilePage/>}/> 
      </Routes>
    </BrowserRouter>
  )
}

export default App;

<Link> — це компонент, натиснувши на який, користувач перейде на іншу сторінку. У react-router-dom <Link> рендерить елемент <a> зі справжнім href, який вказує на ресурс, на який він посилається. Це означає, що такі речі, як клацання правою кнопкою миші <Link>, працюють так, як ви очікували. Ви можете використати <Link reloadDocument>, щоб пропустити маршрутизацію на стороні клієнта та дозволити веб-переглядачу нормально виконувати перехід (як якщо б це був <a href>).

Розташування <Link> компонентів поза <Routes> дозволяє не дублювати код для відображення кнопок навігації на кожній сторінці. Тобто все що знаходиться в середині фрагменту (<></>) буде відображено зверху кожної сторінки.
