Navigation between pages

Let's look at an example of using the Link component:

/** App.js */

import React from 'react';
import { BrowserRouter, Route, Routes, Link } from 'react-router-dom';
import ProfilePage from './pages/ProfilePage';
import HomePage from './pages/HomePage';

const App = () => {
  return (
    <BrowserRouter> 
      <>
        <Link to={'home'}>Home</Link>
        <Link to={'profile'}>Profile</Link>
      </>
      <Routes> 
        <Route path='home' element={<HomePage/>}/>
        <Route path='profile' element={<ProfilePage/>}/> 
      </Routes>
    </BrowserRouter>
  )
}

export default App;

<Link> — is a component that, when clicked, navigates the user to another page. In react-router-dom, <Link> renders an <a> element with a real href that points to the resource it links to. This means that things like right-clicking a <Link> work as you would expect. You can use <Link reloadDocument> to skip client-side routing and let the browser handle the transition normally (as if it were an <a href>).

Placing <Link> components outside <Routes> allows you to avoid duplicating code for displaying navigation buttons on each page. That is, everything inside the fragment (<></>) will be displayed at the top of every page.
