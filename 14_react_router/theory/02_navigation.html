Navigation

There are two ways to navigate: declarative (Link/NavLink) and programmatic (useNavigate).

Link

Link renders an <a> tag but prevents a full page reload:

import { Link } from "react-router-dom";

const Navigation = () => (
  <nav>
    <Link to="/">Home</Link>
    <Link to="/about">About</Link>
    <Link to="/products">Products</Link>
  </nav>
);

Always use <Link> instead of <a href> for internal navigation (no page reload, preserves SPA behavior). Use regular <a href> only for external links (other websites).

NavLink

NavLink is like Link but knows if it's "active" (current route matches):

import { NavLink } from "react-router-dom";

const Navigation = () => (
  <nav>
    <NavLink to="/" className={({ isActive }) => isActive ? "nav-active" : ""}>
      Home
    </NavLink>
    <NavLink to="/about" className={({ isActive }) => isActive ? "nav-active" : ""}>
      About
    </NavLink>
  </nav>
);

Use NavLink for navigation menus where you need to highlight the current page. It receives isActive and isPending in className/style/children functions.

useNavigate

useNavigate — programmatic navigation (after form submit, after login, on button click):

import { useNavigate } from "react-router-dom";

type LoginData = {
  email: string;
  password: string;
};

const LoginForm = () => {
  const navigate = useNavigate();

  const handleSubmit = async (data: LoginData) => {
    await login(data);
    navigate("/dashboard"); // redirect after successful login
  };

  const goBack = () => {
    navigate(-1); // go back one step in history
  };

  return (
    <form onSubmit={() => handleSubmit({ email: "", password: "" })}>
      {/* form fields */}
      <button type="submit">Login</button>
      <button type="button" onClick={goBack}>Back</button>
    </form>
  );
};

navigate("/path") — go to path.

navigate(-1) — go back.

navigate("/path", { replace: true }) — replace current history entry (user can't go back).
