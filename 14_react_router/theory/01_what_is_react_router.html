What is React Router

React is mostly used for developing medium-sized projects. Such projects contain more than 1 page. In React, one of the most popular navigation libraries is React Router.

To start working with React Router, you need to take 2 steps:

Install it in the project:

npm install react-router-dom

Create 2 page components that the user will navigate to:

/** /pages/HomePage.js */

import React from 'react';

const HomePage = () => {
  return (
    <div>
      <h1>Hello, React Router</h1>
    </div>
  );
}

export default HomePage;
/** /pages/ProfilePage.js */

import React from 'react';

const ProfilePage = () => {
  return (
    <div>
      <div><span>Name: React Router</span></div>
      <div><span>Version: 6</span></div>
    </div>
  );
}

export default ProfilePage;

Usually, navigation configuration is done in the App.js file:

/** App.js */

import React from 'react';
import { BrowserRouter, Route, Routes } from 'react-router-dom';
import ProfilePage from './pages/ProfilePage';
import HomePage from './pages/HomePage';


const App = () => {

  return(
    <BrowserRouter> 
      <Routes> 
        <Route path='home' element={<HomePage/>}/>
        <Route path='profile' element={<ProfilePage/>}/> 
      </Routes>
    </BrowserRouter>
  );
}

export default App;

All navigation components are imported from the 'react-router-dom' package:

BrowserRouter - is a component that allows using the browser URL to display different pages in the application. It monitors URL changes and changes the displayed content according to the new URL.

Routes - is a component that contains a list of paths (Routes) that the user can navigate to, and specifies which component should be displayed when reaching each of these paths. Each path represents a URL associated with a specific component. Inside the Routes component, only Route components can be placed.

Route – is a component that maps a path to a component that should be displayed when the user reaches that path. Each Route contains information about the path (path) and the component (element - page) that should be displayed when reaching that path. Additionally, extra parameters can be passed to Route that help configure the component's display on the page.

All that remains is to provide the ability to navigate between pages (routes).
