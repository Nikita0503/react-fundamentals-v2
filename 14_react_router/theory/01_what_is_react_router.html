Що таке React Router

Здебільшого React використовується для розробки проектів середнього розміру. Такі проекти містять більше ніж 1 сторінку. В React однією з найбільш популярних бібліотек для навігації є React Router.

Для початку роботи з React Router необхідно зробити 2 кроки:

Встановити у проект:

npm install react-router-dom

Зробити 2 компоненти-сторінки, на які користувач переходитиме:

/** /pages/HomePage.js */

import React from 'react';

const HomePage = () => {
  return (
    <div>
      <h1>Hello, React Router</h1>
    </div>
  );
}

export default HomePage;
/** /pages/ProfilePage.js */

import React from 'react';

const ProfilePage = () => {
  return (
    <div>
      <div><span>Name: React Router</span></div>
      <div><span>Version: 6</span></div>
    </div>
  );
}

export default ProfilePage;

Зазвичай налаштування навігації відбувається у файлі App.js:

/** App.js */

import React from 'react';
import { BrowserRouter, Route, Routes } from 'react-router-dom';
import ProfilePage from './pages/ProfilePage';
import HomePage from './pages/HomePage';


const App = () => {

  return(
    <BrowserRouter> 
      <Routes> 
        <Route path='home' element={<HomePage/>}/>
        <Route path='profile' element={<ProfilePage/>}/> 
      </Routes>
    </BrowserRouter>
  );
}

export default App;

Усі компоненти навігації імпортуються з пакету 'react-router-dom':

BrowserRouter - це компонент, який дозволяє використовувати URL-адресу браузера для відображення різних сторінок в додатку. Він слідкує за змінами URL-адреси і змінює відображуваний контент відповідно до нового URL-адреси.

Routes - це компонент, що містить список шляхів (Routes), на які може перейти користувач, і вказує, який компонент має відобразитися при потраплянні на кожен з цих шляхів. Кожен шлях представляє собою URL-адресу, яка пов'язана з певним компонентом. В середині Routes компонента можуть розміщатися тільки Route компоненти.

Route – це компонент, який зіставляє шлях із компонентом, який повинен відображатися, коли користувач потрапляє на цей шлях. Кожен Route містить інформацію про шлях (path) та компонент (element - сторінка), який має бути відображений при попаданні на цей шлях. Крім того, у Route можна передати додаткові параметри, які допомагають налаштувати відображення компонента на сторінці.

Залишилося надати змогу переходити між сторінками (роутами).
