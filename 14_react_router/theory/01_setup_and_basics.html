Setup and Basics

Why a router? React is a Single Page Application (SPA) — there is only one HTML page. JavaScript handles "page" changes by swapping components in and out. A router maps URLs to components, so users can navigate between "pages" without a full page reload.

Installation:

npm install react-router-dom

Core components:

BrowserRouter — wraps the entire app, enables URL-based routing (uses the browser History API under the hood).

Routes — a container for all route definitions. It only renders the first matching route.

Route — maps a path to a component: <Route path="about" element={<AboutPage />} />

Basic setup:

// App.tsx
import { BrowserRouter, Routes, Route } from "react-router-dom";
import { HomePage } from "./pages/HomePage";
import { AboutPage } from "./pages/AboutPage";

const App = () => (
  <BrowserRouter>
    <Routes>
      <Route path="/" element={<HomePage />} />
      <Route path="/about" element={<AboutPage />} />
    </Routes>
  </BrowserRouter>
);

export default App;

Page components are just regular components:

// pages/HomePage.tsx
const HomePage = () => <h1>Welcome Home</h1>;
export { HomePage };

// pages/AboutPage.tsx
const AboutPage = () => <h1>About Us</h1>;
export { AboutPage };

How it works: when the URL is /about, React Router renders <AboutPage />. When the URL is /, it renders <HomePage />. No page reload happens — just a component swap.

File structure recommendation:

src/
├── pages/
│   ├── HomePage.tsx
│   ├── AboutPage.tsx
│   └── NotFoundPage.tsx
├── App.tsx
└── main.tsx
