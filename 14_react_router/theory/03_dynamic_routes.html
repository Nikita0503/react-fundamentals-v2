Dynamic Routes

Route Parameters (useParams)

Dynamic segments in the URL allow you to pass identifiers through the path:

// Route definition with :id parameter
<Route path="/products/:id" element={<ProductPage />} />
// ProductPage.tsx — reading the parameter
import { useParams } from "react-router-dom";

type ProductParams = {
  id: string;
};

const ProductPage = () => {
  const { id } = useParams<ProductParams>();

  return <h1>Product #{id}</h1>;
  // URL: /products/42 → shows "Product #42"
};

Parameters are always strings (parse to number if needed: Number(id)).

Multiple params: /users/:userId/posts/:postId

Common use: product pages, user profiles, blog posts.

Query Parameters (useSearchParams)

Query parameters are the ?key=value part of the URL:

// URL: /products?category=electronics&sort=price
import { useSearchParams } from "react-router-dom";

const ProductList = () => {
  const [searchParams, setSearchParams] = useSearchParams();

  const category = searchParams.get("category"); // "electronics"
  const sort = searchParams.get("sort");         // "price"

  // Update search params (doesn't reload page):
  const handleCategoryChange = (newCategory: string) => {
    setSearchParams({ category: newCategory, sort: sort ?? "name" });
  };

  return (
    <div>
      <p>Category: {category}, Sort: {sort}</p>
      <button onClick={() => handleCategoryChange("clothing")}>Clothing</button>
    </div>
  );
};

Use for: filters, search queries, pagination, sorting — anything that should be shareable via URL.

searchParams.get("key") — read a param (returns string | null).

setSearchParams({...}) — update params.

useLocation

Read the current location object:

import { useLocation } from "react-router-dom";

const Breadcrumbs = () => {
  const location = useLocation();
  // location.pathname — "/products/42"
  // location.search — "?color=red"
  // location.hash — "#details"
  // location.state — any data passed via navigate

  return <p>Current path: {location.pathname}</p>;
};

Useful for: breadcrumbs, analytics tracking, conditional rendering based on current route.
