List Operations (CRUD)

Real applications need full CRUD on lists: Create, Read, Update, Delete. All operations follow the immutability principle — never mutate state directly, always create new arrays.

Full Todo App Example

This example demonstrates all four operations in a single component:

import { useState } from "react";

type Todo = {
  id: number;
  text: string;
  completed: boolean;
};

const TodoApp = () => {
  const [todos, setTodos] = useState<Todo[]>([]);
  const [input, setInput] = useState("");

  // CREATE — add new item
  const addTodo = () => {
    if (!input.trim()) return;
    const newTodo: Todo = { id: Date.now(), text: input, completed: false };
    setTodos(prev => [...prev, newTodo]);
    setInput("");
  };

  // UPDATE — toggle completed
  const toggleTodo = (id: number) => {
    setTodos(prev =>
      prev.map(todo =>
        todo.id === id ? { ...todo, completed: !todo.completed } : todo
      )
    );
  };

  // DELETE — remove item
  const deleteTodo = (id: number) => {
    setTodos(prev => prev.filter(todo => todo.id !== id));
  };

  return (
    <div>
      <div>
        <input value={input} onChange={e => setInput(e.target.value)} placeholder="New todo..." />
        <button onClick={addTodo}>Add</button>
      </div>

      {todos.length === 0 ? (
        <p>No todos yet. Add one above!</p>
      ) : (
        <ul>
          {todos.map(todo => (
            <TodoItem
              key={todo.id}
              todo={todo}
              onToggle={toggleTodo}
              onDelete={deleteTodo}
            />
          ))}
        </ul>
      )}
    </div>
  );
};

Extracting List Items into a Component

When list items have their own logic or complexity, extract them into a separate component:

type TodoItemProps = {
  todo: Todo;
  onToggle: (id: number) => void;
  onDelete: (id: number) => void;
};

const TodoItem = ({ todo, onToggle, onDelete }: TodoItemProps) => {
  return (
    <li>
      <input
        type="checkbox"
        checked={todo.completed}
        onChange={() => onToggle(todo.id)}
      />
      <span style={{ textDecoration: todo.completed ? "line-through" : "none" }}>
        {todo.text}
      </span>
      <button onClick={() => onDelete(todo.id)}>Delete</button>
    </li>
  );
};

Why Extract?

  • Each item can be wrapped in React.memo for optimization
  • Cleaner parent component — list logic stays in parent, item rendering in child
  • Easier to test individual items
  • Reusable — same item component can be used in different lists
