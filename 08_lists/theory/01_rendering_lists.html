Rendering Lists

Rendering dynamic lists is one of the most common tasks in React. Almost every application displays collections of data — users, products, messages, notifications — and React provides a clean pattern for this.

The Pattern: .map()

Use the .map() array method to transform an array of data into an array of JSX elements:

type User = { id: number; name: string };

const UserList = ({ users }: { users: User[] }) => {
  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
};

The .map() method iterates over each item in the array and returns a new array of JSX elements that React renders to the DOM.

The key Prop

The key prop is required for every element in a list. React uses keys to identify which items changed, were added, or removed during re-renders.

Rules for keys:

  • Keys must be unique among siblings (not globally unique)
  • Keys must be stable — the same item should always have the same key

What to Use as key

  • ✅ Database ID (user.id, post.id) — best option
  • ✅ Unique business identifier (email, slug)
  • ⚠️ Index (i) — only acceptable for static lists that never reorder/filter
  • ❌ Random values (Math.random(), crypto.randomUUID() on each render) — breaks React's diffing

Why NOT Index as key

When items are added, removed, or reordered, indices shift. React thinks the item at index 0 is the same component as before — but it's actually a different item. The result: wrong state attached to wrong items, input values "jump" between items.

Rule: if the list can be reordered, filtered, or items can be added/removed — don't use index as key.

Empty State

Always handle the case when the list is empty. Never leave the user without feedback:

type User = { id: number; name: string };

const UserList = ({ users }: { users: User[] }) => {
  if (users.length === 0) {
    return <p>No users found.</p>;
  }

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
};

Rendering Different Types

You can use conditional rendering inside .map() to display items differently based on their data:

type Item = { id: number; text: string; completed: boolean };

const ItemList = ({ items }: { items: Item[] }) => {
  return (
    <ul>
      {items.map(item => (
        <li key={item.id} className={item.completed ? "done" : ""}>
          {item.completed ? "✅" : "⬜"} {item.text}
        </li>
      ))}
    </ul>
  );
};
