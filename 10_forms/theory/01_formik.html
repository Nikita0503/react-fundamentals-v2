Formik

Forms in React are used to receive input data from the user, such as text, numbers, selections, checkboxes, and much more. They are an important element of user interaction with a web application and allow transmitting this data to the server for further processing or storage.

The main advantages of using forms in React include:

  • Data state management: Forms in React allow using internal component states to store and manage entered data, which makes it convenient to track and change form values.
  • Data validation: With forms in React, you can perform validation of entered data on the client side (in our application) before sending it to the server. This allows immediately showing input errors to the user and ensures more correct data handling.
  • Sending data to the server: Forms in React allow conveniently sending data to the server for further processing or storage on the server side.
  • Component approach: Using forms in React allows separating the form interaction logic into separate components, which makes it easy to manage form state, validation, and event handling.
  • Code reuse: Forms can be created as reusable components, which allows their use on different pages or in different projects, simplifying development and code maintenance.

Overall, using forms in React allows conveniently and efficiently receiving input data from the user and provides control over data state.

For working with forms in React, we recommend using the Formik library. To install it in a project, you need to enter the command:

npm install formik

Formik is a third-party library for React that provides convenient tools for working with forms. Let's look at an example of using Formik to create a form in a React component.

Let's say we want to create a form for entering user data, such as name, email, and message.

We install Formik as a dependency and import the necessary components:

import React from 'react';
import { Formik, Form, Field, ErrorMessage, FormikHelpers } from 'formik';

type ContactFormValues = {
  name: string;
  email: string;
  message: string;
};

const ContactForm = () => {
  // Initial values of form fields
  const initialValues: ContactFormValues = {
    name: '',
    email: '',
    message: ''
  };

  // Function to handle form submission
  const handleSubmit = (values: ContactFormValues, { setSubmitting }: FormikHelpers<ContactFormValues>) => {
    // Send data to the server or perform other logic
    console.log(values);
    setSubmitting(false);
  };

  // Validation of entered data
  const validateForm = (values: ContactFormValues) => {
    const errors: Partial<ContactFormValues> = {};
    if (!values.name) {
      errors.name = 'The "Name" field is required';
    }
    if (!values.email) {
      errors.email = 'The "Email" field is required';
    } else if (!/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,4}$/i.test(values.email)) {
      errors.email = 'Invalid email address';
    }
    if (!values.message) {
      errors.message = 'The "Message" field is required';
    }
    return errors;
  };

  return (
  <Formik
    initialValues={initialValues}
    onSubmit={handleSubmit}
    validate={validateForm}
  >
    {({ isSubmitting, isValid, dirty }) => (
      <Form>
        <Field type="text" name="name" placeholder="Name" />
        <ErrorMessage name="name" component="div" />
        <Field type="email" name="email" placeholder="Email" />
        <ErrorMessage name="email" component="div" />
        <Field as="textarea" name="message" placeholder="Message" />
        <ErrorMessage name="message" component="div" />
        <button type="submit" disabled={isSubmitting || !isValid || !dirty}>
          Submit
        </button>
      </Form>
    )}
  </Formik>);
};

export default ContactForm;

In this example, we use Formik to create a form with validation and handling of the form submission event. The form contains three fields: "Name", "Email", and "Message". We set the initial values of the form fields using initialValues passed to the Formik component. Then we pass the handleSubmit function, which will be called when the form is submitted, as the onSubmit event handler of the Formik component.

The handleSubmit function receives two arguments: the form values (values) and the setSubmitting function, which we can use to manage the form submission state. In this example, we simply output the form values to the console and set setSubmitting(false) to complete the submission process.

Also, we use the validate function for validating the entered data in the form. This function takes the form values (values) and returns an object with errors if there are any. In our example, we check whether the "Name", "Email", and "Message" fields are not empty, and whether the "Email" field has the correct email format. If there are errors, they are displayed in the ErrorMessage component, which outputs the error text on the screen.

Additionally, we use Field components to create form fields. We specify the field type (type), its name (name), and set the default value (placeholder). Using as="textarea", we can use Field to create a text area.

Finally, we use a form submit button with the disabled={isSubmitting || !isValid || !dirty} attribute, which is automatically set by the Formik component during form submission, to avoid double submission (isSubmitting), and to avoid submitting invalid data (isValid) or submitting a completely empty form (dirty).

In the given example, isSubmitting is a variable that is automatically set by the Formik library during form submission. It has a value of true when the form is currently being submitted, i.e., the onSubmit function is executing, and false in other cases.

Applying isSubmitting to the disabled attribute on the submit button allows us to disable the button during form submission to avoid double submission or unwanted interaction with the form during the submission process.

isValid is a variable that is also automatically set by the Formik library, indicating the validity of the entered data. If its value is true — the data is valid, if not — false respectively. The validateForm function returns true / false for it. If an empty object is returned, the entered data will be considered valid (true will be returned). If the object has fields, the data is invalid (false will be returned).

dirty is a variable that is also automatically set by the Formik library, informing us whether something has been entered in the form. If so, its value will be true, if the form has not been touched — false.

When isSubmitting has a value of true or dirty or isValid have a value of false (!isValid || !dirty), the button will be blocked and inactive, which will help avoid incorrect interaction with the form.

When the submission process is complete, for example, after a successful submission or an error occurs, isSubmitting will be set to false in the onSubmit function or when an error occurs, which will allow reactivating the submit button for further use.

On the first interaction with the form, dirty will be set to true. And if all data is entered correctly and passes the checks, isValid will also be set to true.

This is a useful example of using the disabled={isSubmitting || !isValid || !dirty} attribute together with the Formik library to ensure correct interaction with the form during data entry and avoid double submissions.
