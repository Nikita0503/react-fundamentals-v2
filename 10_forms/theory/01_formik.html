Formik

Форми в React використовуються для отримання вхідних даних від користувача, таких як тексти, числа, вибори, чекбокси та багато іншого. Вони є важливим елементом взаємодії користувача з веб-додатком, і дозволяють передавати ці дані на сервер для подальшої обробки або зберігання.

Основні переваги використання форм у React включають:

  • Керування станом даних: Форми в React дозволяють використовувати внутрішні стани компонентів для зберігання та керування введеними даними, що дозволяє зручно відстежувати та змінювати значення форми.
  • Валідація даних: За допомогою форм у React можна виконувати валідацію введених даних на боці клієнта (в нашому додатку) перед відправкою на сервер. Це дозволяє відразу ж показувати помилки введення користувачеві та забезпечує більш коректну роботу з даними.
  • Передача даних на сервер: Форми в React дозволяють зручно передавати дані на сервер для подальшої обробки або зберігання на серверному боці.
  • Компонентний підхід: Використання форм у React дозволяє відокремити логіку взаємодії з формою в окремі компоненти, що дозволяє легко керувати станом форми, валідацією та обробкою подій.
  • Перевикористання коду: Форми можуть бути створені як реюзабельні (можна використати повторно) компоненти, що дозволяє їх використання на різних сторінках або в різних проектах, спрощуючи розробку та підтримку коду.

Загалом, використання форм у React дозволяє зручно та ефективно отримувати вхідні дані від користувача, забезпечує контроль над станом даних.

Для роботою з формами у React ми радимо використовувати бібліотеку Formik. Для того щоб її встановити у проект, потрібно ввести команду:

npm install formik

Formik - це стороння бібліотека для React, яка надає зручні інструменти для роботи з формами. Давайте розглянемо приклад використання Formik для створення форми в React компоненті.

Припустимо, ми хочемо створити форму для введення даних користувача, таких як ім'я, електронна пошта та повідомлення.

Ми встановлюємо Formik як залежність та імпортуємо необхідні компоненти:

import React from 'react';
import { Formik, Form, Field, ErrorMessage } from 'formik';

const ContactForm = () => {
  // Початкові значення полів форми
  const initialValues = {
    name: '',
    email: '',
    message: ''
  };

  // Функція для обробки відправки форми
  const handleSubmit = (values, { setSubmitting }) => {
    // Виконуємо відправку даних на сервер або виконуємо іншу логіку
    console.log(values);
    setSubmitting(false);
  };

  // Валідація введених даних
  const validateForm = values => {
    const errors = {};
    if (!values.name) {
      errors.name = 'Поле "Ім\'я" є обов\'язковим';
    }
    if (!values.email) {
      errors.email = 'Поле "Електронна пошта" є обов\'язковим';
    } else if (!/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,4}$/i.test(values.email)) {
      errors.email = 'Некоректна адреса електронної пошти';
    }
    if (!values.message) {
      errors.message = 'Поле "Повідомлення" є обов\'язковим';
    }
    return errors;
  };

  return (
  <Formik
    initialValues={initialValues}
    onSubmit={handleSubmit}
    validate={validateForm}
  >
    {({ isSubmitting, isValid, dirty }) => (
      <Form>
        <Field type="text" name="name" placeholder="Ім'я" />
        <ErrorMessage name="name" component="div" />
        <Field type="email" name="email" placeholder="Електронна пошта" />
        <ErrorMessage name="email" component="div" />
        <Field as="textarea" name="message" placeholder="Повідомлення" />
        <ErrorMessage name="message" component="div" />
        <button type="submit" disabled={isSubmitting || !isValid || !dirty}>
          Відправити
        </button>
      </Form>
    )}
  </Formik>);
};

export default ContactForm;

У цьому прикладі ми використовуємо Formik для створення форми з валідацією і обробкою події відправки форми. Форма містить три поля: "Ім'я", "Електронна пошта" та "Повідомлення". Ми встановлюємо початкові значення полів форми за допомогою initialValues переданих у компонент Formik. Далі ми передаємо функцію handleSubmit, яка буде викликатись при відправці форми, в якості обробника події onSubmit компонента Formik.

Функція handleSubmit отримує два аргументи: значення форми (values) та функцію setSubmitting, яку ми можемо використовувати для керування станом відправки форми. У цьому прикладі ми просто виводимо значення форми в консоль та встановлюємо setSubmitting(false) для завершення процесу відправки.

Також, ми використовуємо функцію validate для валідації введених даних у формі. Ця функція приймає значення форми (values) і повертає об'єкт з помилками, якщо вони є. У нашому прикладі ми перевіряємо, чи поля "Ім'я", "Електронна пошта" та "Повідомлення" не є пустими, та чи має поле "Електронна пошта" правильний формат електронної пошти. Якщо є помилки, вони відображаються в компоненті ErrorMessage, який виводить текст помилки на екран.

Крім того, ми використовуємо компоненти Field для створення полів форми. Ми вказуємо тип поля (type), його ім'я (name) та встановлюємо значення за замовчуванням (placeholder). Використовуючи as="textarea", ми можемо використовувати Field для створення текстової області.

Нарешті, ми використовуємо кнопку відправки форми з атрибутом disabled={isSubmitting || !isValid || !dirty}, який встановлюється автоматично компонентом Formik під час відправки форми, щоб уникнути подвійної відправки (isSubmitting), та уникнути відправки невалідних даних (isValid) або відправки взагалі пустої форми (dirty).

У вказаному прикладі, isSubmitting - це змінна, яка автоматично встановлюється бібліотекою Formik під час відправки форми. Вона має значення true, коли форма наразі відправляється, тобто виконується функція onSubmit, і false в інших випадках.

Застосування isSubmitting до атрибуту disabled на кнопці відправки дозволяє нам вимкнути кнопку під час відправки форми, щоб уникнути подвійної відправки або небажаної взаємодії з формою під час процесу відправки.

isValid - змінна, яка також автоматично встановлюється бібліотекою Formik, що свідчить нам про валідність введених даних. Якщо її значення true - дані валідні, якщо ні, відповідно - false. Повертає true / false для неї функція validateForm. У разі повернення пустого обʼєкту, буде вважатися, що введені дані є валідними (повернеться true). Якщо об`єкт має поля то дані невалідні (повернеться false).

dirty - змінна, яка також автоматично встановлюється бібліотекою Formik, що повідомляє нас про те, чи було щось введено у форму. Якщо так, то її значення буде true, у разі якщо форму не чіпали - false.

Коли isSubmitting має значення true або dirty чи isValid мають значення false (!isValid || !dirty), кнопка буде заблокована і неактивна, що дозволить уникнути некоректної взаємодії з формою.

Коли процес відправки завершиться, наприклад, після успішного відправлення або виникнення помилки, isSubmitting буде встановлено на false в функції onSubmit або при виникненні помилки, що дозволить знову активувати кнопку відправки форми для подальшого використання. 

При першій взаємодії з формою, для dirty буде встановлено значення true. Та якщо усі дані введені коректно, пройшли перевірки, то для isValid також буде встановлено значення true.

Це корисний приклад використання атрибуту disabled={isSubmitting || !isValid || !dirty} разом з бібліотекою Formik, щоб забезпечити коректну взаємодію з формою під час введення даних та уникнути подвійних відправок.
