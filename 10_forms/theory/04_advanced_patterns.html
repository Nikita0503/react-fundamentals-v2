Advanced Patterns

React Hook Form provides a rich set of features beyond basic registration and validation. This section covers the most important advanced patterns you'll use in real applications.

useForm Options

The useForm() hook accepts a configuration object with several useful options:

  • defaultValues — initial values for all form fields (important for edit forms)
  • mode — when validation triggers ("onSubmit", "onChange", "onBlur", "onTouched", "all")
  • resetOptions — controls behavior when default values change

Default Values

Default values are essential for edit forms where you pre-populate fields with existing data:

import { useForm } from "react-hook-form";

type ProfileForm = {
  name: string;
  email: string;
  bio: string;
};

const EditProfile = () => {
  const { register, handleSubmit } = useForm<ProfileForm>({
    defaultValues: {
      name: "Alice",
      email: "alice@example.com",
      bio: "Software developer",
    },
  });

  const onSubmit = (data: ProfileForm) => {
    console.log("Updated:", data);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input {...register("name")} />
      <input {...register("email")} />
      <textarea {...register("bio")} />
      <button type="submit">Save</button>
    </form>
  );
};

watch() — Subscribe to Field Changes

The watch() function lets you subscribe to field value changes. This is useful for conditional rendering based on the current form state:

import { useForm } from "react-hook-form";

type OrderForm = {
  deliveryMethod: "pickup" | "delivery";
  address: string;
};

const OrderPage = () => {
  const { register, handleSubmit, watch } = useForm<OrderForm>({
    defaultValues: { deliveryMethod: "pickup", address: "" },
  });

  const deliveryMethod = watch("deliveryMethod");

  return (
    <form onSubmit={handleSubmit(console.log)}>
      <select {...register("deliveryMethod")}>
        <option value="pickup">Pickup</option>
        <option value="delivery">Delivery</option>
      </select>

      {deliveryMethod === "delivery" && (
        <input {...register("address")} placeholder="Delivery address" />
      )}

      <button type="submit">Order</button>
    </form>
  );
};

setValue(), getValues(), and reset()

These methods provide programmatic access to form values:

  • setValue("fieldName", value) — set a field's value programmatically
  • getValues() — get current form values without subscribing to changes
  • reset() — reset the form to its default values (useful after successful submission)
const { setValue, getValues, reset, handleSubmit } = useForm<ContactForm>({
  defaultValues: { name: "", email: "", message: "" },
});

// Set a value programmatically
setValue("email", "user@example.com");

// Get all current values
const currentValues = getValues();

// Reset form after successful submission
const onSubmit = async (data: ContactForm) => {
  await submitToServer(data);
  reset(); // resets to defaultValues
};

Nested Objects and Arrays

React Hook Form supports nested data structures using dot notation and bracket notation:

type UserForm = {
  address: {
    street: string;
    city: string;
    zip: string;
  };
  items: { name: string; quantity: number }[];
};

// Register nested fields
register("address.street");
register("address.city");
register("address.zip");

// Register array items
register("items.0.name");
register("items.0.quantity");

useFieldArray — Dynamic Lists

useFieldArray is designed for managing dynamic lists of fields — where users can add or remove items. It provides methods like append, remove, prepend, insert, swap, and move.

import { useForm, useFieldArray } from "react-hook-form";

type SkillsForm = {
  skills: { name: string }[];
};

const SkillsEditor = () => {
  const { register, control, handleSubmit } = useForm<SkillsForm>({
    defaultValues: {
      skills: [{ name: "" }],
    },
  });

  const { fields, append, remove } = useFieldArray({
    control,
    name: "skills",
  });

  const onSubmit = (data: SkillsForm) => {
    console.log(data.skills);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      {fields.map((field, index) => (
        <div key={field.id}>
          <input
            {...register(`skills.${index}.name`, { required: "Skill name is required" })}
            placeholder={`Skill #${index + 1}`}
          />
          <button type="button" onClick={() => remove(index)}>
            Remove
          </button>
        </div>
      ))}

      <button type="button" onClick={() => append({ name: "" })}>
        Add Skill
      </button>

      <button type="submit">Save</button>
    </form>
  );
};

FormProvider + useFormContext

When your form is split across multiple nested components, passing register and errors through props becomes tedious. FormProvider and useFormContext solve this by sharing the form instance via React context:

import { useForm, FormProvider, useFormContext } from "react-hook-form";

type CheckoutForm = {
  name: string;
  email: string;
  address: string;
  city: string;
};

// Child component — accesses form without props
const ShippingFields = () => {
  const { register, formState: { errors } } = useFormContext<CheckoutForm>();

  return (
    <div>
      <input {...register("address", { required: "Address is required" })} placeholder="Address" />
      {errors.address && <span>{errors.address.message}</span>}

      <input {...register("city", { required: "City is required" })} placeholder="City" />
      {errors.city && <span>{errors.city.message}</span>}
    </div>
  );
};

// Parent component — provides form context
const CheckoutPage = () => {
  const methods = useForm<CheckoutForm>();

  const onSubmit = (data: CheckoutForm) => {
    console.log(data);
  };

  return (
    <FormProvider {...methods}>
      <form onSubmit={methods.handleSubmit(onSubmit)}>
        <input {...methods.register("name")} placeholder="Name" />
        <input {...methods.register("email")} placeholder="Email" />

        <ShippingFields />

        <button type="submit">Place Order</button>
      </form>
    </FormProvider>
  );
};

Controller — External UI Libraries

The Controller component is used to integrate React Hook Form with external controlled components (like custom Select, DatePicker, or Slider components from UI libraries) that don't expose a native ref:

import { useForm, Controller } from "react-hook-form";
import { DatePicker } from "some-ui-library";

type EventForm = {
  title: string;
  date: Date;
};

const EventPage = () => {
  const { register, control, handleSubmit } = useForm<EventForm>();

  return (
    <form onSubmit={handleSubmit(console.log)}>
      <input {...register("title")} placeholder="Event title" />

      <Controller
        name="date"
        control={control}
        rules={{ required: "Date is required" }}
        render={({ field, fieldState: { error } }) => (
          <>
            <DatePicker
              value={field.value}
              onChange={field.onChange}
              onBlur={field.onBlur}
            />
            {error && <span>{error.message}</span>}
          </>
        )}
      />

      <button type="submit">Create Event</button>
    </form>
  );
};

Use Controller only when the component doesn't work with register() (i.e., it doesn't accept a ref). For native HTML inputs, always prefer register().
