Forms Without Additional Libraries

However, if there is no desire to use third-party libraries, in React you can work with forms like this:

import React, { useState } from 'react';

const MyForm = () => {
  // Setting state for form fields
  const [username, setUsername] = useState('');
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');

  // Handler for "Username" field value change
  const handleUsernameChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    setUsername(e.target.value);
  };

  // Handler for "Email" field value change
  const handleEmailChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    setEmail(e.target.value);
  };

  // Handler for "Password" field value change
  const handlePasswordChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    setPassword(e.target.value);
  };

  // Form submission handler
  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    // Execute form submission logic, for example, to the server
    console.log('Form data:', { username, email, password });
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>
        Username:
        <input type="text" value={username} onChange={handleUsernameChange} />
      </label>
      <label>
        Email:
        <input type="email" value={email} onChange={handleEmailChange} />
      </label>
      <label>
        Password:
        <input type="password" value={password} onChange={handlePasswordChange} />
      </label>
      <button type="submit">Submit</button>
    </form>
  );
};

export default MyForm;

In this example, we use the useState function from React to set and store the form state.

Each input field has its own onChange event handler that tracks changes in form field values and updates the state of the corresponding field. The form also has an onSubmit event handler that executes when the form is submitted and performs the necessary logic, for example, sending data to the server.

This is just a simple example, and implementing more complex features such as validation, loading state management, etc., may require additional manual work. However, using the Formik library can simplify this process and provide more functionality, such as automatic validation, state management, sending data to the server, and much more.

However, this example demonstrates the basic approach to working with forms in React without using Formik.
