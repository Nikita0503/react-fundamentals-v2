Форми без додаткових бібліотек

Але, якщо немає бажання використати сторонні бібліотеки, у React можна працювати з формами таким чином:

import React, { useState } from 'react';

const MyForm = () => {
  // Встановлення стану для полів форми
  const [username, setUsername] = useState('');
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');

  // Обробник зміни значення поля "Ім'я користувача"
  const handleUsernameChange = (e) => {
    setUsername(e.target.value);
  };

  // Обробник зміни значення поля "Email"
  const handleEmailChange = (e) => {
    setEmail(e.target.value);
  };

  // Обробник зміни значення поля "Пароль"
  const handlePasswordChange = (e) => {
    setPassword(e.target.value);
  };

  // Обробник відправки форми
  const handleSubmit = (e) => {
    e.preventDefault();
    // Виконання логіки відправки форми, наприклад, на сервер
    console.log('Дані форми:', { username, email, password });
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>
        Ім'я користувача:
        <input type="text" value={username} onChange={handleUsernameChange} />
      </label>
      <label>
        Email:
        <input type="email" value={email} onChange={handleEmailChange} />
      </label>
      <label>
        Пароль:
        <input type="password" value={password} onChange={handlePasswordChange} />
      </label>
      <button type="submit">Відправити</button>
    </form>
  );
};

export default MyForm;

У цьому прикладі ми використовуємо функцію useState з React для встановлення та збереження стану форми.

Кожне поле вводу має свій власний обробник події onChange, який відслідковує зміни значень полів форми та оновлює стан відповідного поля. Форма також має обробник події onSubmit, який виконується при відправці форми та виконує необхідну логіку, наприклад, відправку даних на сервер.

Це лише простий приклад, і реалізація більш складних функцій, таких як валідація, керування станом завантаження, тощо, може вимагати додаткової ручної роботи. Однак, використання бібліотеки Formik може спростити цей процес та надати більше функціональності, такої як автоматична валідація, керування станом, відправка даних на сервер та багато іншого.

Однак, цей приклад демонструє базовий підхід до роботи з формами у React без використання Formik.
