React Hook Form

React Hook Form (RHF) is a performant, flexible form library for React built on uncontrolled components and refs. Instead of re-rendering the entire form on every keystroke, RHF keeps input values in the DOM and only triggers re-renders when necessary (e.g., on validation errors or submission).

Why React Hook Form over Formik?

  • Fewer re-renders — RHF uses uncontrolled inputs by default, so typing doesn't cause re-renders.
  • Smaller bundle size — RHF is significantly lighter than Formik (~8KB vs ~33KB gzipped).
  • Better TypeScript support — RHF is built with TypeScript and provides excellent type inference.
  • Actively maintained — Formik has been effectively abandoned since 2022. RHF is actively developed.
  • Built-in or schema-based validation — supports inline rules, Zod, Yup, and other schema libraries via resolvers.

Installation

npm install react-hook-form

Core API: useForm()

The useForm() hook is the foundation of React Hook Form. It returns an object with everything you need to manage a form:

  • register("fieldName") — connects an input to the form. It spreads ref, onChange, onBlur, and name onto the input element.
  • handleSubmit(onValid, onInvalid) — wraps your submit handler. It validates the form first and only calls your handler if validation passes.
  • formState — an object containing form metadata:
    • errors — validation errors for each field
    • isSubmitting — whether the form is currently submitting
    • isDirty — whether any field has been modified from its default value
    • isValid — whether the form currently passes all validation rules
    • dirtyFields — which fields have been modified
    • touchedFields — which fields have been focused and blurred

Basic Example — Contact Form

import { useForm } from "react-hook-form";

type ContactForm = {
  name: string;
  email: string;
  message: string;
};

const ContactPage = () => {
  const {
    register,
    handleSubmit,
    formState: { errors, isSubmitting },
  } = useForm<ContactForm>();

  const onSubmit = (data: ContactForm) => {
    console.log(data);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input
        {...register("name", { required: "Name is required" })}
        placeholder="Name"
      />
      {errors.name && <span>{errors.name.message}</span>}

      <input
        {...register("email", {
          required: "Email is required",
          pattern: {
            value: /^[^\s@]+@[^\s@]+\.[^\s@]+$/,
            message: "Invalid email",
          },
        })}
        placeholder="Email"
      />
      {errors.email && <span>{errors.email.message}</span>}

      <textarea
        {...register("message", { required: "Message is required" })}
        placeholder="Message"
      />
      {errors.message && <span>{errors.message.message}</span>}

      <button type="submit" disabled={isSubmitting}>
        Submit
      </button>
    </form>
  );
};

register() Validation Options

The second argument to register accepts validation rules:

  • required — field must have a value (can be a boolean or a string with an error message)
  • min / max — minimum/maximum numeric value
  • minLength / maxLength — minimum/maximum string length
  • pattern — a regex pattern the value must match
  • validate — a custom validation function (or object of functions) that returns true or an error message string
register("age", {
  required: "Age is required",
  min: { value: 18, message: "Must be at least 18" },
  max: { value: 120, message: "Invalid age" },
});

register("username", {
  minLength: { value: 3, message: "At least 3 characters" },
  maxLength: { value: 20, message: "Max 20 characters" },
  validate: (value) =>
    value !== "admin" || "Username 'admin' is not allowed",
});

Example: Password and Confirm Password

A common pattern — validate that two fields match using the validate function and watch:

import { useForm } from "react-hook-form";

type SignupForm = {
  email: string;
  password: string;
  confirmPassword: string;
};

const SignupPage = () => {
  const {
    register,
    handleSubmit,
    watch,
    formState: { errors },
  } = useForm<SignupForm>();

  const onSubmit = (data: SignupForm) => {
    console.log(data);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input
        type="email"
        {...register("email", { required: "Email is required" })}
        placeholder="Email"
      />
      {errors.email && <span>{errors.email.message}</span>}

      <input
        type="password"
        {...register("password", {
          required: "Password is required",
          minLength: { value: 8, message: "At least 8 characters" },
        })}
        placeholder="Password"
      />
      {errors.password && <span>{errors.password.message}</span>}

      <input
        type="password"
        {...register("confirmPassword", {
          required: "Please confirm your password",
          validate: (value) =>
            value === watch("password") || "Passwords do not match",
        })}
        placeholder="Confirm password"
      />
      {errors.confirmPassword && <span>{errors.confirmPassword.message}</span>}

      <button type="submit">Sign Up</button>
    </form>
  );
};

The validate function compares confirmPassword with the current value of password (read via watch("password")). If they don't match, the error message is shown.

Errors Object

The errors object from formState contains validation errors keyed by field name. Each error has a type (e.g., "required", "pattern") and a message string:

// Access error message for a field
{errors.email?.message}

// Check if a specific field has an error
{errors.email && <span className="error">{errors.email.message}</span>}

Validation Mode

By default, React Hook Form validates on submit (mode: "onSubmit"). You can change when validation triggers:

  • "onSubmit" — validate only when the form is submitted (default)
  • "onChange" — validate on every change event
  • "onBlur" — validate when an input loses focus
  • "onTouched" — validate on the first blur, then on every change
  • "all" — validate on both blur and change
const { register, handleSubmit } = useForm<ContactForm>({
  mode: "onBlur", // validate when user leaves a field
});
