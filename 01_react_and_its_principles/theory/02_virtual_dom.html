Що таке DOM?

DOM (Document Object Model) - це структура, яка представляє веб-сторінку в браузері у вигляді дерева елементів (наприклад, тегів HTML), які можуть бути змінені або відображені на екрані.

Одна з особливостей роботи з DOM полягає в тому, що зміни в DOM можуть бути дорогими з точки зору продуктивності, особливо при масштабному оновленні великої кількості елементів. Кожна зміна в DOM може призвести до перерахунку розміщення та вигляду елементів, що може бути витратним з точки зору ресурсів браузера та призвести до зниження продуктивності додатка.

DOM сторінки можна побачити відкривши DevTools у вкладці Elements.

Що таке Virtual DOM?

Віртуальний DOM (Virtual DOM) - це техніка оптимізації веб-додатків, яка використовується в React та інших JavaScript-бібліотеках і фреймворках для покращення продуктивності роботи з деревом DOM.

Віртуальний DOM є абстрактним представленням реального DOM в пам'яті браузера. Замість безпосередньої взаємодії з реальним DOM, React створює віртуальний DOM, який є легким та ефективним. Він зберігається в пам'яті як звичайний JavaScript-об'єкт. Virtual DOM складається з вузлів (або елементів) з їх властивостями та дочірніми вузлами. React використовує віртуальний DOM для виконання операцій зміни стану компонентів, порівняння старого та нового стану, та оновлення реального DOM лише в тих місцях, де відбулися зміни.

Перевага полягає у тому що React оновлює не весь реальний DOM, а тільки ті частини DOM, які потрібно (помаранчеві кружки). Інші (зелені кружки) частини DOM, які не потребують оновлення, не зачіпаються. Ця концепція сильно підвищує продуктивність додатку.

Процес роботи з віртуальним DOM в React може бути наступним:

1) Компонент React оновлює свій внутрішній стан (дані), або отримує нові властивості (дані).

2) React створює нове дерево віртуального DOM, представляючи оновлений стан компонента.

3) React порівнює нове дерево віртуального DOM з попереднім деревом віртуального DOM та визначає, які елементи потребують оновлення.

4) React оновлює реальний DOM лише в тих місцях, де відбулися зміни, замість повного оновлення всього дерева DOM.

5) Оновлені елементи в реальному DOM відображаються на веб-сторінці браузера, забезпечуючи відповідне оновлення інтерфейсу користувача (з актуальними даними).

Цей підхід дозволяє оптимізувати оновлення DOM та зменшити кількість операцій, необхідних для оновлення інтерфейсу користувача, що призводить до покращення продуктивності додатка.

Користування віртуальним DOM в React дозволяє розробникам писати ефективний та продуктивний код, оновлювати інтерфейс користувача ефективно та забезпечує кращий досвід використання веб-додатків.
