What is JSX?

JSX (JavaScript XML) is a syntax extension that lets you write HTML-like code inside JavaScript/TypeScript files. It makes component templates readable and intuitive.

JSX is not HTML — it's syntactic sugar that gets compiled into React.createElement() calls. The browser never sees JSX — a build tool (like Vite) transforms it into regular JavaScript before the code runs.

JSX Transformation

Here's what happens under the hood:

// What you write (JSX):
const element = <h1 className="title">Hello, world!</h1>;

// What React sees (after compilation):
const element = React.createElement("h1", { className: "title" }, "Hello, world!");

You never need to write React.createElement() manually — JSX does it for you. But understanding this transformation helps you debug issues and understand how React works internally.

JSX Rules

JSX looks like HTML but has important differences:

  1. Single root element: A component must return one parent element. If you don't want an extra wrapper <div>, use a Fragment: <>...</>
  2. className, not class: Because class is a reserved word in JavaScript
  3. htmlFor, not for: Same reason — used on <label> elements
  4. camelCase attributes: onClick, onChange, tabIndex (not onclick, onchange, tabindex)
  5. Self-closing tags are required: <img />, <input />, <br /> (you can't write <img> without closing)
  6. Expressions in curly braces: {variable}, {condition && <Component />}, {items.map(...)}

Embedding Expressions

You can embed any JavaScript expression inside JSX using curly braces {}:

const name = "Alice";
const age = 25;

const greeting = (
  <div>
    <h1>Hello, {name}!</h1>
    <p>You are {age} years old.</p>
    <p>Next year you'll be {age + 1}.</p>
  </div>
);

Anything that is a valid JavaScript expression can go inside {} — variables, function calls, math operations, ternary operators.

Conditional Rendering

You can conditionally show or hide elements using JavaScript expressions:

const isLoggedIn = true;

return (
  <div>
    {isLoggedIn ? <p>Welcome back!</p> : <p>Please log in.</p>}
    {isLoggedIn && <button>Logout</button>}
  </div>
);
  • Ternary operator (? :): Show one thing or another
  • Logical AND (&&): Show something only if the condition is true

Rendering Lists

Use .map() to render arrays of data as lists of elements:

const fruits = ["Apple", "Banana", "Cherry"];

return (
  <ul>
    {fruits.map((fruit) => (
      <li key={fruit}>{fruit}</li>
    ))}
  </ul>
);

The key Prop

When rendering lists, every element needs a unique key prop. This helps React identify which items changed, were added, or removed — making updates efficient. We'll cover this in detail in the Lists module.
