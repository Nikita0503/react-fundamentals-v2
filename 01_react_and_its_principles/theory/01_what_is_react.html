Що таке React?

React - це відкрита бібліотека JavaScript, розроблена компанією Facebook, для створення інтерфейсів користувача (UI) в веб-додатках. Він дозволяє розробникам будувати динамічні інтерфейси швидко та ефективно за допомогою компонентної архітектури.

Одна з головних концепцій React  - це використання компонентів. Компоненти в React є незалежними блоками інтерфейсу, які можна складати разом для створення більш складних інтерфейсів. Кожен компонент може мати свою внутрішню логіку, стан, властивості та методи, які дозволяють взаємодіяти з іншими компонентами та змінювати відображення на екрані.

React також підтримує односторонній потік даних (unidirectional data flow), що дозволяє контролювати потік даних та стану в додатку, сприяє декларативному підходу до опису UI та полегшує розподіл додатку на компоненти.

React є однією з найпопулярніших технологій для створення веб-інтерфейсів і широко використовується в розробці веб-додатків та сайтів.

 

Фреймворк / бібліотека

Багато інженерів не розуміють різницю між фреймворком та бібліотекою.

Бібліотека (library) - це набір функцій, класів та ресурсів, які можна використовувати у вашому коді. Бібліотеки надають набір інструментів для виконання певних завдань, і ви можете імпортувати та використовувати потрібні речі з бібліотеки у своєму коді. Ви можете розглядати бібліотеку як набір функцій, які ви можете викликати зі свого коду для виконання певних операцій.

Фреймворк (framework), з іншого боку, є більш широкою структурою, що визначає архітектуру та правила розробки додатків. Фреймворк зазвичай надає основу для розробки додатків, визначаючи структуру файлової системи, способи взаємодії з базою даних, управління користувачами і т. д. Ви створюєте свій код всередині фреймворку, дотримуючись його правил і використовуючи його компоненти, такі як класи, методи і бібліотеки.

Отже, бібліотека і фреймворк відрізняються рівнем абстракції та призначенням. Бібліотеки надають набір функцій для виконання конкретних завдань, а фреймворки визначають структуру та правила для розробки додатків. Ви можете використовувати як бібліотеки, так і фреймворки у своєму коді, незалежно від того, чи пишете ви новий код, чи інтегруєте його з вже існуючим.

Якщо поясними вкрай простими словами:

Бібліотека (library) - коли інший код (функції, класи) ви використовуєте у своєму коді.

Фреймворк (framework) - коли ви пишите свій код всередині іншого коду (бо він задає структуру та правила розробки).

Компонентний підхід

Один з принципів React – компонентний підхід.

Компоненти в React - це відокремлені, повторно використовувані блоки коду, які містять логіку та відображення інтерфейсу. Вони можуть бути використані для створення різних елементів інтерфейсу, таких як кнопки, форми, списки, заголовки, картки тощо.

Простими словами:

Компонент – набір html тегів, відображення яких налаштовано з використанням css, а поведінка задана за допомогою javascript.

Односторонній потік даних

Односторонній потік даних у React - це концепція, за якою дані переміщуються тільки в одному напрямку, від батьківських компонентів до дочірніх компонентів:

App -> MainPage

MainPage -> Table

Це означає, що батьківський компонент може передати дані своїм дочірнім компонентам і дочірні компоненти можуть використовувати ці дані для відображення або виконання певних дій.

Батьківський компонент - це компонент, який містить інші компоненти всередині себе. (App для Navbar, MainPage).

Дочірній компонент - це компонент, який міститься всередині батьківського компонента. (Navbar, MainPage по відношенню до App).
