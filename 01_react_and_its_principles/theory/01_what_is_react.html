What is React?

React is an open-source JavaScript library developed by Facebook for building user interfaces (UI) in web applications. It allows developers to build dynamic interfaces quickly and efficiently using a component-based architecture.

One of the main concepts of React is the use of components. Components in React are independent blocks of the interface that can be composed together to create more complex interfaces. Each component can have its own internal logic, state, properties, and methods that allow it to interact with other components and change what is displayed on the screen.

React also supports unidirectional data flow, which allows controlling the flow of data and state in the application, promotes a declarative approach to describing UI, and makes it easier to divide the application into components.

React is one of the most popular technologies for building web interfaces and is widely used in the development of web applications and websites.

Framework / Library

Many engineers do not understand the difference between a framework and a library.

Library - is a set of functions, classes, and resources that can be used in your code. Libraries provide a set of tools for performing certain tasks, and you can import and use the things you need from the library in your code. You can think of a library as a set of functions that you can call from your code to perform certain operations.

Framework, on the other hand, is a broader structure that defines the architecture and rules for application development. A framework usually provides a foundation for application development, defining the file system structure, ways of interacting with the database, user management, etc. You write your code inside the framework, following its rules and using its components, such as classes, methods, and libraries.

So, a library and a framework differ in the level of abstraction and purpose. Libraries provide a set of functions for performing specific tasks, while frameworks define the structure and rules for application development. You can use both libraries and frameworks in your code, regardless of whether you are writing new code or integrating it with existing code.

If explained in very simple terms:

Library - when you use other code (functions, classes) in your code.

Framework - when you write your code inside other code (because it defines the structure and rules of development).

Component-Based Approach

One of the principles of React is the component-based approach.

Components in React are isolated, reusable blocks of code that contain logic and interface rendering. They can be used to create various interface elements, such as buttons, forms, lists, headers, cards, etc.

In simple terms:

A component is a set of HTML tags, whose appearance is configured using CSS, and whose behavior is defined using JavaScript.

Unidirectional Data Flow

Unidirectional data flow in React is a concept where data moves in only one direction, from parent components to child components:

App -> MainPage

MainPage -> Table

This means that a parent component can pass data to its child components, and child components can use this data for rendering or performing certain actions.

A parent component is a component that contains other components inside it. (App for Navbar, MainPage).

A child component is a component that is contained inside a parent component. (Navbar, MainPage in relation to App).
