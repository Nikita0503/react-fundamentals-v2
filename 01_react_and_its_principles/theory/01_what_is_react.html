What is React?

React is an open-source UI library created by Meta (formerly Facebook). It is used to build user interfaces for web applications. The current stable version is React 19.

React focuses on one thing and does it well: rendering UI. It is not a full framework — it's a library that you integrate into your application however you see fit.

Library vs Framework

This is a fundamental distinction every developer should understand:

  • Library — you call its code from your code. You are in control. You decide when and how to use it.
  • Framework — your code runs inside its structure. The framework is in control — it calls your code when it decides to. This is known as "inversion of control".

React is a library. You decide how to structure your app, what router to use, how to fetch data, and how to manage state. React only handles the view layer — everything else is your choice.

Core Principles of React

React is built on three fundamental principles:

  • Component-based: The UI is built from independent, reusable pieces called components. Each component encapsulates its own logic, markup, and styling. You compose small components into larger ones to build complex interfaces.
  • Declarative: You describe what the UI should look like for a given state, and React figures out how to update the DOM to match. You never manually manipulate DOM elements — you just declare the desired result.
  • Unidirectional data flow: Data flows in one direction — from parent components to child components via props. When a child needs to communicate back to the parent, it does so through callback functions (events flow up). This makes data flow predictable and easier to debug.

Where React is Used

React is not limited to web browsers:

  • Web applications — React DOM (the most common use case)
  • Mobile applications — React Native (iOS and Android)
  • Desktop applications — Electron with React
  • VR applications — React 360

The core concepts (components, state, props, hooks) remain the same across all platforms — only the rendering target changes.

React Ecosystem

Since React is just the view layer, you choose your own tools for everything else:

  • Routing (React Router, TanStack Router)
  • State management (Redux Toolkit, Zustand)
  • Data fetching (TanStack Query, SWR)
  • Form handling (React Hook Form)
  • Styling (Tailwind CSS, CSS Modules)

This flexibility is both React's greatest strength and its learning curve — you build exactly the stack you need.
