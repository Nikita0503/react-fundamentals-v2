Creating a React Project in 2025

Vite is the standard tool for creating React projects today. It's fast, modern, and has TypeScript support out of the box.

Creating a Project

Run these commands in your terminal:

npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
npm run dev

That's it — you have a working React + TypeScript project with a development server running.

What Vite Gives You

  • Dev server with hot reload: Changes appear instantly in the browser without losing state
  • TypeScript support: No extra configuration needed
  • Fast builds: Uses esbuild for development and Rollup for production
  • ES modules: Modern module system, no bundling during development

Project Structure

After creation, your project looks like this:

my-app/
├── public/            # Static files (favicon, etc.)
├── src/
│   ├── App.tsx        # Root component
│   ├── main.tsx       # Entry point (renders App into DOM)
│   ├── App.css        # Styles for App
│   └── vite-env.d.ts  # Vite TypeScript declarations
├── index.html         # Single HTML page (SPA entry)
├── package.json       # Dependencies and scripts
├── tsconfig.json      # TypeScript configuration
└── vite.config.ts     # Vite configuration

The Entry Point — main.tsx

This is where your React application starts:

import React from "react";
import ReactDOM from "react-dom/client";
import App from "./App";

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);

What's happening here:

  • createRoot mounts your React application into the <div id="root"> element in index.html
  • React.StrictMode is a development-only wrapper that helps find bugs early. It double-renders components in development to catch side effects, and warns about deprecated APIs. It has no effect in production.

Your First Component — App.tsx

const App = () => {
  return (
    <div>
      <h1>My First React App</h1>
      <p>Edit src/App.tsx and save to see changes.</p>
    </div>
  );
};

export default App;

This is a functional component — a plain function that returns JSX. It's the simplest building block in React.

Key Scripts

  • npm run dev — Start the development server (with hot reload)
  • npm run build — Create an optimized production build
  • npm run preview — Preview the production build locally

A Note on Create React App (CRA)

You may see older tutorials using npx create-react-app. This tool is deprecated as of 2023 and is no longer maintained. Vite is the recommended replacement — it's faster, simpler, and actively developed.
