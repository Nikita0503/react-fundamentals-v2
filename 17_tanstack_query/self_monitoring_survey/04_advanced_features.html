What does useInfiniteQuery's getNextPageParam return?


( ) The total number of pages available ( ) A boolean indicating if more pages exist (x) The parameter for the next page — null/undefined means no more pages ( ) The full URL for the next API request

What does refetchInterval do?


( ) Sets the minimum time between manual refetch calls ( ) Controls how long to wait before retrying a failed request (x) Automatically refetches the query at the specified interval — polling ( ) Determines how often the cache is garbage collected

What does the select option do?


( ) Chooses which fields to request from the API ( ) Filters which components can access the cached data (x) Transforms cached data before returning to the component — component only re-renders when transformed value changes ( ) Selects which cache entry to use when multiple exist

What is prefetching useful for?


( ) Fetching data during server-side rendering only ( ) Downloading the entire API response set on app startup (x) Loading data before the user needs it — e.g., on link hover ( ) Caching data permanently so it never needs to be refetched
