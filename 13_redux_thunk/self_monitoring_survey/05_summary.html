3. What does this code do?

const fetchTodos = createAsyncThunk<Todo[], void, { rejectValue: string }>(
  "todos/fetch",
  async (_, thunkAPI) => {
    const res = await fetch("/api/todos");
    if (!res.ok) return thunkAPI.rejectWithValue("Failed to load");
    return res.json();
  }
);
Creates a reducer that handles todo state
Creates a React hook called useFetchTodos
(x) Creates an async thunk that fetches todos, returns Todo[] on success, and returns a typed string error via rejectWithValue on failure — generating pending/fulfilled/rejected actions
Creates an API endpoint with automatic caching
