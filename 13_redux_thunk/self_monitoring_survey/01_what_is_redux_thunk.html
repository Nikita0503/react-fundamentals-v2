Що таке middleware в Redux і яку функцію виконує Redux Thunk?


( ) Middleware - це засіб для збільшення продуктивності в Redux, і Redux Thunk відповідає за стан компонентів. ( ) Middleware - це інструмент для забезпечення безпеки в Redux, і Redux Thunk слідкує за безпекою додатку. (x) Middleware - це операція, яка відпрацьовує між викликом Dispatch та обробкою Action у Reducer, а Redux Thunk дозволяє створювати асинхронні дії в Redux.

Які можливості Redux Thunk?


( ) Забезпечує анімацію компонентів в Redux. (x) Дозволяє створювати асинхронні дії (Actions) в Redux. ( ) Застосовує стилі до компонентів.

Які кроки необхідно виконати для використання Redux Thunk у проекті?


(x) Встановити пакет redux-thunk та підключити його до Redux store за допомогою applyMiddleware. ( ) Встановити пакет redux-async та використовувати його для асинхронних операцій в Redux. ( ) Змінити всі Actions на асинхронні, безпосередньо вписуючи асинхронний код у кожен Action.

Які параметри отримує функція, що повертається з Redux Thunk?


( ) ActionCreator та State (x) Dispatch та getState ( ) ClearStore та AsyncStorage

  return { type: 'UPDATE_DATA', payload: { name: 'John', age: 25 } };
};

Варіант 2: 
const fetchData = () => async (dispatch, getState) => {
  try {
    const data = await fetch('https://api.example.com/data');
    const result = await data.json();
    dispatch({ type: 'SET_DATA', payload: result });
  } catch (error) {
    dispatch({ type: 'SET_ERROR', payload: error });
  }
};

Чому необхідно використовувати функцію Dispatch при оновленні даних в Redux Store?


( ) Dispatch є необов'язковим у Redux, і можна оновлювати дані без його використання. (x) Dispatch відповідає за відправку Action до Reducer для оновлення Store, і без його використання дані не будуть оновлюватися. ( ) Dispatch використовується тільки для збереження даних у Store, але не для їх оновлення.
