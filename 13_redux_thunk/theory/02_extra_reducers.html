Where to Handle Async Actions: extraReducers

When you create a thunk with createAsyncThunk, it generates 3 action types (pending, fulfilled, rejected). But where do you handle them? In the extraReducers field of createSlice.

Why "extra"?

The reducers field in createSlice is for actions that the slice defines itself. The extraReducers field is for actions defined elsewhere — like thunks, or actions from other slices. They're "extra" because they weren't created by this slice's reducers object.

The Builder Pattern

extraReducers uses a builder callback with .addCase() for each action type you want to handle.

First, here's the thunk we'll be handling:

// store/thunks/fetchUser.ts
import { createAsyncThunk } from "@reduxjs/toolkit";

type User = { id: number; name: string; email: string };

export const fetchUser = createAsyncThunk(
  "user/fetchUser",
  async (userId: string) => {
    const response = await fetch(`/api/users/${userId}`);
    return (await response.json()) as User;
  }
);

Now, the slice that handles its pending/fulfilled/rejected actions:

import { createSlice } from "@reduxjs/toolkit";
import { fetchUser } from "./thunks/fetchUser";

const userSlice = createSlice({
  name: "user",
  initialState,
  reducers: {
    // regular synchronous actions here
  },
  extraReducers: (builder) => {
    builder
      .addCase(fetchUser.pending, (state) => {
        state.status = "loading";
        state.error = null;
      })
      .addCase(fetchUser.fulfilled, (state, action) => {
        state.status = "succeeded";
        state.data = action.payload;
      })
      .addCase(fetchUser.rejected, (state, action) => {
        state.status = "failed";
        state.error = action.payload?.message ?? "Unknown error";
      });
  },
});

The Standard Loading State Pattern

Almost every async slice follows this pattern for its state shape:

type User = {
  id: string;
  name: string;
  email: string;
};

type UserState = {
  data: User | null;
  status: "idle" | "loading" | "succeeded" | "failed";
  error: string | null;
};

const initialState: UserState = {
  data: null,
  status: "idle",
  error: null,
};

This gives you everything you need to show loading spinners, error messages, and data — all driven by the store.

Full Slice Example

// store/slices/userSlice.ts
import { createSlice } from "@reduxjs/toolkit";
import { fetchUser } from "../thunks/fetchUser";

type User = {
  id: string;
  name: string;
  email: string;
  avatar: string;
};

type UserState = {
  data: User | null;
  status: "idle" | "loading" | "succeeded" | "failed";
  error: string | null;
};

const initialState: UserState = {
  data: null,
  status: "idle",
  error: null,
};

const userSlice = createSlice({
  name: "user",
  initialState,
  reducers: {
    clearUser(state) {
      state.data = null;
      state.status = "idle";
      state.error = null;
    },
  },
  extraReducers: (builder) => {
    builder
      .addCase(fetchUser.pending, (state) => {
        state.status = "loading";
        state.error = null;
      })
      .addCase(fetchUser.fulfilled, (state, action) => {
        state.status = "succeeded";
        state.data = action.payload;
      })
      .addCase(fetchUser.rejected, (state, action) => {
        state.status = "failed";
        state.error = action.payload?.message ?? "Unknown error";
      });
  },
});

export const { clearUser } = userSlice.actions;
export const userReducer = userSlice.reducer;

Component Example: Using the Thunk

Here's how a component dispatches the thunk and reacts to the loading/error/data states:

// components/UserProfile.tsx
import { useEffect } from "react";
import { useAppDispatch, useAppSelector } from "../store/hooks";
import { fetchUser } from "../store/thunks/fetchUser";
import { clearUser } from "../store/slices/userSlice";

type UserProfileProps = {
  userId: string;
};

const UserProfile = ({ userId }: UserProfileProps) => {
  const dispatch = useAppDispatch();
  const { data: user, status, error } = useAppSelector((state) => state.user);

  useEffect(() => {
    dispatch(fetchUser(userId));

    return () => {
      dispatch(clearUser());
    };
  }, [dispatch, userId]);

  if (status === "loading") {
    return <p>Loading user...</p>;
  }

  if (status === "failed") {
    return <p style={{ color: "red" }}>Error: {error}</p>;
  }

  if (!user) {
    return null;
  }

  return (
    <div>
      <img src={user.avatar} alt={user.name} />
      <h2>{user.name}</h2>
      <p>{user.email}</p>
    </div>
  );
};

export { UserProfile };

When to Use createAsyncThunk

Use it when:

  • You need the fetched data in the Redux store (not just local component state)
  • Multiple components consume the same async data
  • You need to track loading/error state globally
  • Other parts of the app need to react to the fetch lifecycle (e.g., show a global loading bar)

Don't use it when:

  • Data is only used by one component — just use useEffect + useState
  • You don't need caching or global access — consider React Query / TanStack Query
  • You have many endpoints with similar patterns — RTK Query (next section) is better

Full Example: Task CRUD with Thunks

Let's put it all together — a complete example with tasks that can be fetched, added, toggled, and deleted:

Types and Thunks:

// store/tasks/types.ts
type Task = {
  id: number;
  title: string;
  status: "in progress" | "done";
};

// store/tasks/thunks.ts
import { createAsyncThunk } from "@reduxjs/toolkit";

export const fetchTasks = createAsyncThunk("tasks/fetchAll", async () => {
  const response = await fetch("/api/tasks");
  return (await response.json()) as Task[];
});

export const addTask = createAsyncThunk("tasks/add", async (title: string) => {
  const response = await fetch("/api/tasks", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ title, status: "in progress" }),
  });
  return (await response.json()) as Task;
});

export const toggleTask = createAsyncThunk("tasks/toggle", async (task: Task) => {
  const newStatus = task.status === "in progress" ? "done" : "in progress";
  const response = await fetch(`/api/tasks/${task.id}`, {
    method: "PATCH",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ status: newStatus }),
  });
  return (await response.json()) as Task;
});

export const deleteTask = createAsyncThunk("tasks/delete", async (id: number) => {
  await fetch(`/api/tasks/${id}`, { method: "DELETE" });
  return id; // return the id so the reducer knows which task to remove
});

Slice with extraReducers:

// store/tasks/tasksSlice.ts
import { createSlice } from "@reduxjs/toolkit";
import { fetchTasks, addTask, toggleTask, deleteTask } from "./thunks";

type TasksState = {
  items: Task[];
  loading: boolean;
  error: string | null;
};

const initialState: TasksState = {
  items: [],
  loading: false,
  error: null,
};

const tasksSlice = createSlice({
  name: "tasks",
  initialState,
  reducers: {},
  extraReducers: (builder) => {
    // Fetch all
    builder.addCase(fetchTasks.pending, (state) => {
      state.loading = true;
      state.error = null;
    });
    builder.addCase(fetchTasks.fulfilled, (state, action) => {
      state.items = action.payload;
      state.loading = false;
    });
    builder.addCase(fetchTasks.rejected, (state, action) => {
      state.loading = false;
      state.error = action.error.message ?? "Failed to fetch tasks";
    });

    // Add
    builder.addCase(addTask.fulfilled, (state, action) => {
      state.items.push(action.payload);
    });

    // Toggle status
    builder.addCase(toggleTask.fulfilled, (state, action) => {
      const index = state.items.findIndex((t) => t.id === action.payload.id);
      if (index !== -1) state.items[index] = action.payload;
    });

    // Delete
    builder.addCase(deleteTask.fulfilled, (state, action) => {
      state.items = state.items.filter((t) => t.id !== action.payload);
    });
  },
});

export default tasksSlice.reducer;

Component:

// components/TaskList.tsx
import { useEffect, useState } from "react";
import { useAppDispatch, useAppSelector } from "../store/hooks";
import { fetchTasks, addTask, toggleTask, deleteTask } from "../store/tasks/thunks";

const TaskList = () => {
  const dispatch = useAppDispatch();
  const { items: tasks, loading, error } = useAppSelector((state) => state.tasks);
  const [newTitle, setNewTitle] = useState("");

  useEffect(() => {
    dispatch(fetchTasks());
  }, [dispatch]);

  const handleAdd = () => {
    if (newTitle.trim()) {
      dispatch(addTask(newTitle));
      setNewTitle("");
    }
  };

  if (loading) return <p>Loading...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <div>
      <div>
        <input
          value={newTitle}
          onChange={(e) => setNewTitle(e.target.value)}
          placeholder="New task..."
        />
        <button onClick={handleAdd}>Add</button>
      </div>

      <ul>
        {tasks.map((task) => (
          <li key={task.id}>
            <span style={{ textDecoration: task.status === "done" ? "line-through" : "none" }}>
              {task.title}
            </span>
            <button onClick={() => dispatch(toggleTask(task))}>
              {task.status === "in progress" ? "Done" : "Undo"}
            </button>
            <button onClick={() => dispatch(deleteTask(task.id))}>Delete</button>
          </li>
        ))}
      </ul>
    </div>
  );
};

This is a complete async CRUD flow: fetch tasks on mount, add new tasks, toggle status between "in progress" and "done", and delete tasks. Each operation is a thunk that calls the API, and the slice handles the results via extraReducers.
