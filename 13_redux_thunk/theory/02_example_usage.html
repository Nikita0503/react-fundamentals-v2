Приклад викорстання

Функції в котрі виносять код взємодії з REST API у Redux Thunk називають «Санки». «Санка» - асинхронний Action.

Різниця між ними в тім, що звичайний Action Creator повертає об`єкт з Action Type та Payload (сам Action), а Санка повертає асинхронну функцію:

const sendUserData = () => async (dispatch, getState) => { 	
  // логіка взаємодії з REST API
};

В середині Санки є доступ до Dispatch, та getState функції, котра повертає увесь Store.

На прикладі стане зрозуміліше. Додамо до попереднього компоненту кнопку «Send»:

/** /components/UserData.js */

import { useSelector, useDispatch } from 'react-redux';
import { setName, setSurname } from '../redux/actions';

const UserData = () => {
  const dispatch = useDispatch();

  const name = useSelector(state => state.user.name);
  const surname = useSelector(state => state.login.surname);

  return (
    <div>
      <input value={name} onChange={(event) => dispatch(setName(event.target.value))} />
      <input value={surname} onChange={(event) => dispatch(setSurname(event.target.value))} />
      <button onClick={() => {}}>Send</button> 
    </div>
  );
}

export default UserData;

Поки що кнопка «Send» нічого не вміє. Наша задача - зробити так, щоб по натисканню на «Send» name та surname відправлялися на ендпоінт REST API.

Так як Санка - асинхронний Action, ми додаємо його у файл з Actions:

/** /redux/actions.js */

export const SET_NAME = "SET_NAME";
export const SET_SURNAME = "SET_SURNAME";

export const setName = (name) => ({
  type: SET_NAME,
  payload: name
});

export const setSurname = (surname) => ({
  type: SET_SURNAME,
  payload: surname
});

// Санка
export const sendUserData = () => async (dispatch, getState) => {     try{
        const userName = getState().user.name;
        const userSurname = getState().user.surname;

	const response = await fetch('https://yourapi/user', {
            method: 'POST',
            body: JSON.stringify({
                name: userName,
                surname: userSurname,
            })
        });

        const result = await response.json();
        console.log("Результат:", result);
    }catch(e){
        console.log('sendUserData error', e)
    }
};

sendUserData - Санка. Якщо правильно сказати, то це функція, котра повертає callback, приймаючий першим параметром Dispatch, другим getState.

В тілі callback пишеться асинхронний код, наприклад взаємодія з REST API.

Весь код всередині слід огорнути у конструкцію try-catch для обробки непердбачуваних помилок, адже з серверу може повернутися помилка.

'const userName = getState().user.name' -  userName містить значення поля name, котре всередині userReducer.

Далі - імітація відправлення цих даних до вигаданого REST API та обробка відповіді сервера з виводом результата на екран.

Припустимо, що після обробки відповіді з серверу необхідно очистити поля name та surname у Store:

export const sendUserData = () => async (dispatch, getState) => {     try{
        const userName = getState().user.name;
        const userSurname = getState().user.surname;

	const response = await fetch('https://yourapi/user', {
            method: 'POST',
            body: JSON.stringify({
                name: userName,
                surname; userSurname,
            })
        });

        const result = await response.json();
        console.log("Результат:", result);
	dispatch(setName(''));
        dispatch(setSurname(''));
    }catch(e){
        console.log('sendUserData error', e)
    }
};

Для очистки полів, використовуємо Dispatch, котрий надає Санка.

Залишилося використати Санку з компоненту. Для виклику Санки викликається Dispatch, так як і для звичайного Action:

/** /components/UserData.js */

import { useSelector, useDispatch } from 'react-redux';
import { setName, setSurname, sendUserData } from '../redux/actions';

const UserData = () => {
  const dispatch = useDispatch();

  const name = useSelector(state => state.user.name);
  const surname = useSelector(state => state.login.surname);

  return (
    <div>
      <input value={name} onChange={(event) => dispatch(setName(event.target.value))} />
      <input value={surname} onChange={(event) => dispatch(setSurname(event.target.value))} />
      <button onClick={() => {dispatch(sendUserData())}}>Send</button> 
    </div>
  );
}

export default UserData;
