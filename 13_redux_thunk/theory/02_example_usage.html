Usage Example

Functions that extract REST API interaction code in Redux Thunk are called "Thunks". A "Thunk" is an asynchronous Action.

The difference between them is that a regular Action Creator returns an object with Action Type and Payload (the Action itself), while a Thunk returns an asynchronous function:

import { AppDispatch, RootState } from './store';

const sendUserData = () => async (dispatch: AppDispatch, getState: () => RootState) => {
  // REST API interaction logic
};

Inside the Thunk, there is access to Dispatch and the getState function, which returns the entire Store.

It will become clearer with an example. Let's add a "Send" button to the previous component:

/** /components/UserData.tsx */

import { useSelector, useDispatch } from 'react-redux';
import { setName, setSurname } from '../redux/actions';
import { RootState, AppDispatch } from '../redux/store';

const UserData = () => {
  const dispatch = useDispatch<AppDispatch>();

  const name = useSelector((state: RootState) => state.user.name);
  const surname = useSelector((state: RootState) => state.user.surname);

  return (
    <div>
      <input value={name} onChange={(event) => dispatch(setName(event.target.value))} />
      <input value={surname} onChange={(event) => dispatch(setSurname(event.target.value))} />
      <button onClick={() => {}}>Send</button> 
    </div>
  );
}

export default UserData;

For now, the "Send" button does nothing. Our task is to make it so that when "Send" is clicked, name and surname are sent to a REST API endpoint.

Since a Thunk is an asynchronous Action, we add it to the Actions file:

/** /redux/actions.ts */

import { AppDispatch, RootState } from './store';

export const SET_NAME = "SET_NAME" as const;
export const SET_SURNAME = "SET_SURNAME" as const;

type SetNameAction = { type: typeof SET_NAME; payload: string };
type SetSurnameAction = { type: typeof SET_SURNAME; payload: string };
export type UserAction = SetNameAction | SetSurnameAction;

export const setName = (name: string): SetNameAction => ({
  type: SET_NAME,
  payload: name
});

export const setSurname = (surname: string): SetSurnameAction => ({
  type: SET_SURNAME,
  payload: surname
});

// Thunk
export const sendUserData = () => async (dispatch: AppDispatch, getState: () => RootState) => {
    try {
        const userName = getState().user.name;
        const userSurname = getState().user.surname;

        const response = await fetch('https://yourapi/user', {
            method: 'POST',
            body: JSON.stringify({
                name: userName,
                surname: userSurname,
            })
        });

        const result = await response.json();
        console.log("Result:", result);
    } catch(e) {
        console.log('sendUserData error', e)
    }
};

sendUserData is a Thunk. To be precise, it is a function that returns a callback accepting Dispatch as the first parameter and getState as the second.

Inside the callback, asynchronous code is written, for example REST API interaction.

All code inside should be wrapped in a try-catch construct to handle unexpected errors, since the server may return an error.

'const userName = getState().user.name' - userName contains the value of the name field inside userReducer.

Next - simulating sending this data to a fictional REST API and processing the server response with output of the result to the screen.

Let's assume that after processing the server response, we need to clear the name and surname fields in the Store:

export const sendUserData = () => async (dispatch: AppDispatch, getState: () => RootState) => {
    try {
        const userName = getState().user.name;
        const userSurname = getState().user.surname;

        const response = await fetch('https://yourapi/user', {
            method: 'POST',
            body: JSON.stringify({
                name: userName,
                surname: userSurname,
            })
        });

        const result = await response.json();
        console.log("Result:", result);
        dispatch(setName(''));
        dispatch(setSurname(''));
    } catch(e) {
        console.log('sendUserData error', e)
    }
};

To clear the fields, we use the Dispatch provided by the Thunk.

All that remains is to use the Thunk from the component. To call a Thunk, Dispatch is called just like for a regular Action:

/** /components/UserData.tsx */

import { useSelector, useDispatch } from 'react-redux';
import { setName, setSurname, sendUserData } from '../redux/actions';
import { RootState, AppDispatch } from '../redux/store';

const UserData = () => {
  const dispatch = useDispatch<AppDispatch>();

  const name = useSelector((state: RootState) => state.user.name);
  const surname = useSelector((state: RootState) => state.user.surname);

  return (
    <div>
      <input value={name} onChange={(event) => dispatch(setName(event.target.value))} />
      <input value={surname} onChange={(event) => dispatch(setSurname(event.target.value))} />
      <button onClick={() => {dispatch(sendUserData())}}>Send</button> 
    </div>
  );
}

export default UserData;
