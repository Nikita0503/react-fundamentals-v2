What is Redux Thunk

Keeping REST API interaction logic in component code is not a good practice. Redux Thunk is used for this purpose.

To start working with Redux Thunk, you need to take 2 steps:

First - install Redux Thunk in the project: 

npm install redux-thunk

Second - connect Redux Thunk:

/** /redux/store */

import { combineReducers, createStore, applyMiddleware } from 'redux';
import thunkMiddleware from 'redux-thunk';
import userReducer from './reducer';

const rootReducer = combineReducers({
    user: userReducer,
});

export const store = createStore(rootReducer, applyMiddleware(thunkMiddleware));

To integrate middlewares into Redux, the result of the applyMiddleware function is passed as the second parameter to createStore.

ApplyMiddleware accepts middlewares. In our case, only 1 middleware - Redux Thunk. It is located in the 'redux-thunk' package.

Middleware can be understood as: an operation that executes between two other operations.
