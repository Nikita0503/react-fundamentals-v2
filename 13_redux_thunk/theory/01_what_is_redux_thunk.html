Що таке Redux Thunk

Тримати логіку взаємодії з REST API у коді компонента не є хорошою практикою. Для цього використовується Redux Thunk.

Для початку роботи з Redux Thunk необхідно зробити 2 кроки:

Перший - встановити Redux thunk у проект: 

npm install redux-thunk

Другий - підключити Redux Thunk:

/** /redux/store */

import { combineReducers, createStore, applyMiddleware } from 'redux';
import thunkMiddleware from 'redux-thunk';
import userReducer from './reducer';

const rootReducer = combineReducers({
    user: userReducer,
});

export const store = createStore(rootReducer, applyMiddleware(thunkMiddleware));

Тому для впровадження middlewares у Redux, другим параметром до createStore передається результат функції applyMiddleware.

ApplyMiddleware приймає middlewares. У нашому випадку тільки 1 middleware - Redux Thunk. Він знаходиться у пакеті 'redux-thunk'.

Middleware можна розуміти так: операція, котра відпрацьовує між двома іншими операціями.
