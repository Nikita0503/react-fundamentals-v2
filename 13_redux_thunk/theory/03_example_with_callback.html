Приклад з callback-параметром

Існують випадки, коли в Санку необхідно передати параметри з компоненту. Для нашого випадку: передамо функцію, котра повідомляє користувача про успішне виконання відправки даних:

/** /components/UserData.js */
import { useSelector, useDispatch } from 'react-redux';
import { setName, setSurname, sendUserData } from '../redux/actions';

const UserData = () => {
  const dispatch = useDispatch();

  const name = useSelector(state => state.user.name);
  const surname = useSelector(state => state.login.surname);

  const successMessage = () => {
    alert('Дані відправлені успішно.');
  }

  return (
    <div>
      <input value={name} onChange={(event) => dispatch(setName(event.target.value))} />
      <input value={surname} onChange={(event) => dispatch(setSurname(event.target.value))} />
      <button onClick={() => {dispatch(sendUserData(successMessage))}}>Send</button> 
    </div>
  );
}

export default UserData;

Для цього створимо функцію successMessage, котра виводить повідомлення та передамо її як параметр до Санки sendUserData.

Залишилося викликати цю функцію в середині Санки:

export const sendUserData = (callback) => async (dispatch, getState) => {    
    try{
        const userName = getState().user.name;
        const userSurname = getState().user.surname;

	const response = await fetch('https://yourapi/user', {
            method: 'POST',
            body: JSON.stringify({
                name: userName,
                surname: userSurname,
            })
        });

        const result = await response.json();
        console.log("Результат:", result);
	dispatch(setName(''));
        dispatch(setSurname(''));
	if(!!callback){
	    callback();
	}
    }catch(e){
        console.log('sendUserData error', e)
    }
};

Такий механізм називається callback, тож нехай параметр має таку назву.

Пілся очищення полів name та surname, перевіряємо чи був переданий якийсь callback, та викликаємо його.

Теперь після успішного виконання запиту, користувач буде повідомлений.
