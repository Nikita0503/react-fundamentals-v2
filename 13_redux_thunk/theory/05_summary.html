Summary

In this module, we covered connecting and using Redux Thunk with a simple example. Asynchronous code was moved to a separate file, and as a result - the code became more readable and the architecture more correct.

Possible questions:

"Are there alternatives to Redux Thunk?"

Answer - yes, there are. It is Redux Saga. This middleware is significantly more complex than Redux Thunk, but more flexible. It should be used in large projects with more complex REST API interaction processes.

"At what stage should Redux Thunk be connected to the project?"

Answer - preferably from the very beginning. If you or the development team has decided to use a set of middlewares or libraries, it is better to install and connect them right away, for more convenient project architecture building.
