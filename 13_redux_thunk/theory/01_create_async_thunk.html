Why Async in Redux?

Redux reducers are pure, synchronous functions. They take state + action and return new state — no side effects allowed. But real applications need to make API calls, read from databases, or perform other async operations.

The question is: where does async logic live? The answer in Redux Toolkit is thunks.

What is a Thunk?

A thunk is a function that returns another function — it's a pattern for delaying execution. In Redux, a thunk is a function that:

  • Gets dispatched like a regular action
  • Receives dispatch and getState as arguments
  • Can contain async logic (API calls, timeouts, etc.)
  • Can dispatch other actions based on results

Redux Toolkit includes thunk middleware by default — no extra installation needed. When you use configureStore, thunk support is already there.

createAsyncThunk Syntax

createAsyncThunk is RTK's utility for creating thunks that handle async operations. It takes two arguments:

  1. A string action type prefix (e.g., "user/fetchUser")
  2. A payload creator — an async function that returns the data
import { createAsyncThunk } from "@reduxjs/toolkit";

type User = {
  id: string;
  name: string;
  email: string;
};

const fetchUser = createAsyncThunk(
  "user/fetchUser",
  async (userId: string, thunkAPI) => {
    const response = await fetch(`/api/users/${userId}`);
    return response.json() as Promise<User>;
  }
);

What It Generates Automatically

createAsyncThunk automatically generates 3 lifecycle action types based on the string prefix you provide:

  • fetchUser.pending → "user/fetchUser/pending" — dispatched when the async function starts
  • fetchUser.fulfilled → "user/fetchUser/fulfilled" — dispatched when the Promise resolves
  • fetchUser.rejected → "user/fetchUser/rejected" — dispatched when the Promise rejects or you call rejectWithValue

You don't create these actions manually — they're generated for you. You just handle them in your reducer.

TypeScript: Typing createAsyncThunk

You can provide generic type parameters for full type safety:

// createAsyncThunk<ReturnType, ArgType, ThunkApiConfig>

type FetchUserError = {
  message: string;
  statusCode: number;
};

const fetchUser = createAsyncThunk<
  User,              // Return type of the payload creator
  string,            // Argument type (what you pass when dispatching)
  { rejectValue: FetchUserError }  // ThunkAPI config
>(
  "user/fetchUser",
  async (userId, thunkAPI) => {
    const response = await fetch(`/api/users/${userId}`);
    if (!response.ok) {
      return thunkAPI.rejectWithValue({
        message: "User not found",
        statusCode: response.status,
      });
    }
    return response.json() as Promise<User>;
  }
);

Error Handling: rejectWithValue

By default, if your async function throws, the rejected action's payload is the error message. But you often want structured error data. Use thunkAPI.rejectWithValue():

const fetchUser = createAsyncThunk<
  User,
  string,
  { rejectValue: FetchUserError }
>(
  "user/fetchUser",
  async (userId, thunkAPI) => {
    try {
      const response = await fetch(`/api/users/${userId}`);
      if (!response.ok) {
        const errorData = await response.json();
        // This becomes action.payload in the rejected case
        return thunkAPI.rejectWithValue({
          message: errorData.message,
          statusCode: response.status,
        });
      }
      return (await response.json()) as User;
    } catch (error) {
      return thunkAPI.rejectWithValue({
        message: "Network error",
        statusCode: 0,
      });
    }
  }
);

Dispatching a Thunk

You dispatch a thunk just like any other action. It returns a Promise that you can await:

// In a component or another thunk:
dispatch(fetchUser("123"));

// You can also await the result:
const result = await dispatch(fetchUser("123"));

if (fetchUser.fulfilled.match(result)) {
  console.log("User loaded:", result.payload);
}

if (fetchUser.rejected.match(result)) {
  console.log("Error:", result.payload); // typed as FetchUserError
}

Full Example: Fetching a User

// store/thunks/fetchUser.ts
import { createAsyncThunk } from "@reduxjs/toolkit";

type User = {
  id: string;
  name: string;
  email: string;
  avatar: string;
};

type FetchUserError = {
  message: string;
  statusCode: number;
};

export const fetchUser = createAsyncThunk<
  User,
  string,
  { rejectValue: FetchUserError }
>(
  "user/fetchUser",
  async (userId, thunkAPI) => {
    try {
      const response = await fetch(`/api/users/${userId}`);

      if (!response.ok) {
        const errorData = await response.json();
        return thunkAPI.rejectWithValue({
          message: errorData.message || "Failed to fetch user",
          statusCode: response.status,
        });
      }

      return (await response.json()) as User;
    } catch (error) {
      return thunkAPI.rejectWithValue({
        message: "Network error — please check your connection",
        statusCode: 0,
      });
    }
  }
);
