What is useReducer?

useReducer is a built-in React hook — it has nothing to do with the Redux library. It's just an alternative to useState for managing state that has multiple related values.

Instead of calling setState directly, you "dispatch" an action (a plain object that describes what happened), and a "reducer" function decides how the state should change.

The Pattern

The useReducer pattern has four parts:

const [state, dispatch] = useReducer(reducer, initialState);
  • state — the current state value (like what useState returns)
  • dispatch — a function to send actions to the reducer (instead of calling setState directly)
  • reducer — a pure function with signature (state, action) => newState. It takes the current state and an action, and returns the new state. "Pure" means it has no side effects — given the same inputs, it always returns the same output.
  • initialState — the starting value for your state

Full Example — Counter with Multiple Actions

A simple counter where state changes depend on which action was dispatched:

import { useReducer } from "react";

// State type
type CounterState = {
  count: number;
};

// All possible actions
type CounterAction =
  | { type: "INCREMENT" }
  | { type: "DECREMENT" }
  | { type: "RESET" }
  | { type: "SET"; value: number };

const initialState: CounterState = { count: 0 };

// Reducer — decides how state changes based on the action
const counterReducer = (state: CounterState, action: CounterAction): CounterState => {
  switch (action.type) {
    case "INCREMENT":
      return { count: state.count + 1 };
    case "DECREMENT":
      return { count: state.count - 1 };
    case "RESET":
      return { count: 0 };
    case "SET":
      return { count: action.value };
    default:
      return state;
  }
};

const Counter = () => {
  const [state, dispatch] = useReducer(counterReducer, initialState);

  return (
    <div>
      <p>Count: {state.count}</p>
      <button onClick={() => dispatch({ type: "INCREMENT" })}>+1</button>
      <button onClick={() => dispatch({ type: "DECREMENT" })}>-1</button>
      <button onClick={() => dispatch({ type: "RESET" })}>Reset</button>
      <button onClick={() => dispatch({ type: "SET", value: 10 })}>Set to 10</button>
    </div>
  );
};

Practical Advice

  • For most React components, useState is enough — don't reach for useReducer by default
  • For complex shared state across many components, state management libraries like Zustand or Redux Toolkit are better than useReducer
  • useReducer is useful for: local complex state (forms, wizards), and understanding Redux (same pattern — actions, reducers, dispatch)
  • Interview question: "When would you use useReducer?" — answer: when state updates are complex and interdependent, e.g., a multi-step form where going to the next step also resets validation errors
