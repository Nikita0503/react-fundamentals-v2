Компоненти обгортки

HOC також можна називати компонентом обгорткою, але це визначення більш стосується компонентів, котрі мають властивість дочірніх елементів (props.children).

props.children в React - це спеціальна властивість, яка дозволяє передавати дочірні елементи в компонент як вміст між відкриваючим і закриваючим тегами компонента. Це дозволяє компонентам використовувати вкладені елементи, такі як текст, інші компоненти або фрагменти в своєму внутрішньому вмісті (бути контейнерами).

props.children дозволяє створювати компоненти з більш гнучким відображенням та функціональністю, оскільки вони можуть приймати та відображати дочірні елементи без необхідності жорстко прописувати їх у властивості компонента. Це особливо корисно, коли компонент має бути використаний в різних контекстах з різним вмістом.

Ось приклад використання props.children у компоненті, який надає додаткові стилі:

import React from 'react';

const Container = (props) => {
  return (
    <div className="container">
      {props.children}
    </div>
  );
};
  
export default Container;
import React from 'react';
import Container from './Container';
  
const App = () => {
  return (
    <div>
      <h1>Мій додаток</h1>
      <Container>
        <p>Вміст контейнера</p>
      </Container>
    </div>
  );
};

export default App;

Стиль container може містити будь-які налаштування. Це можуть бути відступи (margin), колір фону (background-color) та багато іншого. Усі компоненти, що будуть знаходитися між відкритим та закритим тегами Container будуть обгорнуті в блок, який має стилі класу container.

Ми розглянули приклад компонента обгортки з використанням стилів, але це може бути більш складна реалізація:

import React from 'react';

const Card = ({ title, children }) => {
  return (
    <div className="card">
      <h2>{title}</h2>
      <div className="card-content">
        {children}
      </div>
    </div>
  );
};

export default Card;
import React from 'react';
import Card from './Card';
  
const App = () => {
  return (
    <div>
      <h1>Мій додаток</h1>
      <Card title="Карта 1">
        <p>Це контент першої карти.</p>
        <button>Дія</button>
      </Card>
      <Card title="Карта 2">
        <p>Це контент другої карти.</p>
        <a href="#">Посилання</a>
      </Card>
    </div>
  );
};
  
export default App;

У цьому прикладі, компонент Card має властивість title, яка передається в якості заголовка карти, і props.children, який містить вміст карти між відкриваючим і закриваючим тегами. Завдяки props.children можна передавати будь-який вміст (текст, елементи, компоненти) внутрішнім елементом Card безпосередньо в розмітці, що робить компонент Card більш варіативним та повторно використовуваним.
