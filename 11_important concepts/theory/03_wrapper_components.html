Wrapper Components

A HOC can also be called a wrapper component, but this definition is more applicable to components that have the children property (props.children).

props.children in React is a special property that allows passing child elements into a component as content between the opening and closing tags of the component. This allows components to use nested elements such as text, other components, or fragments in their internal content (to be containers).

props.children allows creating components with more flexible rendering and functionality, since they can accept and display child elements without the need to hardcode them in the component's properties. This is especially useful when a component needs to be used in different contexts with different content.

Here is an example of using props.children in a component that provides additional styles:

import React from 'react';

const Container = (props) => {
  return (
    <div className="container">
      {props.children}
    </div>
  );
};
  
export default Container;
import React from 'react';
import Container from './Container';
  
const App = () => {
  return (
    <div>
      <h1>My App</h1>
      <Container>
        <p>Container content</p>
      </Container>
    </div>
  );
};

export default App;

The container style can contain any settings. These can be margins, background color, and much more. All components placed between the opening and closing Container tags will be wrapped in a block that has the container class styles.

We looked at an example of a wrapper component using styles, but it can be a more complex implementation:

import React from 'react';

const Card = ({ title, children }) => {
  return (
    <div className="card">
      <h2>{title}</h2>
      <div className="card-content">
        {children}
      </div>
    </div>
  );
};

export default Card;
import React from 'react';
import Card from './Card';
  
const App = () => {
  return (
    <div>
      <h1>My App</h1>
      <Card title="Card 1">
        <p>This is the content of the first card.</p>
        <button>Action</button>
      </Card>
      <Card title="Card 2">
        <p>This is the content of the second card.</p>
        <a href="#">Link</a>
      </Card>
    </div>
  );
};
  
export default App;

In this example, the Card component has a title property that is passed as the card's heading, and props.children, which contains the card's content between the opening and closing tags. Thanks to props.children, you can pass any content (text, elements, components) as an inner element of Card directly in the markup, making the Card component more versatile and reusable.
