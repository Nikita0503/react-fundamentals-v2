Компоненти вищого порядку

Компоненти вищого порядку (Higher-Order Components або HOCs) в React - це функції, які приймають компонент React в якості вхідного параметра і повертають новий компонент React в якості виходу. HOC не є частиною синтаксису React, а є патерном використання функцій вищого порядку в JavaScript.

Одна з основних використань HOC - це розширення функціональності компонентів React без зміни їхньої реалізації. HOC можуть бути використані для додавання спільної логіки до різних компонентів, такої як логування, авторизація, кешування, операції з мережею, переклад та багато іншого.

Для прикладу розглянемо HOC, де у разі якщо користувач авторизований, повертаємо наданий компонент, якщо ні - повертаємо надпис «Немає доступу»:

import React from 'react';

// Оголошуємо основний компонент, який буде обгортатися HOC
const MyComponent = () => {
  return (
    <div>
      <h1>Hello, React</h1>
    </div>
  );
};

// Оголошуємо HOC з назвою withAuthorization
const withAuthorization = (WrappedComponent) => {
  return (props) => {
    // Тут має бути власна логіка перевірки авторизації
    const isAuthorized = true; // В даному прикладі завжди повертає true

    if (isAuthorized) {
      // Якщо користувач авторизований, повертаємо обгорнутий компонент
      return <WrappedComponent {...props} />;
    } else {
      // Якщо користувач не авторизований, повертаємо надпис "Немає доступу"
      return <div>Немає доступу</div>;
    }
  }
};

// Використовуємо HOC для обгортання основного компоненту
const MyComponentWithAuthorization = withAuthorization(MyComponent);

export default MyComponentWithAuthorization;

У цьому коді withAuthorization є HOC, який приймає WrappedComponent (основний компонент) і повертає новий функціональний компонент, який перевіряє, чи користувач авторизований. Якщо користувач авторизований, HOC повертає WrappedComponent з усіма переданими йому властивостями (props), в іншому випадку повертає надпис "Немає доступу". Компонент MyComponent є основним компонентом, який може бути обгорнутий HOC withAuthorization, щоб додати логіку авторизації до його відображення.
