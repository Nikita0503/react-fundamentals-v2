Higher-Order Components

Higher-Order Components (HOCs) in React are functions that accept a React component as an input parameter and return a new React component as output. HOC is not part of React's syntax, but rather a pattern of using higher-order functions in JavaScript.

One of the main uses of HOC is extending the functionality of React components without changing their implementation. HOCs can be used to add shared logic to different components, such as logging, authorization, caching, network operations, translation, and much more.

As an example, let's look at a HOC where if the user is authorized, we return the provided component, if not — we return the message "Access denied":

// withAuthorization.tsx

import React, { ComponentType } from 'react';

// Declare the main component that will be wrapped by the HOC
const MyComponent = () => {
  return (
    <div>
      <h1>Hello, React</h1>
    </div>
  );
};

// Declare the HOC named withAuthorization
const withAuthorization = <P extends object>(WrappedComponent: ComponentType<P>) => {
  return (props: P) => {
    // Here should be your own authorization check logic
    const isAuthorized = true; // In this example it always returns true

    if (isAuthorized) {
      // If the user is authorized, return the wrapped component
      return <WrappedComponent {...props} />;
    } else {
      // If the user is not authorized, return the message "Access denied"
      return <div>Access denied</div>;
    }
  }
};

// Use the HOC to wrap the main component
const MyComponentWithAuthorization = withAuthorization(MyComponent);

export default MyComponentWithAuthorization;

In this code, withAuthorization is a HOC that accepts WrappedComponent (the main component) and returns a new functional component that checks whether the user is authorized. If the user is authorized, the HOC returns WrappedComponent with all its passed props, otherwise it returns the message "Access denied". The MyComponent is the main component that can be wrapped by the HOC withAuthorization to add authorization logic to its rendering.
