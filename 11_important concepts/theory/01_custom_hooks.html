Custom Hooks

React itself and various libraries provide developers with many hooks, but usually this is not enough. Therefore, developers write custom (self-created) hooks that help isolate certain logic and use them in different components.

As an example, let's implement a custom hook that accepts a REST API endpoint URL and returns the response (data), an error (error, if one occurs), and the execution status (loading):

import { useState, useEffect } from 'react';

const useAdvancedFetch = (url) => {
    const [data, setData] = useState(null);
    const [error, setError] = useState(null);
    const [loading, setLoading] = useState(true);
    
    useEffect(() => {
      setLoading(true);
      fetch(url)
        .then((response) => response.json())
        .then((jsonData) => {
          setData(jsonData);
        })
        .catch((err) => {
          setError(err);
        })
        .finally(() => {
          setLoading(false);
        });
    }, [url]);
    
    return { data, error, loading };
};
    
export default useAdvancedFetch;

This hook accepts a URL as an argument and uses the useState and useEffect hooks to make an API request, storing the data, error, and loading status.

It then returns an object with this data, which can be used in components to display content, handle errors, or show the loading state based on the values of data, error, and loading.

And now it can be used in different components to isolate the request logic, providing only the request URL. Based on the execution results returned by the hook, you can configure the component's behavior.

import React from 'react';
import useAdvancedFetch from './hooks/useAdvancedFetch';

const MyComponent = () => {

  const { data, error, loading } = useAdvancedFetch('https://random.api/v1/posts');

  return (
    <div>
      <p>Component with custom hook</p>
      {loading ? (
        <p>Loading...</p>
      ) : (
        <>
          {data && <p>{JSON.stringify(data)}</p>}
          {error && <p>{error}</p>}
        </>
      )}
    </div>
  );
};

export default MyComponent;
