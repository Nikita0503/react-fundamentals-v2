Кастомні хуки

Сам React та різноманітні бібліотеки надають розробникам багато хуків, але зазвичай цього недостатньо. Тому розробники пишуть кастомні (створені самостійно) хуки, які допомогають ізолювати певну логіку та використовувати їх у різних компонентах.

Для прикладу реалізуємо кастомний хук, котрий приймає посилання на ендпоінт REST API, та повертає відповідь (data), помилку (error, якщо виникає) та статус виконання (loading):

import { useState, useEffect } from 'react';

const useAdvancedFetch = (url) => {
    const [data, setData] = useState(null);
    const [error, setError] = useState(null);
    const [loading, setLoading] = useState(true);
    
    useEffect(() => {
      setLoading(true);
      fetch(url)
        .then((response) => response.json())
        .then((jsonData) => {
          setData(jsonData);
        })
        .catch((err) => {
          setError(err);
        })
        .finally(() => {
          setLoading(false);
        });
    }, [url]);
    
    return { data, error, loading };
};
    
export default useAdvancedFetch;

Цей хук приймає URL в якості аргументу та використовує useState та useEffect хуки для виконання запиту до API, зберігання даних, помилки та статусу завантаження.

Потім він повертає об'єкт з цими даними, який може бути використаний в компонентах для відображення вмісту, обробки помилок або відображення стану завантаження на основі значень data, error та loading.

І тепер його можна використовувати у різних компонентах для ізоляції логіки запиту, надаючи лише url запиту. А вже спираючись на результати виконання, котрі повертає хук, налаштовувати поведінку компонента.

import React from 'react';
import useAdvancedFetch from './hooks/useAdvancedFetch';

const MyComponent = () => {

  const { data, error, loading } = useAdvancedFetch('https://random.api/v1/posts');

  return (
    <div>
      <p>Component with custom hook</p>
      {loading ? (
        <p>Loading...</p>
      ) : (
        <>
          {data && <p>{JSON.stringify(data)}</p>}
          {error && <p>{error}</p>}
        </>
      )}
    </div>
  );
};

export default MyComponent;
