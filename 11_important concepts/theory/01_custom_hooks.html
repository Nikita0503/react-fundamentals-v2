Custom Hooks

What is a custom hook?

A custom hook is a function that starts with use and can call other hooks inside it. It allows you to extract reusable logic from components. Instead of copy-pasting useState/useEffect patterns across multiple components, you put them in a hook.

Rules of Hooks (apply to custom hooks too)

  1. Must start with use (useToggle, useFetch, useDebounce)
  2. Can only be called at the top level (not inside conditions, loops, or nested functions)
  3. Can only be called from React components or other custom hooks

When to create a custom hook

  • Same useState + useEffect pattern repeated in multiple components
  • Complex logic that clutters the component
  • You want to test the logic independently from the UI

Example 1: useToggle — simple boolean toggle

import { useState, useCallback } from "react";

const useToggle = (initialValue = false) => {
  const [value, setValue] = useState(initialValue);

  const toggle = useCallback(() => setValue(prev => !prev), []);
  const setTrue = useCallback(() => setValue(true), []);
  const setFalse = useCallback(() => setValue(false), []);

  return { value, toggle, setTrue, setFalse };
};

// Usage:
const Modal = () => {
  const { value: isOpen, toggle, setFalse: close } = useToggle();
  return (
    <div>
      <button onClick={toggle}>Toggle Modal</button>
      {isOpen && <div className="modal"><button onClick={close}>Close</button></div>}
    </div>
  );
};

Example 2: useFetch — data fetching with loading/error states

import { useState, useEffect } from "react";

type UseFetchResult<T> = {
  data: T | null;
  error: string | null;
  loading: boolean;
};

const useFetch = <T>(url: string): UseFetchResult<T> => {
  const [data, setData] = useState<T | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    setLoading(true);
    fetch(url)
      .then(res => res.json())
      .then((json: T) => setData(json))
      .catch(err => setError(err.message))
      .finally(() => setLoading(false));
  }, [url]);

  return { data, error, loading };
};

// Usage:
type Post = { id: number; title: string };

const PostList = () => {
  const { data: posts, loading, error } = useFetch<Post[]>("https://api.example.com/posts");

  if (loading) return <p>Loading...</p>;
  if (error) return <p>Error: {error}</p>;
  return <ul>{posts?.map(p => <li key={p.id}>{p.title}</li>)}</ul>;
};

Note: in real projects, you'd use TanStack Query instead of a custom useFetch — but understanding the pattern is valuable for learning.

Example 3: useOnlineStatus — track internet connection

import { useState, useEffect } from "react";

const useOnlineStatus = () => {
  const [isOnline, setIsOnline] = useState(navigator.onLine);

  useEffect(() => {
    const handleOnline = () => setIsOnline(true);
    const handleOffline = () => setIsOnline(false);

    window.addEventListener("online", handleOnline);
    window.addEventListener("offline", handleOffline);

    return () => {
      window.removeEventListener("online", handleOnline);
      window.removeEventListener("offline", handleOffline);
    };
  }, []);

  return isOnline;
};

// Usage:
const StatusBar = () => {
  const isOnline = useOnlineStatus();

  return <p>{isOnline ? "✅ Online" : "❌ Offline"}</p>;
};

Example 4: useDebounce — delay value updates (for search inputs)

import { useState, useEffect } from "react";

const useDebounce = <T>(value: T, delay: number): T => {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => setDebouncedValue(value), delay);
    return () => clearTimeout(timer);
  }, [value, delay]);

  return debouncedValue;
};

// Usage:
const Search = () => {
  const [query, setQuery] = useState("");
  const debouncedQuery = useDebounce(query, 300);

  useEffect(() => {
    if (debouncedQuery) {
      // fetch search results only after user stops typing for 300ms
      fetch(`/api/search?q=${debouncedQuery}`);
    }
  }, [debouncedQuery]);

  return <input value={query} onChange={e => setQuery(e.target.value)} />;
};

Custom hook best practices

  • Name clearly: useX where X describes what it does
  • Return an object (for named access) or tuple (for positional, like useState)
  • Keep hooks focused — one responsibility per hook
  • Hooks can call other custom hooks (composition)
