Children & Composition

The children prop

The children prop is a special prop that contains whatever is placed between a component's opening and closing tags. Its TypeScript type is ReactNode (can be text, elements, components, arrays, null, undefined).

Basic wrapper / container pattern

import { ReactNode } from "react";

type ContainerProps = {
  children: ReactNode;
};

const Container = ({ children }: ContainerProps) => (
  <div className="container">{children}</div>
);

// Usage:
<Container>
  <h1>Title</h1>
  <p>Any content goes here</p>
</Container>

Card pattern — wrapper with its own props + children

type CardProps = {
  title: string;
  children: ReactNode;
};

const Card = ({ title, children }: CardProps) => (
  <div className="card">
    <h2 className="card-title">{title}</h2>
    <div className="card-body">{children}</div>
  </div>
);

// Usage:
<Card title="User Profile">
  <p>Name: Alice</p>
  <button>Edit</button>
</Card>

Layout pattern — page structure with named slots

type LayoutProps = {
  header: ReactNode;
  sidebar: ReactNode;
  children: ReactNode; // main content
};

const Layout = ({ header, sidebar, children }: LayoutProps) => (
  <div className="layout">
    <header>{header}</header>
    <aside>{sidebar}</aside>
    <main>{children}</main>
  </div>
);

// Usage:
<Layout header={<NavBar />} sidebar={<Menu />}>
  <h1>Page Content</h1>
</Layout>

This is the "slots" pattern — named props for specific areas + children for the main content.

Composition over inheritance

  • React doesn't use class inheritance for component reuse
  • Instead: compose components together (small pieces → bigger pieces)
  • children is the primary mechanism for composition
  • This is more flexible than inheritance — any content can go inside

When to use children

  • Layout components (Container, Card, Modal, Sidebar)
  • Generic wrappers (ErrorBoundary, ThemeProvider, AnimationWrapper)
  • Components where the inner content varies but the outer structure is fixed
