Яке правильне твердження щодо кастомних хуків у React?


( ) Кастомні хуки непотрібні, оскільки вбудовані хуки React вже надають достатньо функціональності для розробки. ( ) Кастомні хуки стають причиною конфліктів із вбудованими хуками React та іншими бібліотеками. ( ) Кастомні хуки призначені лише для невеликих проектів і не принесуть значної вигоди у великих додатках. (x) Кастомні хуки дозволяють ізолювати та перевикористовувати логіку, спрощуючи компоненти та полегшуючи їхнє тестування. ( ) Кастомні хуки ускладнюють код та роблять його важчим для розуміння.

Чи можна передавати у кастомний хук параметри?


( ) Ні, кастомний хук завжди має фіксовану логіку та не приймає параметрів. (x) Так, у кастомний хук можна передавати параметри, які використовуються для налаштування його логіки. ( ) Тільки в класових компонентах можна передавати параметри у кастомні хуки.
