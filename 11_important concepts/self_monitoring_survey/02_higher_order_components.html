Що таке компоненти вищого порядку (HOC) в React?


( ) HOC - це синтаксичний елемент React, який дозволяє створювати вищі порядки компонентів без використання функцій вищого порядку. (x) HOC - це функції, які приймають компонент React в якості вхідного параметра і повертають новий компонент React в якості виходу. ( ) HOC - це вбудовані функції React, які автоматично надають вищий порядок компонентам за необхідності.

Яке основне використання компонентів вищого порядку (HOC) в React?


( ) HOC використовуються виключно для зміни структури DOM у React-додатках. (x) HOC можуть бути використані для розширення функціональності компонентів React без зміни їхньої реалізації. ( ) HOC використовуються для створення точних копій компонентів у React-додатках.

Що буде у результаті виконання коду?


// Оголошуємо основний компонент, який буде обгортатися HOC
const MyComponent = ({ username }) => {
  return (
    <div>
      <h1>Hello, {username}</h1>
    </div>
  );
};

// Оголошуємо HOC з назвою withLogging
const withLogging = (WrappedComponent) => {
  return (props) => {
    // Додаємо логування перед відображенням компонента
    console.log(`Компонент відображається з username:`, props.username);

    // Повертаємо обгорнутий компонент
    return <WrappedComponent {...props} />;
  };
};

// Використовуємо HOC для обгортання основного компоненту
const MyComponentWithLogging = withLogging(MyComponent);

// Використання компонента з логуванням
const App = () => {
  return <MyComponentWithLogging username="User123" />;
};

( ) Нічого не виведеться у консоль, а компонент App покаже "Hello, User123". (x) У консолі буде: "Компонент відображається з username: User123", а компонент App покаже "Hello, User123". (x) У консолі буде: "Компонент відображається з username: User123", а компонент App покаже "Hello, undefined". ( ) Нічого не виведеться у консоль, а компонент App покаже "Hello, undefined".
