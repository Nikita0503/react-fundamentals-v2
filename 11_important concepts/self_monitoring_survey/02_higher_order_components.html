What are Higher-Order Components (HOC) in React?


( ) HOC is a syntactic element of React that allows creating higher-order components without using higher-order functions. (x) HOC are functions that accept a React component as an input parameter and return a new React component as output. ( ) HOC are built-in React functions that automatically provide higher order to components when needed.

What is the main use of Higher-Order Components (HOC) in React?


( ) HOCs are used exclusively to change the DOM structure in React applications. (x) HOCs can be used to extend the functionality of React components without changing their implementation. ( ) HOCs are used to create exact copies of components in React applications.

What will be the result of executing this code?


// Declare the main component that will be wrapped by the HOC
const MyComponent = ({ username }) => {
  return (
    <div>
      <h1>Hello, {username}</h1>
    </div>
  );
};

// Declare the HOC named withLogging
const withLogging = (WrappedComponent) => {
  return (props) => {
    // Add logging before rendering the component
    console.log(`Component is rendering with username:`, props.username);

    // Return the wrapped component
    return <WrappedComponent {...props} />;
  };
};

// Use the HOC to wrap the main component
const MyComponentWithLogging = withLogging(MyComponent);

// Using the component with logging
const App = () => {
  return <MyComponentWithLogging username="User123" />;
};

( ) Nothing will be logged to the console, and the App component will show "Hello, User123". (x) The console will show: "Component is rendering with username: User123", and the App component will show "Hello, User123". (x) The console will show: "Component is rendering with username: User123", and the App component will show "Hello, undefined".
