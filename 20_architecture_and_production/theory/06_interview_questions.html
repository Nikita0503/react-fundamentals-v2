Top 15 React Interview Questions

Concise answers you can use as a reference. Each answer covers the "what" and "why" — interviewers care about understanding, not memorization.

1. What is the Virtual DOM and how does it work?

A lightweight JavaScript representation of the real DOM. When state changes, React creates a new Virtual DOM tree, diffs it with the previous one (reconciliation), and applies only the minimal changes to the real DOM. This is faster than manipulating the real DOM directly for every change.

2. What are the rules of hooks?

1) Only call hooks at the top level (not inside conditions, loops, or nested functions). 2) Only call hooks from React components or custom hooks. This ensures hooks are called in the same order every render — React relies on call order to match state to the correct hook.

3. What is the difference between useEffect and useLayoutEffect?

useEffect runs asynchronously after the browser paints. useLayoutEffect runs synchronously before the browser paints. Use useLayoutEffect only when you need to measure or mutate DOM before the user sees it (rare — e.g., tooltip positioning, preventing visual flicker).

4. Explain React.memo, useMemo, and useCallback.

  • React.memo: wraps a component, skips re-render if props didn't change (shallow comparison)
  • useMemo: caches a computed value, recomputes only when dependencies change
  • useCallback: caches a function reference, useful when passing callbacks to memoized children
  • They work together: useCallback stabilizes the function → memo sees same reference → skips render

5. What is the key prop and why is it important?

A unique identifier for list items. React uses it to track which items changed/added/removed during reconciliation. Without stable keys, React may reuse wrong component instances, causing bugs with state (e.g., input values appearing in the wrong list item).

6. Controlled vs uncontrolled components?

Controlled: React state drives the input value (value + onChange). Uncontrolled: DOM owns the value, accessed via ref. Controlled gives you full control (validation, formatting, conditional logic). Uncontrolled is simpler for basic cases where you only need the value on submit.

7. What is lifting state up?

Moving shared state to the nearest common parent of components that need it. Parent owns the state, passes it down via props. Enables sibling communication without global state. We covered this in the State Management module.

8. What are the limitations of Context?

All consumers re-render when the context value changes (no selectors — you can't subscribe to just one field). Not suitable for frequently changing data (like mouse position or animation frames). For complex or frequently updating state, use Zustand or Redux.

9. How does React handle batching?

React 18+ automatically batches multiple setState calls in the same event handler into one re-render. This means calling setState 3 times doesn't cause 3 re-renders — just one. Before React 18, batching only worked in React event handlers (not in setTimeout or promises).

10. What is React Fiber?

The internal reconciliation engine (React 16+). It breaks rendering work into small units that can be paused, prioritized, and resumed. Enables features like Suspense, useTransition, and concurrent rendering. Before Fiber, rendering was synchronous and couldn't be interrupted.

11. What is a custom hook?

A function starting with "use" that encapsulates reusable logic using other hooks. Extracts complex useState/useEffect patterns into a shareable, testable unit. Each component that uses the hook gets its own independent state — hooks don't share state between components.

12. How do you optimize a slow React app?

  1. Measure first (React DevTools Profiler) — don't guess
  2. Move state down / lift content up
  3. React.memo for expensive children
  4. useMemo for expensive computations
  5. Code split with React.lazy
  6. Virtualize long lists (react-window or @tanstack/react-virtual)

13. What is an Error Boundary?

A class component that catches rendering errors in its child tree and shows a fallback UI instead of crashing the whole app. Uses getDerivedStateFromError + componentDidCatch. The only remaining use case for class components in modern React.

14. Explain useReducer vs useState.

useState: simple state (counter, toggle, single value). useReducer: complex state with many related fields and complex update logic (multi-step forms, state machines). Same dispatch/action pattern as Redux but local to the component.

15. What is Suspense?

A component that shows a fallback (like a spinner or "Loading...") while a lazy-loaded component is being downloaded. You wrap lazy components with <Suspense fallback={...}> — React shows the fallback until the component's code is ready, then swaps it in automatically.

Tips for React Interviews

  • Show you understand WHY, not just HOW (why does React use keys? why is memo needed?)
  • Mention trade-offs (memo has comparison cost, Context re-renders all consumers)
  • Give real examples from your experience
  • It's OK to say "I'd need to look up the exact API, but the concept is..."
  • Ask clarifying questions — interviewers appreciate it
