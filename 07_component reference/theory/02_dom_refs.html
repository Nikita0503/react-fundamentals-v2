DOM Refs — Direct Access to DOM Elements

The primary use case for useRef is getting direct access to a DOM element. Sometimes you need to interact with the DOM directly — focus an input, scroll to an element, measure dimensions, or integrate with a non-React library that expects a DOM node.

The Pattern

  1. Create a ref: const myRef = useRef<HTMLElement>(null)
  2. Attach it to an element via the ref attribute: <input ref={myRef} />
  3. Access the DOM node via myRef.current (after mount)

Example 1: Focus an Input

import { useRef } from "react";

const SearchBar = () => {
  const inputRef = useRef<HTMLInputElement>(null);

  const handleFocus = () => {
    inputRef.current?.focus();
  };

  return (
    <div>
      <input ref={inputRef} type="text" placeholder="Search..." />
      <button onClick={handleFocus}>Focus search</button>
    </div>
  );
};

Example 2: Scroll to Element

import { useRef } from "react";

const ScrollDemo = () => {
  const bottomRef = useRef<HTMLDivElement>(null);

  const scrollToBottom = () => {
    bottomRef.current?.scrollIntoView({ behavior: "smooth" });
  };

  return (
    <div>
      <button onClick={scrollToBottom}>Scroll to bottom</button>
      {/* ... lots of content ... */}
      <div ref={bottomRef}>Bottom of the page</div>
    </div>
  );
};

Example 3: Measure Element Size

import { useRef, useState, useEffect } from "react";

const MeasuredBox = () => {
  const boxRef = useRef<HTMLDivElement>(null);
  const [dimensions, setDimensions] = useState({ width: 0, height: 0 });

  useEffect(() => {
    if (boxRef.current) {
      const { width, height } = boxRef.current.getBoundingClientRect();
      setDimensions({ width, height });
    }
  }, []);

  return (
    <div>
      <div ref={boxRef} style={{ padding: 20, border: "1px solid gray" }}>
        Measure me!
      </div>
      <p>Width: {dimensions.width}px, Height: {dimensions.height}px</p>
    </div>
  );
};

TypeScript Generics for Different Elements

Use the correct HTML element type as the generic parameter:

useRef<HTMLInputElement>(null)    // <input>
useRef<HTMLDivElement>(null)      // <div>
useRef<HTMLButtonElement>(null)   // <button>
useRef<HTMLTextAreaElement>(null) // <textarea>
useRef<HTMLVideoElement>(null)    // <video>

Important: Ref is null Until Mount

The ref starts as null and only gets assigned the DOM element after the component mounts. This means:

  • Always use optional chaining (?.) or null checks when accessing ref.current
  • Don't try to access the ref during the initial render — it won't be set yet
  • Inside useEffect is safe because effects run after mount

When to Use DOM Refs

  • Focus management — programmatically focusing inputs for accessibility
  • Scrolling to elements — smooth scroll to sections, chat auto-scroll
  • Measuring element dimensions — responsive layouts, tooltips positioning
  • Integrating with third-party DOM libraries — charts (D3, Chart.js), maps (Leaflet, Google Maps), video players
  • Triggering animations — GSAP, Web Animations API
