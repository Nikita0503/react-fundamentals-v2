useRef

В React є можливість звертатися до компонентів та звертатися до їх методів напряму за домогою хука useRef.  useRef - це хук в React, який дозволяє отримувати посилання на DOM-елемент або зберігати значення між рендерами без того, щоб спричиняти перерендер компонента. Він дозволяє працювати з DOM-елементами безпосередньо в функціональних компонентах.

Ось приклад використання useRef:

import React, { useRef } from 'react';

const MyComponent = () => {
  const inputRef = useRef(null); // Створення посилання на DOM-елемент

  const handleClick = () => {
    inputRef.current.focus(); // Виклик методу focus() на DOM-елементі за допомогою useRef
  };

  return (
    <div>
      <input ref={inputRef} type="text" />
      <button onClick={handleClick}>Фокус</button>
    </div>
  );
};

export default MyComponent;

У цьому прикладі ми використовуємо useRef для створення посилання на DOM-елемент input за допомогою атрибуту ref. Потім ми можемо викликати методи цього DOM-елемента, такі як focus(), без необхідності виклику setState або спричинення перерендеру компонента.

useRef також може використовуватись для зберігання значень, які не мають впливу на рендер компонента між оновленнями:

import React, { useRef } from 'react';

const MyComponent = () => {
  const countRef = useRef(0); // Створення посилання на значення

  const handleClick = () => {
    countRef.current++; // Зміна значення через посилання
    console.log('Поточне значення count:', countRef.current);
  };

  return (
    <div>
      <button onClick={handleClick}>Збільшити</button>
    </div>);
};

export default MyComponent;

У цьому прикладі ми використовуємо useRef для створення посилання зі значенням 0 під час ініціалізації компонента.

Ми можемо змінювати значення цього посилання без необхідності виклику setState або спричинення перерендеру компонента.

Використовуючи countRef.current, ми можемо отримати поточне значення збереженого значення count між оновленнями компонента.

Ось приклад використання useRef зі введенням даних у поле вводу:

import React, { useRef } from 'react';

const InputComponent = () => {
  const inputRef = useRef(null); // Створення посилання на елемент input

  const handleButtonClick = () => {
    // Отримання значення з елементу input за допомогою current.value
    const inputValue = inputRef.current.value;
    alert(`Введене значення: ${inputValue}`);
  };

  return (
    <div>
      <input ref={inputRef} type="text" />
      <button onClick={handleButtonClick}>Показати значення</button>
    </div>
  );
};

export default InputComponent;

У цьому прикладі ми використовуємо useRef для створення посилання на елемент вводу input в компоненті.

За допомогою inputRef.current.value ми можемо отримати поточне значення, введене в поле вводу, без необхідності використання onChange обробника подій.
