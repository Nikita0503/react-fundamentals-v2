useRef

In React, there is the ability to reference components and call their methods directly using the useRef hook. useRef is a hook in React that allows you to get a reference to a DOM element or store values between renders without causing a component re-render. It allows working with DOM elements directly in functional components.

Here is an example of using useRef:

import React, { useRef } from 'react';

const MyComponent = () => {
  const inputRef = useRef(null); // Creating a reference to a DOM element

  const handleClick = () => {
    inputRef.current.focus(); // Calling the focus() method on the DOM element using useRef
  };

  return (
    <div>
      <input ref={inputRef} type="text" />
      <button onClick={handleClick}>Focus</button>
    </div>
  );
};

export default MyComponent;

In this example, we use useRef to create a reference to the DOM element input using the ref attribute. Then we can call methods of this DOM element, such as focus(), without the need to call setState or cause a component re-render.

useRef can also be used to store values that do not affect the render of the component between updates:

import React, { useRef } from 'react';

const MyComponent = () => {
  const countRef = useRef(0); // Creating a reference to a value

  const handleClick = () => {
    countRef.current++; // Changing the value through the reference
    console.log('Current count value:', countRef.current);
  };

  return (
    <div>
      <button onClick={handleClick}>Increment</button>
    </div>);
};

export default MyComponent;

In this example, we use useRef to create a reference with a value of 0 during component initialization.

We can change the value of this reference without the need to call setState or cause a component re-render.

Using countRef.current, we can get the current value of the stored count value between component updates.

Here is an example of using useRef with data input in an input field:

import React, { useRef } from 'react';

const InputComponent = () => {
  const inputRef = useRef(null); // Creating a reference to the input element

  const handleButtonClick = () => {
    // Getting the value from the input element using current.value
    const inputValue = inputRef.current.value;
    alert(`Entered value: ${inputValue}`);
  };

  return (
    <div>
      <input ref={inputRef} type="text" />
      <button onClick={handleButtonClick}>Show value</button>
    </div>
  );
};

export default InputComponent;

In this example, we use useRef to create a reference to the input element in the component.

Using inputRef.current.value, we can get the current value entered in the input field without the need to use an onChange event handler.
